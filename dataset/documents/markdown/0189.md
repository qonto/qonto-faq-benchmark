# Comment créer une facture d'acompte et une facture de solde ?

Cette fonctionnalité permet de demander des paiements anticipés à vos clients, particulièrement utile pour les projets nécessitant des coûts initiaux importants. Une fois la facture d'acompte réglée, une facture de solde peut être émise pour le montant restant. Ce processus aide à gérer votre trésorerie, réduire les risques d'impayés et assurer la conformité.

Qui peut utiliser cette fonctionnalité ?
----------------------------------------

Cette fonctionnalité est disponible sur web et mobile, accessible à tous les forfaits sans add-on supplémentaire. Les factures d'acompte peuvent être créées par les Propriétaires et Administrateurs. Les Comptables peuvent consulter les factures d'acompte créées.

Comment créer une facture d'acompte ?
-------------------------------------

Vous pouvez la créer soit à partir d'un devis validé, soit depuis la section Factures clients :

#### **À partir d'un devis validé :**

1. Accédez à la section **Devis**
2. Sélectionnez un devis validé (les devis non validés ne peuvent pas être convertis en factures d'acompte)
3. Cliquez sur **Créer une facture d'acompte**
4. Dans l'écran de création, activez l'option "**C'est une facture d'acompte**"
5. Précisez le montant ou le pourcentage d'acompte, ajoutez une description (optionnel), et vérifiez le montant calculé
6. Cliquez sur **Créer la facture** pour générer votre facture d'acompte

#### **Depuis la section Factures clients :**

1. Allez dans **Factures > Factures clients** dans le menu
2. Cliquez sur **Créer une facture**
3. Dans l'écran de création, activez l'option **C'est une facture d'acompte**
4. Précisez le montant d'acompte, ajoutez une description (optionnel), et vérifiez le montant calculé
5. Cliquez sur **Créer la facture** pour générer votre facture d'acompte

Vous pouvez visualiser toutes vos factures d'acompte dans le tableau de bord Factures clients. La liste affiche le type de facture et le numéro sous le nom du client.

Vous pouvez également personnaliser vos factures d'acompte en ajoutant :

* Des en-têtes personnalisés, conditions générales
* Des pourcentages ou montants d'acompte
* Des dates d'échéance pour le paiement de l'acompte

Que se passe-t-il après le paiement d'une facture d'acompte ?
-------------------------------------------------------------

Une fois la facture d'acompte payée, vous pouvez générer une facture de solde pour le montant restant (calculé automatiquement) en accédant à la facture d'acompte payée. L'acompte sera automatiquement lié à la facture finale et/ou au devis pour un suivi simplifié.

⚠️ La facture de solde n'est pas générée automatiquement après le paiement de la facture d'acompte.

Comment annuler une facture d'acompte ?
---------------------------------------

* Pour les factures d'acompte **non payées** : Annulez directement depuis la vue de la facture d'acompte.
* Pour les factures d'acompte **payées** : Annulez via un avoir depuis la vue de la facture d'acompte.

Comment créer une facture de solde ?
------------------------------------

1. Ouvrez la facture d'acompte payée
2. Cliquez sur "**Créer la facture de solde**"
3. Le solde restant est calculé automatiquement
4. Vérifiez et finalisez la facture.
