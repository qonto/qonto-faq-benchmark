# Wie kann ich mir die Fahrtkosten erstatten lassen?

Die Kilometererstattungsfunktion ist verfügbar unter [dem Spesenmanagement-Add-on.](https://support-de.qonto.com/hc/de/articles/28602398347537)

Wenn Sie Ihr privates Fahrzeug für eine geschäftliche Reise genutzt haben, können Sie ganz einfach eine Erstattung der Reisekosten über unsere Kilometererstattungsfunktion beantragen. Es ist möglich, dass Eigentümer, Administratoren und fortgeschrittene Manager mit aktivierten Überweisungsberechtigungen Kilometeranträge genehmigen.

**Was benötige ich, um einen Kilometerantrag einzureichen?**
------------------------------------------------------------

* Start- und Zielpunkt Ihrer Reise

**💡** Sie können Ihre Route mit Google Maps in unserer App auswählen. Es berechnet automatisch die Entfernung zwischen den beiden Punkten und Sie können diese auch in eine Hin- und Rückfahrt umwandeln.

* Fahrzeugtyp und Steuerkraft: Sie finden die Steuerkraft Ihres Fahrzeugs in Ihrem Fahrzeugschein.

💡 Der Spesenbetrag wird automatisch basierend auf [den vordefinierten Tarifen im Qonto-Berechnungssystem](https://support-de.qonto.com/hc/de/articles/23949196873233) eingegeben, unter Verwendung der von Ihnen in den vorherigen Schritten angegebenen Standorte und Fahrzeugdaten. Sie können den Betrag nicht manuell hinzufügen oder bearbeiten.

* Zweck der Reise: Geben Sie Ihrem Administrator oder fortgeschrittenen Manager mehr Kontext zu Ihrer Ausgabe.
* IBAN: Um Ihre Erstattung zu erhalten, müssen Sie die IBAN Ihres persönlichen Bankkontos eingeben. Sie können Ihre IBAN direkt bei der Antragsstellung hinzufügen oder in Ihrem persönlichen Profil ausfüllen.

💡 Ihre IBAN wird in Ihrem Profil gespeichert und kann direkt von dort hinzugefügt oder aktualisiert werden.

**Wie kann ich eine Kilometerpauschale beantragen oder einreichen?**
--------------------------------------------------------------------

**In der Mobil App**

Die Kilometerpauschale-Funktion ist verfügbar im [Kostenmanagement-Add-on.](https://support-de.qonto.com/hc/de/articles/28602398347537)

Wenn Sie Ihr privates Fahrzeug für eine dienstliche Reise genutzt haben, können Sie ganz einfach eine Erstattung der Reisekosten über unsere Kilometerpauschale-Funktion beantragen. Es ist möglich für Eigentümer, Administratoren und Fortgeschrittene Manager mit aktivierten Überweisungsberechtigungen, Kilometeranfragen zu genehmigen.

**Was benötige ich, um eine Kilometeranfrage einzureichen?**
------------------------------------------------------------

* Startpunkt und Ziel Ihrer Reise

**💡** Sie können Ihre Route mit Google Maps in unserer App wählen. Es berechnet automatisch die Entfernung zwischen den beiden Punkten, und Sie können dies auch in eine Hin- und Rückfahrt umwandeln.

* Fahrzeugtyp und steuerliche Leistung: Sie finden die steuerliche Leistung Ihres Fahrzeugs in Ihrem Fahrzeugschein.

💡 Der Ausgabenbetrag wird automatisch basierend auf den [vordefinierten Tarifen im Qonto-Berechnungssystem](https://support-de.qonto.com/hc/de/articles/23949196873233) eingetragen, unter Verwendung der von Ihnen angegebenen Standorte und Fahrzeugdetails. Sie können den Betrag nicht manuell hinzufügen oder bearbeiten.

* Zweck der Reise: Geben Sie mehr Kontext zu Ihrer Ausgabe für Ihren Administrator oder Fortgeschrittenen Manager an.
* IBAN: Um Ihre Erstattung zu erhalten, müssen Sie die IBAN Ihres persönlichen Bankkontos eingeben. Sie können Ihre IBAN direkt bei der Anfrage hinzufügen oder in Ihrem persönlichen Profil ausfüllen.

💡 Ihre IBAN wird in Ihrem Profil gespeichert und kann dort direkt hinzugefügt oder aktualisiert werden.

**Wie kann ich eine Kilometerpauschale anfordern oder einreichen?**
-------------------------------------------------------------------

**Am Desktop**

1. Wählen Sie den Abschnitt **Team-Ausgaben** auf der linken Seite.
2. Klicken Sie auf **Erstattung**, dann **Eine Ausgabe einreichen.**
3. Wählen Sie **Kilometerpauschale.**
4. Geben Sie Ihre **Reiseroute** an, indem Sie einen Startpunkt und ein Ziel auswählen, und bestätigen Sie dann.
5. Füllen Sie den **Zweck Ihrer Reise** aus und geben Sie Ihre IBAN an, falls Sie diese noch nicht zu Ihrem Profil hinzugefügt haben.

**Auf dem Handy**

1. Öffnen Sie die Qonto-App auf Ihrem Gerät.
2. Tippen Sie auf **Anfragen**, dann **Kilometerpauschale.**
3. Geben Sie Ihre **Reiseroute** an, indem Sie einen Startpunkt und ein Ziel auswählen, und bestätigen Sie dann.
4. Füllen Sie den **Zweck Ihrer Reise** aus und geben Sie Ihre IBAN an, falls Sie diese noch nicht zu Ihrem Profil hinzugefügt haben.

💡 Eigentümer, Administratoren und Fortgeschrittene Manager mit Überweisungsberechtigungen können ihre eigenen Kilometerpauschalen direkt genehmigen und bezahlen.

**Wie kann ich den Status meiner Anfrage sehen?**
-------------------------------------------------

Sie können den Status Ihrer Anfrage im Abschnitt **Anfragen** sehen. Wenn ein Erstattungsantrag genehmigt wird, erhalten Sie eine sofortige Erstattungsüberweisung auf die ausgewählte IBAN. Wenn ein Antrag abgelehnt wird, erhalten Sie eine E-Mail und Benachrichtigung mit einem Grund, der von Ihrem Administrator oder Fortgeschrittenen Manager angegeben wurde. Sie können dies sehen, indem Sie auf die Anfrage klicken.
