# Quelles applications puis-je connecter à mon compte Qonto ?

Retrouvez grâce à ce [lien](https://www.notion.so/06f32797e0b64860949cada860f9f67c?pvs=21) la liste des applications que vous pouvez connecter à Qonto, le mode d’installation de l’intégration ainsi que plus d’informations sur les données qu’il sera possible de synchroniser.

👆 Bon à savoir : Le mode d’installation ainsi que les données que vous pourrez synchroniser est propre à chaque intégration.

**Comment connecter une application avec Qonto ?**
==================================================

Consultez [cette page](https://www.notion.so/06f32797e0b64860949cada860f9f67c?pvs=21) pour connaître le mode d’installation de l’application que vous souhaitez connecter à Qonto. Ensuite, retrouvez ci-dessous la marche à suivre pour connecter votre outil à Qonto.

**Connexion à votre application depuis votre application web Qonto** :

1. Cliquez sur l’icône **Paramètres** en bas à gauche de la page principale
2. Sélectionnez **Intégrations et partenariats > Intégrations**
3. Cliquez sur l’application que vous souhaitez installer, puis sur **Connecter** en haut à droite de votre écran.
4. Enfin, laissez-vous guider pour finir d’installer l’intégration.

**Connexion directement sur l'application avec vos identifiants Qonto :**

L’intégration se fera directement depuis l’application que vous souhaitez connecter à Qonto : vous aurez besoin de vos accès Qonto pour installer l’intégration.

**Connexion à Qonto avec votre clé API Qonto** :

1. Cliquez sur l’icône **Paramètres** en bas à gauche de la page principale
2. Sélectionnez **Intégrations et partenariats > Clé API**
3. Renseignez ensuite cette clé API directement depuis l’application que vous souhaitez connecter à Qonto.

👆 Bon à savoir : Pour plus d’informations sur votre clé API, consultez [cet article](https://qonto9015.zendesk.com/hc/fr/articles/23947692362513-O%C3%B9-trouver-mon-identifiant-et-ma-cl%C3%A9-secr%C3%A8te-API) dédié.

**Comment faire si une intégration n’est pas disponible ?**
===========================================================

Vous pouvez nous suggérer une nouvelle intégration directement depuis l’application web Qonto :

1. Cliquez sur l’icône **Paramètres** en bas à gauche de la page principale
2. Sélectionnez **Intégrations et partenariats > Intégrations**
3. Allez en bas de page et cliquez sur **Vous ne trouvez pas l’intégration à votre outil préféré ?** afin de suggérer une nouvelle intégration

Vous pouvez également utiliser [Zapier](https://qonto9015.zendesk.com/hc/fr/articles/23947682572049-Comment-fonctionne-l-int%C3%A9gration-Zapier-x-Qonto) et [Make](https://support-fr.qonto.com/hc/fr/articles/23947679146129-Comment-fonctionne-l-int%C3%A9gration-Make-ex-Integromat-x-Qonto) pour automatiser certaines tâches manuelles ou connecter votre compte Qonto à encore plus d’outils.

**Vous avez développé une nouvelle intégration ?**
==================================================

N’hésitez pas à nous envoyer un e-mail à [connect@qonto.com](mailto:connect@qonto.com) pour que nous puissions la partager.
