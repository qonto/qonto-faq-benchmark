# Quelles sont les permissions du rôle Manager ?

Le rôle de manager est divisé en deux niveaux de permissions :

* Manager basique : disponible avec [les plans Business et Enterprise](https://qonto.com/fr/pricing?select-toggle=custom&periodicity=yearly).
* Manager avancé : disponible via [les modules complémentaires Gestion des factures fournisseurs et Gestion des dépenses d'équipes.](https://support-fr.qonto.com/knowledge/editor/01J82QW3AS08GGZN09Y8JYR6NF/fr?brand_id=17320677699345)

Le rôle de manager est également personnalisable : les Administrateurs ou le Titulaire du compte définissent les permissions pour chaque manager individuellement.

Quel est le périmètre des permissions pour un Manager ?
-------------------------------------------------------

En fonction de ce qu'ils souhaitent déléguer, l'Admin ou le Titulaire définit le périmètre des permissions pour chaque Manager :

* au niveau de l'**ensemble de l'entreprise**
* au niveau de l'**équipe**

Le Manager pourra voir les transactions, gérer les paiements, inviter les Employés et accéder aux soldes en fonction du niveau de périmètre choisi.

💡 Vous devez [créer une équipe](https://support-fr.qonto.com/hc/fr/articles/23947666322961-Comment-cr%C3%A9er-et-modifier-une-%C3%A9quipe-dans-Qonto) avant d'attribuer un Manager à une équipe.

|  |  |  |
| --- | --- | --- |
|  | **Manager Basique** | **Manager Avancé** |
| Accéder aux transactions | ✅ | ✅ |
| Effectuer des paiements depuis des comptes sélectionnés | ✅ | ✅ |
| Gérer les cartes | ✅ | ✅ |
| Effectuer des virements et rembourser les dépenses (fixer des limites de dépenses, par mois et par virement) | ✅ | ✅ |
| Télécharger et configurer les factures fournisseurs | ✅ | ✅ |
| Inviter des membres de l'équipe en tant qu'Employés | ✅ | ✅ |
| Valider les demandes de carte | ✅ | ✅ |
| Consulter les soldes de comptes sélectionnés | ❌ | ✅ |
| Voir l'IBAN et télécharger les relevés | ❌ | ✅ (si le périmètre du manager est étendu à l'ensemble de l'entreprise) |
| Gérer la comptabilité et les fournisseurs | ❌ | ✅ |
| Approuver les virements et rembourser les dépenses, y compris les frais de déplacement | ❌ | ✅ |
| Configurer et suspendre les mandats de prélèvement automatique | ❌ | ✅ |
| Déposer des chèques | ❌ | ✅ |

Le manager avancé peut être inclus dans le flux d'approbation pour les demandes de virement et de remboursement, paramétré par le Titulaire ou un Admin. Si vous disposez des modules complémentaires Gestion des factures fournisseurs et Gestion des dépenses d'équipes, veuillez consulter [Comment personnaliser le circuit de validation pour les demandes de virement et de remboursement ?](https://support-fr.qonto.com/hc/fr/articles/26570070089745-Comment-personnaliser-le-circuit-de-validation-des-demandes-de-virement-et-de-remboursement) pour en savoir plus.

Un Manager peut-il accéder à certains sous-comptes ?
----------------------------------------------------

Oui, que les permissions d'un Manager soient au niveau d'une équipe ou de toute l'entreprise, vous pouvez attribuer un ou plusieurs sous-comptes à ces rôles. Ils pourront accéder aux transactions et effectuer des paiements à partir des comptes sélectionnés.

* Le Manager a déjà un profil sur le compte :
  Dans ce cas, allez dans **Gestion des utilisateurs** > **Accès des utilisateurs** > **Actif** > cliquez sur le Manager en question que vous souhaitez modifier > **Permissions du compte** > cliquez sur le **crayon** à côté de **Rôle.** Cliquez sur le rôle **Manager** et sur **sélectionner les sous-comptes** auxquels il peut accéder.
* Le Manager n'a pas encore été invité sur le compte :
  Allez dans **Gestion des utilisateurs** > **Accès des utilisateurs** > **Inviter un membre** > suivez les étapes d'inscription et **sélectionnez les sous-comptes** auxquels il peut accéder.

Vous pouvez également décider si le Manager peut voir les soldes des comptes sélectionnés, l'IBAN, les transactions et télécharger les relevés.

Cette action peut être modifiée à tout moment depuis la section **Accès des utilisateurs**.

Quelles permissions ne peuvent pas être déléguées à un Manager ?
----------------------------------------------------------------

❌ Inviter tous types de membres d'équipe : Admins, Managers et Comptables

❌ Modifier les statuts des rôles pour eux-mêmes et d'autres utilisateurs

❌ Modifier l'abonnement

❌ Configurer des sous-comptes

❌ Configurer et gérer des outils tiers via les intégrations Connect

💡 Les Admins peuvent effectuer ces actions.

Comment vérifier les permissions d'un Manager ?
-----------------------------------------------

Il est possible de consulter le périmètre et les permissions d'un Manager directement depuis son profil de membre.

Depuis un **ordinateur** :

* Rendez-vous sur **Gestion des équipes,**
* Cliquez sur **Accès Utilisateurs,**
* Sélectionnez le profil du Manager que vous souhaitez consulter.



Depuis l'application **mobile** :

* Allez dans **Menu**,
* Accédez aux membres de l'équipe.
