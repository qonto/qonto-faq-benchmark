# What is Two-Factor Authentication (2FA)?

2-factor authentication, 2-step verification

The Two-factor authentication (2FA), sometimes referred to as Two-step verification, involves the transmission of a temporary verification code **via SMS.** The received code must then be entered in addition to the password to confirm the user's identity.

💡 **Two-Factor Authentication is a prerequisite for setting up [Strong Customer Authentication (SCA)](https://qonto9015-it.zendesk.com/hc/en-us/articles/23949944205201), now mandatory for the use of your Qonto account.**

How to set up Two-Factor Authentication?
========================================

1. From your computer, log in to your Qonto account, go to **Settings** > **Personal Settings** section.
2. Click on the **Security** tab
3. In the **Two-Factor Authentication** section, click Configure to start
4. Provide or confirm your **mobile phone number**
5. In the next step, **enter the 6-digit verification code received via SMS**.
   Note: this code is only valid for 1 minute. If you fail to enter it in time, make a new request.

✅ From this moment on, Two-Factor Authentication is successfully configured on your account.

I've lost my phone or no longer have access to my number, What should I do?
