# Où puis-je voir et télécharger mon RIB (IBAN) ?

Votre relevé d’identité bancaire (RIB) sur lequel figurent votre IBAN et votre BIC/SWIFT est disponible sur votre application Qonto (web et mobile).

Application web
---------------

Depuis votre application web, vous avez deux options :

Option 1 : Cliquez sur la section ”**Compte pro**” puis ”**Transactions**”, cliquez sur le bouton ”**Coordonnées bancaires**”, puis ”**Télécharger (PDF)**” pour obtenir le fichier au format PDF ou “**Copier**” pour obtenir un format texte.

Option 2 : Vous pouvez également cliquer sur “**Compte pro**” puis ”**Comptes**”, puis sélectionner votre compte principal ou l’un de vos sous-comptes si vous en disposez.

☝️ Bon à savoir : Vous avez la possibilité de télécharger votre RIB dans une langue étrangère (🇫🇷 🇬🇧 🇪🇸 🇮🇹 🇩🇪), lorsque vous cliquez sur le bouton “**Télécharger (PDF)**” depuis l’app web uniquement.

Application mobile
------------------

1. Depuis votre application mobile, rendez-vous dans “**Menu**”
2. Allez dans la section ”**Comptes (IBAN)”** et sélectionnez le compte de votre choix
3. Choisissez ”**Télécharger PDF**” pour télécharger le fichier de votre RIB au format PDF ou **”Partager l’IBAN”** pour copier le RIB au format texte.

☝️ Sur la version mobile, vous pouvez télécharger votre RIB uniquement dans la langue du pays où est basée votre entreprise.

Pour obtenir un **RIB (IBAN) certifié**, merci de contacter notre support client via la petite bulle de chat sur votre application web ou mobile 💬 ou par e-mail à [support@qonto.com](mailto:support@qonto.com)
