# Comment télécharger une preuve de virement international ?

Il est possible de télécharger une preuve de virement directement depuis votre interface Qonto, en cas de demande de preuve par un tiers par exemple.

☝️ Bon à savoir : Le téléchargement d'une preuve de virement est disponible pour le **Titulaire** du compte, les **Admins** et les **Managers** disposant [des autorisations appropriées](https://support-fr.qonto.com/hc/fr/articles/23947656192145-Quelles-sont-les-permissions-du-r%C3%B4le-Manager).

Les **Managers** sans autorisations ou les **Collaborateurs** ne pourront pas télécharger les preuves de virement, ils doivent contacter un **Admin** ou le **Titulaire** du compte.

Depuis votre application web 💻 :

1. rendez-vous dans l'onglet **Compte pro**
2. puis dans l'onglet **Transactions**
3. sélectionnez le virement
4. cliquez sur **Télécharger la preuve de virement**

Depuis votre application mobile 📱 :

1. rendez-vous dans la section **Transactions**
2. sélectionnez le virement
3. cliquez sur **Télécharger la preuve de virement**

☝️ Bon à savoir : ce document ne peut être téléchargé **que si le virement a été effectué** (il peut y avoir un délai après l'exécution du virement jusqu'à ce que la preuve de paiement soit disponible en raison des banques intermédiaires et des partenaires de paiement).
