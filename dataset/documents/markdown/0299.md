# Comment fonctionne l'intégration Make (ex-Integromat)  x Qonto ?

Automatisation avec l'outil Make Integromat

Avec plus de 500 applications connectées, Make est un outil d'automatisation en ligne avancé. Les scénarios sont illimités pour vous permettre d'aller encore plus loin.

Qonto a développé une intégration avec Make pour automatiser vos processus financiers.

Comment connecter Make avec Qonto ?
-----------------------------------

Vous pouvez connecter votre compte Qonto à Make en quelques clics :

1. Connectez-vous à votre compte Make
2. Partez à la recherche de votre application préférée, Qonto
3. Saisissez vos identifiants Qonto puis sélectionnez le nom de votre entreprise
4. Enfin, autorisez Make à accéder à votre compte Qonto en cliquant sur **Autoriser l'accès**

☝️ Bon à savoir : La mise à jour de cette nouvelle connexion peut prendre quelque temps à se mettre en place.

**Comment initier un virement avec** Make **?**
-----------------------------------------------

Avec Make, vous pouvez initier des virements, à la fois vers un compte externe, mais aussi entre vos comptes courants Qonto. Afin de protéger votre compte, nous avons inclus le [système d'authentification forte](https://support-fr.qonto.com/hc/fr/articles/23947670125329-Qu-est-ce-que-l-authentification-forte-SCA) pour vos virements Make, le même que pour ceux initiés depuis votre application Qonto.

Pour éviter de valider manuellement vos virements automatisés avec Make, nous vous proposons de **définir vos bénéficiaires de confiance** en amont de votre virement :

* Rendez-vous sur [cette page](https://support-fr.qonto.com/hc/fr/articles/23947644174993-Automatisation-des-virements-Pourquoi-et-comment-ajouter-un-b%C3%A9n%C3%A9ficiaire-de-confiance) et suivez les étapes. Vous pouvez aussi le faire [à partir de l'API](https://api-doc.qonto.com/docs/business-api/2247a81491900-trust-a-list-of-beneficiaries).

Prêt ! Vous pouvez automatiser vos transferts sur Make. 🎉

Pour plus d'information sur le fonctionnement de Make, visitez leur [centre d'aide](https://www.make.com/en/help/home) !
