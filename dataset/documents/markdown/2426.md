# ¿Puedo crear varias cuentas para mi empresa?

**Una cuenta por empresa**

En Qonto, cada empresa sólo puede tener una cuenta. Nos basamos en el NIF (Número de Identificación Fiscal). Por lo tanto, no puede haber varias cuentas para el mismo NIF, es decir, para la misma empresa.

**Creación de subcuentas**

Gracias a la función de [cuentas múltiples](https://support-es.qonto.com/hc/es/articles/23950983707409--Qu%C3%A9-son-las-cuentas-m%C3%BAltiples), puedes tener fácilmente, en la misma cuenta, varias subcuentas con IBAN dedicados, así como extractos de cuenta y medios de pago específicos para cada una de estas subcuentas.
