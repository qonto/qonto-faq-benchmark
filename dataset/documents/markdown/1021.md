# Wie kann ich ein SEPA-Mandat über die Qonto Mobile App hochladen? 📲

**SEPA B2B-Lastschriften**
--------------------------

* Füllen Sie das vom Gläubiger erteilte **B2B-Mandat** aus und **unterschreiben Sie es**
* Loggen Sie sich in Ihre Qonto Mobile App ein und klicken Sie im Bereich **Mehr** auf **Lastschriften**
* Klicken Sie auf die Schaltfläche **+**, um das Mandat hochzuladen
* Nehmen Sie ein Foto des Mandats auf oder wählen Sie es aus Ihrer Fotobibliothek oder einem anderen Ordner aus
* Geben Sie die Mandatsdetails ein: die eindeutige Mandatsreferenz (UMR), die Gläubiger-Identifikationsnummer (CSI) und die Zahlungsfrequenz (einmalig oder wiederkehrend).
* Das Mandat einreichen

💡 Wenn Sie [die starke Kundenauthentifizierung](https://support-de.qonto.com/hc/de/articles/23949223040657-Was-ist-die-starke-Kundenauthentifizierung-SCA) in Ihrem Konto eingerichtet haben, werden Sie eine Bestätigungsanfrage auf Ihrem gekoppelten Gerät erhalten.

SEPA-Basislastschriften
-----------------------

Sie müssen in Ihrem Qonto-Konto nichts tun!

Es genügt, wenn Sie Ihrem Gläubiger Ihre Qonto-Bankverbindung mitteilen. Sie können sie jederzeit von Ihrem Konto herunterladen. Der Gläubiger kann dann Ihr Konto belasten.

Sie können [eine SEPA-Basislastschrift anfechten](https://support-de.qonto.com/hc/de/articles/23949254140945-Wie-kann-ich-eine-Lastschrift-widerrufen), wenn der Betrag, der in Ihrem Kontoverlauf erscheint, falsch zu sein scheint.
