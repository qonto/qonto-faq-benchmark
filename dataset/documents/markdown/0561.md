# How do I apply my promotional code?

A promotional code at Qonto is an alphanumeric code that you enter in the app to obtain a discount on the monthly or annual subscription. The discount is directly applied to the subscription fees for a specified period, with only one active code at a time.

How is my promotional code applied to my subscription fees?
-----------------------------------------------------------

### I have a monthly subscription:

A discount is applied to your subscription fees each month for the entire validity of the promotional code. For example, if you have a promotional code of €11 (excluding VAT) for 6 months, €11 (excluding VAT) maximum will be deducted from your monthly fees, each month, for 6 months.

### I have an annual subscription:

If you have an annual subscription, the discount is applied directly to the annual subscription fee. For example, if you have a promotional code of €11 (excluding VAT) for 3 months, the total (€11\*3) will be directly deducted from the annual fee amount at its next renewal.

☝️ Important: In this case, it is necessary to **enter your promotional code before the renewal date**. You must enter the code either during the month preceding the renewal or at the latest in the month of renewal, before the actual date of it.



Note: If you have multiple promotional codes, you can enter all of them on your web interface. **Only one code can be active at a time**. You will therefore have visibility on which one is active and those that are pending. The promotional codes will automatically apply in the order they were entered.

How do I enter my promotional code?
-----------------------------------

### I already have a Qonto account:

To apply a promotional code to your Qonto account, you need to log in from a computer and perform the following actions:

1. Go to the **Settings** section of your Qonto web application at the bottom left.
2. Click on the **Plan and Invoices** section.
3. Enter your promotional code under **Promo Code** and click on **Add**.
4. That's it, your promotional code will be automatically taken into account. 🎉

### I do not yet have a Qonto account:

If you have not yet created your Qonto account or are in the process of doing so, you can apply a promotional code during the registration process. Here's how:

When you reach the plan selection step, a dedicated entry for the promotional code will appear on this page. Enter your code in the field "**Promo Code**".
