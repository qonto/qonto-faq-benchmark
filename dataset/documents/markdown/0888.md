# Wie kann ich eine geplante internationale Überweisung ändern oder stornieren?

Nach der Bestätigung einer Überweisung haben Sie unter bestimmten Umständen immer noch die Möglichkeit, diese direkt über die mobile und die Web-App zu bearbeiten oder zu stornieren.

**Wo kann ich meine geplanten internationalen Überweisungen einsehen?**
-----------------------------------------------------------------------

Eine Übersicht Ihrer Überweisungen finden Sie im Menü **Geschäftskonto** im Bereich **Überweisungen**. Ihre geplanten, noch nicht verarbeiteten Überweisungen erscheinen im Tab **In Bearbeitung**, während bereits abgeschlossene und fehlgeschlagene Überweisungen im Tab **Abgeschlossen** angezeigt werden.

**💡 Gut zu wissen:** Nur abgeschlossene Überweisungen erscheinen in der **Transaktionen** Ansicht. Wenn eine geplante Überweisung über den Bereich **Lieferantenrechnungen** erstellt wird, erscheint die mit dieser Überweisung verbundene Rechnung auch im Tab **Geplante Zahlungen** dieses Bereichs.

**Wie kann ich sie ändern oder stornieren?**
--------------------------------------------

### **💻 In Ihrer Web-App**

1. Klicken Sie auf **Geschäftskonto** und gehen Sie zur Überweisungsübersicht, indem Sie auf **Überweisungen** klicken.
2. Gehen Sie zum Tab **In Bearbeitung** und wählen Sie die Überweisung aus, die Sie bearbeiten oder stornieren möchten.

* Um die Überweisung zu bearbeiten, klicken Sie auf **Bearbeiten**.
  + Nehmen Sie die notwendigen Anpassungen vor und klicken Sie dann auf **Bestätigen**.
  + Führen Sie die Zwei-Faktor-Authentifizierung durch, um die Änderung zu bestätigen.
* Um die Überweisung zu stornieren, klicken Sie auf **Stornieren**.
  + Bestätigen Sie Ihre Aktion, indem Sie im Bestätigungsdialog auf **Bestätigen** klicken.

### **📱In Ihrer mobilen App**

1. Gehen Sie zur Überweisungsübersicht, indem Sie auf **Überweisungen** tippen.
2. Tippen Sie auf die Überweisung, die Sie bearbeiten oder stornieren möchten.

* Um die Überweisung zu bearbeiten, tippen Sie auf **Überweisung bearbeiten**.
  + Nehmen Sie die notwendigen Anpassungen vor und tippen Sie dann auf **Bestätigen**.
  + Führen Sie die Zwei-Faktor-Authentifizierung durch, um die Änderung zu bestätigen.
* Um eine Überweisung zu stornieren, tippen Sie auf **Überweisung stornieren**.
  + Bestätigen Sie Ihre Aktion, indem Sie im Bestätigungsdialog auf **Bestätigen** tippen.

**Gibt es Einschränkungen bei der Änderung der Überweisungsdetails?**
---------------------------------------------------------------------

Es gibt einige Einschränkungen bezüglich der Überweisungsdetails, die bearbeitet werden können, nachdem eine geplante oder wiederkehrende Überweisung eingerichtet wurde.

* Der Betrag, das zu belastende Konto und der Zahlungsempfänger **können nicht mehr geändert werden**. Wenn Sie diese Details ändern möchten, müssen Sie die Überweisung stornieren und eine neue einrichten.
* Die Häufigkeit und das Enddatum einer wiederkehrenden Überweisung können sowohl in der mobilen als auch in der Web-App gändert werden. **Das Ausführungsdatum kann nur in der mobilen App geändert werden.**
