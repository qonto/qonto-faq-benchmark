# Comment les automatisations peuvent-elles améliorer la gestion de mes finances chez Qonto ?

L'automatisation vous permets de gérer plus facilement vos finances, directement depuis votre compte Qonto, améliorant ainsi votre efficacité et réduisant les tâches manuelles.

Qui peut s'en servir ?
----------------------

Cette fonctionnalité est disponible pour les **forfaits Smart, Premium, Essential, Business et Enterprise**, et peut être utilisée par les **rôles Titulaire et Admin.**

Que dois-je savoir avant d'utiliser les automatisations Qonto ?
---------------------------------------------------------------

1. **Compte Unique**
   Vous devez disposer d'au moins deux comptes ou sous-comptes pour configurer des automatisations. Elles ne peuvent pas être mises en place avec un seul compte.
2. **Accès Mobile**
   Les automatisations sont actuellement uniquement accessibles via l'application mobile Qonto, et non sur la plateforme web.
3. **Cas d'Usage Spécifiques**
   Les automatisations sont conçues pour des tâches financières spécifiques et ne peuvent pas être personnalisées à d'autres fins.
4. **Fonds Insuffisants**
   Une automatisation peut échouer s'il n'y a pas assez de fonds dans le compte source lors de son exécution.
5. **Changement de forfait**
   Le fait de rétrograder votre plan ou de supprimer des options peut restreindre certaines fonctionnalités d'automatisation, y compris les approbations automatiques.
6. **Disponibilité des Modèles**
   Tous les modèles ne sont pas actuellement actifs ; certains sont marqués comme "prochainement" et ne peuvent pas encore être utilisés.

Quelles automatisations sont disponibles ?
------------------------------------------

1. **Équilibre TVA sur les revenus :** Gérez votre TVA sans effort en automatisant les calculs de balance.
2. **Répartiteur avancé de revenus :** Divisez automatiquement les revenus dans différentes catégories ou comptes selon vos besoins.
3. **Équilibreur de taxe sur les sociétés (**🇫🇷 **IS) :** Équilibrez facilement les paiements de la taxe sur les sociétés pour les entreprises françaises.
4. **Équilibreur de taxe sur les sociétés (**🇫🇷 **Urssaf) :** Automatisez l'équilibrage des contributions Urssaf pour votre entreprise en France.
5. **Taxes combinées (**🇫🇷 **TVA, Urssaf, et IS) :** Une automatisation complète pour gérer la TVA, les contributions Urssaf et la taxe sur les sociétés collectivement pour une gestion financière sans faille.

Comment puis-je créer une automatisation ?
------------------------------------------

1. **Accéder aux automatisations :**

* Depuis le menu Qonto, cliquez sur **Automatisations**

2. **Choisir un modèle :**

* Cliquez sur l'onglet **modèles**.
* Parcourez la bibliothèque de modèles et sélectionnez un modèle qui répond à vos besoins.

3. **Configurer l'automatisation :**

* Cliquez sur **continuer** après avoir sélectionné un modèle.
* Suivez les instructions pour configurer l'automatisation :

+ Sélectionnez les comptes source et de destination (tous les modèles nécessitent au moins 2 comptes).
+ Définissez les déclencheurs, conditions et actions.
+ Revoyez vos paramètres pour vous assurer que tout est correct.

* Cliquez sur **continuer**.

💡 Assurez-vous que des fonds suffisants sont disponibles dans vos comptes sources pour éviter toute interruption dans les flux de travail automatisés.

1. **Choisir le type d'exécution pour l'automatisation :**

* **Demander une approbation :** Nécessite une approbation pour chaque automatisation (chaque fois que l'automatisation se déclenche, vous recevrez une notification et devrez approuver l'action - toutes les automatisations nécessitant une approbation peuvent être trouvées dans les **Tâches**).
* **Automatiquement :** Fonctionne sans intervention (vous serez toujours notifié lorsque l'automatisation se déclenche, sans action requise de votre part).

En suivant ces étapes, vous pouvez automatiser efficacement vos flux financiers chez Qonto, économisant du temps et réduisant les tâches manuelles.

Comment puis-je modifier et supprimer une automatisation ?
----------------------------------------------------------

1. **Voir les automatisations actives :**

* Allez dans l'onglet **Vos automatisations**.
* Ici, vous pouvez voir toutes vos automatisations actives.
* Vérifiez leur statut et l'historique des automatisations.

2. **Modifier une automatisation :**

* Depuis l'onglet **Vos automatisations**, sélectionnez l'automatisation que vous souhaitez modifier ou supprimer.
* Modifiez les paramètres selon le besoin.
* Sauvegardez vos modifications.

Comment puis-je approuver une tâche automatisée ?
-------------------------------------------------

1. **Pour une approbation manuelle :**

* Recevez une notification de la tâche en attente.
* Rendez-vous dans la section **tâches** de Qonto.
* Sélectionnez l'automatisation que vous devez examiner.
* Examinez attentivement les détails de l'automatisation.
* Si vous êtes satisfait des actions, sélectionnez celles que vous souhaitez approuver et cliquez sur **approuver les actions sélectionnées**.
* Si vous décidez de ne pas approuver l'automatisation, cliquez sur **refuser toutes les actions**.

2. **Pour une approbation automatique :**

* Les tâches s'exécutent automatiquement selon les règles que vous avez définies.
* Vous recevrez des notifications après chaque exécution pour rester informé.
* Vous pouvez consulter l'historique de ces tâches automatiques dans les détails de l'automatisation.
