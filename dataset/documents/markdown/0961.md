# Wie kann ich einem Teammitglied eine Ausgabe erstatten, die mit eigenen Mitteln bezahlt wurde?

*Die **Kilometererstattungs**funktion ist verfügbar mit dem [Ausgabenmanagement-Add-on](https://support-de.qonto.com/hc/en-us/articles/28602398347537-What-add-ons-are-available-to-complete-my-plan)*

**Kilometererstattung** ermöglicht es Teammitgliedern, Erstattungen zu beantragen oder einzureichen, wenn sie bei der Nutzung persönlicher Fahrzeuge für dienstliche Reisen Ausgaben haben. Erstattungsanträge können von Eigentümern, Administratoren und Fortgeschrittenen Managern mit Überweisungsberechtigungen genehmigt werden.

**Wie erfahre ich, wann ein Kilometererstattungs** **antrag eingereicht wurde?**
--------------------------------------------------------------------------------

Eigentümer, Administratoren und Fortgeschrittene Manager mit aktivierten Überweisungsberechtigungen erhalten eine E-Mail und eine mobile Benachrichtigung, sobald ein Antrag eingereicht wurde.

Erfahren Sie mehr darüber, [wie Sie die Benachrichtigungen von Qonto anpassen können](https://support-de.qonto.com/hc/en-us/articles/23949255083409).

**Wie kann ich einen Kilometererstattungsantrag genehmigen oder ablehnen?**
---------------------------------------------------------------------------

**Am Desktop 💻**

1. Wählen Sie den Abschnitt **Team-Ausgaben** auf der linken Seite
2. Klicken Sie auf **Erstattung** und wählen Sie dann einen Kilometerantrag aus
3. Genehmigen Sie den Antrag oder Lehnen Sie ihn ab, einschließlich eines Ablehnungsgrundes.

**Auf dem Handy📱**

1. Öffnen Sie die Qonto-App auf Ihrem Gerät
2. Tippen Sie auf Anfragen und wählen Sie dann den Kilometerantrag aus
3. Tippen Sie auf Per Überweisung zahlen um den Antrag zu genehmigen oder tippen Sie auf Ablehnen, einschließlich eines Ablehnungsgrundes.

Sobald der **Kilometer****erstattungs**antrag genehmigt wurde, erhält der Antragsteller eine sofortige Erstattung.

💡 Der Erstattungsbetrag wird automatisch basierend auf den [vordefinierten Raten im Qonto-Berechnungssystem](https://www.notion.so/A3-FAQ-Content-985dcb12077648699fd0b07502c9bf11?pvs=21) ausgefüllt, unter Verwendung der vom Antragsteller bereitgestellten Standort- und Fahrzeugdetails. Diese können den Betrag nicht manuell hinzufügen oder bearbeiten.

Alle Erstattungsanträge können Teil eines anpassbaren Genehmigungsworkflows sein. Bitte besuchen Sie [Wie passen Sie die Workflow-Genehmigung für Überweisungs- und Erstattungsanfragen an?](https://support-fr.qonto.com/hc/en-us/articles/26570070089745-How-to-customize-workflow-approval-for-transfer-and-reimbursement-requests) um mehr über mehrstufige Genehmigungsworkflows zu erfahren, um die Kontrolle über große zu erstattende oder zu zahlende Beträge mit konfigurierbaren Genehmigungen zu behalten.

Als Eigentümer, Administrator oder Fortgeschrittener Manager mit aktivierten Überweisungsberechtigungen, wie bekomme ich eine Erstattung **für eine Ausgabe, die ich mit meinem eigenen Geld bezahlt habe?**
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Um eine Erstattung für eine geschäftliche Kilometerpauschale zu erhalten, können Eigentümer, Administratoren oder Fortgeschrittene Manager mit Überweisungsberechtigungen das gleiche Verfahren wie oben beschrieben befolgen, indem sie ihre eigenen Einreichungen genehmigen. Sie erhalten dann die Erstattung über eine sofortige Überweisung.
