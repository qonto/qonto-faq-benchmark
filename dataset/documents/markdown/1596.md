# Quale documenti inviarci a supporto della principale fonte di reddito della tua azienda?

All'interno del questionario che ti è stato inviato per completare la richiesta di aggiornamento dei dati societari, ti abbiamo chiesto ***Qual è la principale fonte di reddito della tua azienda?*** e di allegare della documentazione a supporto della scelta effettuata.

💡 Per aiutarti nell'inviarci i documenti corretti, di seguito troverai la lista dei documenti che ci puoi inviare sulla base della scelta fatta.

👉 Nel caso in cui dovessi inviarci più documenti, **ricordati di inserirli all'interno di un file .zip**

* **Vendite di prodotti B2B:**
  + Lista disponenti e beneficiari
    e/o
  + Contratti di vendita
* **Fatture e ricevute di pagamento**
  + Ordini d'acquisto
* **Tariffe di servizio B2B:**
  + Contratti di servizio
  + Fatture per servizi resi
  + Rapporti di attività o di progetto
* **Tariffe di abbonamento B2B:**
  + Contratti di abbonamento
  + Fatture periodiche
  + Registri dei pagamenti ricorrenti
* **Tariffe di licenza:**
  + Contratti di licenza
  + Registri delle royalty
  + Fatture per licenze concesse
* **Commissione:**
  + Contratti di intermediazione
  + Fatture di commissione
  + Rapporti di vendita o di transazione
* **Partnership e collaborazioni B2B:**
  + Accordi di partnership
  + Rapporti di joint venture
  + Fatture o documentazione di profitto condiviso
* **Formazione e workshop:**
  + Contratti di formazione
  + Registi delle iscrizioni
  + Fatture per corsi o workshop erogati
* **Pubblicità e sponsorizzazioni B2B:**
  + Contratti pubblicitari o di sponsorizzazione
  + Fatture pubblicitarie
  + Rapporti di campagne pubblicitarie
* **Vendite di prodotti B2C:**
  + Scontrini e fatture di vendita
  + Rapporti di inventario
  + Ordini di clienti
* **Tariffe di servizio B2C:**
  + Contratti di servizio
  + Fatture di servizio
  + Registri dei pagamenti dei clienti
* **Entrate da abbonamento B2C:**
  + Contratti di abbonamento
  + Fatture ricorrenti
  + Storico dei pagamenti
* **Entrate pubblicitarie B2C:**
  + Contratti pubblicitari
  + Registri delle entrate pubblicitarie
  + Rapporti di visualizzazione degli annunci
* **Marketing di affiliazione:**
  + Accordi di affiliazione
  + Rapporti di commissione
  + Fatture di affiliazione
* **Piattaforme di e-commerce:**
  + Rapporti di vendita online
  + Fatture di e-commerce
  + Registri delle transazioni
* **Operazioni al dettaglio:**
  + Scontrini di vendita al dettaglio
  + Rapporti di cassa
  + Inventari di magazzino
* **Licenze e merchandising:**
  + Contratti di licenza
  + Fatture di merchandising
  + Rapporti di royalty
* **Vendita di biglietti per eventi:**
  + Registri delle vendite di biglietti
  + Fatture di eventi
  + Rapporti di partecipazione agli eventi
* **Crowdfunding e preordini:**
  + Registri delle campagne di crowdfunding
  + Conferme di pre-ordine
  + Rapporti delle entrate da crowdfunding
