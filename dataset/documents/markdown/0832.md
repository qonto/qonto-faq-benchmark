# Wie kann ich eine Echtzeitüberweisung in Euro (SEPA) ausführen?

Eine Echtzeitüberweisung ist eine Überweisung, die innerhalb weniger Sekunden stattfindet, im Gegensatz zu einer Standardüberweisung, die bis zu 3 Arbeitstage dauern kann, bis sie empfangen wird.

Und das Wichtigste: Diese Art von Überweisung funktioniert jeden Tag, zu jeder Zeit, auch an Feiertagen.

**👆Gut zu wissen:** Einmalige, geplante und wiederkehrende Überweisungen sind standardmäßig als Echtzeitüberweisung konfiguriert, aber Sie können auch diese Option abwählen und eine klassische Überweisung (innerhalb von 48 Arbeitsstunden empfangen) im *Letzten Blick Schritt* des Ablaufs durchführen.

Damit Ihre Überweisung sofort erfolgt, muss sie zwei Hauptbedingungen erfüllen:

* sie muss innerhalb der SEPA-Zone erfolgen ([die sich von der Europa-Zone unterscheidet](https://support-de.qonto.com/hc/de/articles/23949231819025))
* sie darf **nicht mehr als 100.000 Euro betragen.**

Wenn Sie beispielsweise an einem Samstag Geld an einen Lieferanten senden, sieht dieser das Geld innerhalb von Sekunden auf seinem Konto.

Bei Qonto ist das **Senden und Empfangen von Echtzeitüberweisungen kostenlos, bis zur Anzahl der in Ihrem [Plan](https://qonto.com/de/pricing) enthaltenen kostenlosen Überweisungen**.

☝🏻 Bitte beachten: Überweisungen zwischen Qonto-Konten sind kostenlos, sodass für eine solche Überweisung keine zusätzlichen Gebühren für Ihren Plan anfallen.

☝🏻 In einigen Fällen ist die Option der Echtzeitüberweisung nicht möglich, und Sie müssen sie als Standardüberweisung senden. 🙏🏻
