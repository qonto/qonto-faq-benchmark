# What is the Slack Requests integration?

The Slack Requests integration allows you to receive daily notifications in your Slack workspace (selected during installation) of all Qonto pending requests, including transfers, multi-transfers, virtual cards, and flash cards. This feature is available for all plans!

Who can set it up?
------------------

**Admin**, or **Owner** roles can install this integration, as long as the **Strong Customer Authentication (SCA)** is enabled on your Qonto account.

How can I install the Slack Request integration?
------------------------------------------------

You need to set the Slack Request integration from the Slack marketplace.

Once it is done, you need to enable it from your Qonto app (’Integrations and Partnerships’ section).

What kind of requests are sent to Slack?
----------------------------------------

The integration sends the following types of requests to Slack:

* **Flash card**
* **Virtual card**
* **Transfer**
* **Multi-transfer**

You can approve or decline these requests directly from Slack, and the decision will be reflected in the Qonto app.

How many users per organization can use the integration?
--------------------------------------------------------

The Slack Requests integration supports **multiple users per organization**.

The user who installs the integration can invite additional Slack users to connect to Qonto, allowing them to approve or decline transfer requests through Slack.

How often will I receive Slack messages?
----------------------------------------

You will receive a summary of your Qonto pending requests **once a day at 8:00 AM**.
