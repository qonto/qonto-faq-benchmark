# Come gestisce Qonto i documenti non finanziari?

Per risparmiare tempo ed evitare confusione, Qonto ora rileva e segnala automaticamente i documenti non finanziari caricati sul tuo account. Questo assicura che la tua libreria di documenti rimanga pertinente alle tue esigenze di gestione finanziaria.

###

### **Cosa significa la notifica “Questo file non sembra una fattura”?**

Questa notifica significa che il nostro sistema OCR ha rilevato un documento che probabilmente non è una fattura o un documento finanziario. Puoi rivederlo, eliminarlo, o sostituirlo con il documento corretto.

###

### **Cosa significa il simbolo ⚠️ accanto a un documento?**

Il simbolo ⚠️ indica un potenziale problema con il documento, come:

* **Non è un documento finanziario**: Il nostro sistema sospetta che il file sia stato caricato per errore.
* **È un duplicato**: Il file sembra identico a un altro documento già caricato.

Per risolvere il problema:

1. Apri il documento segnalato.
2. Se è un duplicato, clicca su **Rivedi fatture** per vedere e rimuovere documenti simili.
3. Se non è un documento pertinente, eliminalo direttamente dalla schermata di revisione.

### **Perché Qonto segnala documenti non finanziari?**

Identificando e segnalando file irrilevanti o duplicati, Qonto ti aiuta a mantenere una libreria di documenti organizzata e a concentrarti sui documenti finanziari che contano di più per i tuoi processi contabili e di riconciliazione.
