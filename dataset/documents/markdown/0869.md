# Wie kann ich meinen Überweisungsnachweis (SEPA) herunterladen?

Sie können einen Überweisungsnachweis direkt über Ihre Qonto-Oberfläche herunterladen, falls ein Dritter einen Nachweis anfordert, zum Beispiel.

**💡 Gut zu wissen:** Das Herunterladen eines Überweisungsnachweises für ausgehende Überweisungen steht **Kontoinhabern**, **Administratoren** und **Managern** mit den [entsprechenden Berechtigungen](https://support-de.qonto.com/hc/de/articles/23949229714705) zur Verfügung.

Manager ohne Berechtigungen oder Mitarbeiter können keine Überweisungsnachweise herunterladen und müssen sich an einen Administrator oder den Kontoinhaber wenden. Manager, die direkt Überweisungen tätigen können und nicht nur Überweisungsanfragen stellen, können Überweisungsnachweise für die von ihnen selbst initiierten Überweisungen herunterladen.

Sollten Sie einen Nachweis für eingehende Überweisungen benötigen, wenden Sie sich einfach per Chat oder E-Mail an unseren Support.

Von Ihrer Web-App aus:

* Gehen Sie zu Ihrem **Geschäftskonto** im Bereich **Transaktionen**
* Suchen Sie die Überweisung, für die Sie einen Überweisungsnachweis benötigen, und klicken Sie darauf
* Klicken Sie im Seitenbereich auf "**Zahlungsnachweis herunterladen**", um das Dokument herunterzuladen

Von Ihrer mobilen App aus:

* Gehen Sie zum Bereich **Überweisungen** im **Menü**
* Suchen Sie die Überweisung, für die Sie einen Überweisungsnachweis benötigen, und klicken Sie darauf
* Klicken Sie auf "**Zahlungsnachweis herunterladen**", um das Dokument herunterzuladen

**💡 Gut zu wissen:** Sie können Ihre ausgehende Überweisung auch im Tab **Überweisungen** finden. Klicken Sie auf **"Überweisungsdetails anzeigen"**, um zu den Details im Tab **Transaktionen** zu gelangen.

**Hinweis:** Dieses Dokument kann nur heruntergeladen werden, wenn [die Überweisung ausgeführt wurde](https://support-de.qonto.com/hc/de/articles/23949259612433).
