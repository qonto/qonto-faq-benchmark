# Wie kann ich eine Karte sperren/entsperren?

Sie können Ihre Qonto-Karte nicht finden und möchten sie zuerst vorübergehend sperren, bevor Sie sie möglicherweise als verloren/gestohlen melden? Sie können sie pausieren.

**Wie kann ich eine Karte vorübergehend sperren?** 🔒

* Gehen Sie zum Abschnitt **‘Geschäftskonto’** und klicken Sie auf **'Karten'**
* Wählen Sie die Karte aus, die Sie sperren möchten
* Klicken Sie auf **'Karte sperren'**
* Bestätigen Sie Ihre Wahl.

Diese Aktion setzt Ihre Karte nur aus, sie blockiert sie nicht dauerhaft. Sie können entscheiden, sie wieder zu entsperren, wenn Sie sie erneut verwenden müssen.

⚠️ Das Pausieren Ihrer Karte wird das mit ihr verknüpfte Abonnement nicht kündigen. Um es zu stoppen, müssen Sie die Karte als verloren oder gestohlen melden.

**Wie kann ich eine Karte nach einer vorübergehenden Sperrung entsperren?** 🔓

* Gehen Sie zum Abschnitt **‘Geschäftskonto’,** und klicken Sie auf **'Karten'**
* Wählen Sie die Karte aus, die Sie entsperren möchten
* Klicken Sie auf **'Karte entsperren'**
* Geben Sie Ihr Passwort ein und wählen Sie **'Diese Karte entsperren'**
* Bestätigen Sie Ihre Wahl.

Wenn Sie ein Mitarbeiter sind, benötigen Sie die Bestätigung Ihres Administrators oder Managers.

**Ich habe meine Karte nicht gefunden und denke, dass sie definitiv verloren/gestohlen ist** 😔

* **Entsperren Sie zuerst Ihre Karte**, wenn Sie sie vorübergehend gesperrt haben.
* Melden Sie sie als verloren/gestohlen, um sie dauerhaft zu sperren

  + Wenn Sie zu der Web-App auf Ihrem Computer geführt werden möchten, klicken Sie bitte **[hier](https://app.qonto.com?tdm=report-lost-card)**, um **die Karte als verloren zu melden**.
    Wenn Sie zu der Web-App auf Ihrem Computer geführt werden möchten, klicken Sie bitte [**hier**](https://app.qonto.com?tdm=report-stolen-card), um **die Karte als gestohlen zu melden.**
