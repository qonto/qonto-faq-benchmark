# Quelles sont les limites pour mes virements ?

**Virements SEPA instantanés**

Il vous est possible d'émettre des virements SEPA instantanés jusqu'à 100 000€ vers votre bénéficiaire. Si votre virement est supérieur à 100 000€ ou que votre bénéficiaire n’est pas atteignable via virements SEPA instantanés, celui-ci sera effectué comme un virement classique.

L'owner pourra également définir des limites personnalisables pour chaque transfert instantané pour lui-même ou pour tout autre membre pouvant effectuer des transferts.

Vous pourrez vérifier ces limites directement sur votre profil.
​

**Virements SEPA standards ?**

Il vous est possible d'émettre des virements SEPA sans limite de montant vers votre bénéficiaire. Si votre virement est supérieur à 30 000€ vous serez dans l’obligation de fournir un justificatif en pièce jointe.

💡 Pour gagner du temps dans votre comptabilité nous vous conseillons d'**ajouter un justificatif à l'émission de chaque virement**.
