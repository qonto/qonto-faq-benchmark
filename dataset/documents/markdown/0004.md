# Comment renommer mon compte courant Qonto ?

**Compte principal**
--------------------

Lorsque vous ouvrez un compte courant Qonto, le nom de votre compte est **Compte principal** par défaut.

Vous souhaitez le renommer ?

Vous pouvez personnaliser le **libellé du compte** pour mieux identifier vos comptes (par exemple, par fonction, département, ou avec des emojis) :

1. Accédez à la section **Compte pro** 👉 **Comptes** de votre application web Qonto
2. Dans la carte de votre compte, cliquez sur les trois points en haut à droite de la boîte
3. Ensuite, cliquez sur **Renommer** et saisissez votre nouveau libellé de compte   (vous pouvez même ajouter des emojis)

***Important :** Le **nom officiel de l'entreprise** (tel qu'enregistré au registre du commerce) est utilisé par défaut pour votre compte Qonto et apparaît sur vos documents légaux. Ce nom **ne peut pas être modifié** dans l'application.*

*Le libellé que vous modifiez dans l'application est uniquement destiné à votre propre organisation/visualisation de vos comptes et n'affecte pas le nom officiel de votre entreprise.*

**Comptes courants multiples**
------------------------------

Si vous avez un forfait Smart, Premium, Essential, Business ou Enterprise, vous pouvez créer plusieurs comptes courants. Vous pourrez le nommer lors de sa création.

☝️ Bon à savoir : Le libellé que vous choisissez apparaîtra sur vos coordonnées bancaires et sur vos relevés pour une identification plus facile, mais votre **nom officiel d'entreprise** reste inchangé et continuera d'apparaître sur les documents légaux.

Pour savoir comment créer plusieurs comptes courants, vous pouvez consulter notre article [Qu'est-ce que les comptes multiples ?](https://support-fr.qonto.com/hc/fr-fr/articles/23947679356817)
