# Comment fonctionne l'offre promotionnelle de la carte X Métal ?

Qonto propose des cartes de débit Mastercard physiques et virtuelles (vous pouvez en avoir jusqu'à 5 par membre si vous le souhaitez). Ces cartes doivent être reliées à un membre de Qonto et peuvent être configurées pour répondre à ses besoins spécifiques. Paiements en ligne, paiements sans contact ou paiements avec la saisie du code PIN.

Nous lançons une **offre promotionnelle sur la carte X Métal ce mois-ci, le 3 juillet 2023** : nous vous offrons cette **carte gratuitement pendant 3 moi**s.

**Comment puis-je profiter de l'offre spéciale et obtenir une carte X Métal gratuitement durant 3 mois ?**

La carte X Métal est gratuite durant 3 mois pour chaque **nouveau client** qui ouvre un compte Qonto (quelle que soit la formule choisie).

Pour profiter de cette offre, suivez les étapes suivantes :

1. Notez le code promotionnel de l'offre : **XCARD3M**
2. Commencez le processus d'ouverture de compte sur [Qonto.com](https://welcome.qonto.com/signup/select-country)
3. Lorsque vous êtes invité à sélectionner votre forfait, cliquez sur ***Avez-vous un code promo ?*** dans le coin supérieur droit.



4. Saisissez le code de réduction : **XCARD3M** et confirmez.

*NB : il sera écrit que le code promo a été appliqué*

5. Poursuivre le processus d'inscription

6. Après la signature du contrat, commandez votre **carte X Métal**



C'est fait ! **Vous pouvez maintenant profiter de votre carte X Métal gratuitement pendant les 3 prochains mois.**

À l'issue de ces 3 mois gratuits, votre carte X vous sera automatiquement facturée au tarif standard de 20 € HT par mois.

*NB : le code promotionnel est actif immédiatement.*

👆 Cela signifie que si vous la commandez le 17/07/2023, vous ne paierez pas cette carte X du 17/07/2023 au 16/10/2023, vous paierez ensuite au prorata en octobre entre le 17/10/2023 et le 31/10/2023.

**Détails de la carte X Métal**

20 € / mois (hors taxes)

  + 60 000 € par mois **si vous n'avez pas activé votre SCA.** Nous vous conseillons vivement d'activer cette authentification forte, en suivant les étapes suivantes : [Comment associer mon téléphone à mon compte Qonto pour la première fois ?](https://support-fr.qonto.com/hc/fr/articles/23947682067985-Comment-associer-mon-t%C3%A9l%C3%A9phone-%C3%A0-mon-compte-Qonto)

* Accédez aux salons d'aéroport
* Bénéficier de l'assurance carte la plus exclusive de Qonto. [Plus d'informations ici](https://help.qonto.com/fr/articles/6845080-quelle-est-la-couverture-d-assurance-de-ma-carte)

✌️ Bon à savoir : Pour confirmer la commande d'une carte X, vous devez d'abord recharger votre compte Qonto par un simple virement bancaire. Pour savoir comment procéder, [cliquez ici](https://qonto9015.zendesk.com/hc/fr/articles/23947739917969-Comment-effectuer-un-virement-vers-mon-compte-Qonto).

**Suis-je éligible à l'offre ?**

Si je suis un nouveau client et que j'ai signé mon contrat après le **3 juillet 2023**, oui je suis éligible jusqu'au 23 juillet et dans la limite des bons restants. (2 000 bons disponibles)

​

**Une seule carte X Métal** gratuite est disponible par entreprise.

Disponible sur tous les forfaits tarifaires, du solo à l'équipe !
