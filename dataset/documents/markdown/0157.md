# Pourquoi ne puis-je pas exécuter de virements internationaux en devises étrangères ?

Voici les principales raisons qui peuvent expliquer pourquoi notre prestataire tiers n'accepte pas encore vos virements internationaux :

* Votre entreprise **[n'est pas encore validée](https://support-fr.qonto.com/hc/fr/articles/23947664661009-Mon-compte-n-est-pas-valid%C3%A9-et-mon-acc%C3%A8s-est-restreint-que-dois-je-faire)**. Lorsque le processus d'intégration sera finalisé par notre équipe, vous pourrez accéder à cette fonctionnalité.
* Votre entreprise a été **immatriculée récemment**. Ce qui veut dire que toutes les informations requises ne sont pas encore disponibles publiquement (par exemple, pour les entreprises françaises, votre code NAF/APE). Rassurez vous, nous vérifions automatiquement l'activité dans les bases de données publiques plusieurs fois par semaine, de sorte à ce que votre compte soit validé rapidement.
* Un représentant de votre entreprise a fait jouer son droit de **non publication dans les bases officielles.** Si tel est le cas, veuillez contacter notre support client afin de nous fournir les informations requises en privé. Nous mettrons alors à jour ces informations afin que vous puissiez accéder rapidement aux virements en devise étrangère.

  💡 Pour les entreprises allemandes, la fonctionnalité peut être indisponible si vous n'avez pas fournis les **informations d'immatriculation légales**. Notre équipe vérifiera si votre entreprise répond aux critères de notre prestataire tiers pour vous permettre d'effectuer des virements internationaux en devises.

Si vous ne parvenez toujours pas à effectuer des virements internationaux, veuillez contacter notre équipe de support client sur notre chat, ils traiteront votre demande et la résoudront dans les plus brefs délais.
