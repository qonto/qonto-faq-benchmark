# Kann ich mein Qonto Konto überziehen?

**Sie können Ihr Konto nicht überziehen.** Deswegen überprüfen wir immer Ihren Kontostand, bevor wir eine Zahlung autorisieren.

Sie wolle eine Kartenzahlung, Überweisung oder Lastschrift durchführen? [Bitte stellen Sie stets sicher, dass Sie über **ausreichend Guthaben** verfügen](https://support-de.qonto.com/hc/de/articles/23949246923409-Wie-kann-ich-eine-%C3%9Cberweisung-auf-mein-Qonto-Gesch%C3%A4ftskonto-vornehmen), um Ihren Zahlungsverpflichtungen nachkommen können.

Wenn wir feststellen, dass der Saldo auf Ihrem Konto zu niedrig ist, erhalten Sie eine entsprechende Benachrichtigung. Dieser Fall tritt ein, wenn Ihr aktueller Saldo Ihnen nicht erlaubt, Überweisungen oder Lastschriften, die für die nächsten 14 Tage geplant sind, umzusetzen.

**👉 Bitte beachten Sie:** Wenn Ihr Unternehmen die Voraussetzungen erfüllt, können Sie gerne unser **Pay Later** Angebot nutzen. Mehr dazu finden Sie in: [Wie nutze ich die Ratenzahlung-Funktion (Pay Later) von Qonto?](https://support-de.qonto.com/hc/de/articles/24275960254609) Alternativ finden Sie lokale Finanzierungsangebote im Bereich Finanzierung in Ihrer Qonto App.
