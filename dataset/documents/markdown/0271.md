# Comment fonctionne l'intégration Cegid Loop?

*Exportez automatiquement vos reçus et factures dans Cegid Loop : clôturer la pré-comptabilité de vos clients n’a jamais été aussi simple.*

**Comment fonctionne l’intégration ?**
--------------------------------------

Une fois par jour à 21 heures (heure de Paris), l’intégration Cegid Loop synchronise et récupère à votre place les reçus et les factures réglées ou en attente de paiement.

* Le compte Qonto de votre client sera scanné quotidiennement à la recherche de nouveaux reçus ou factures.
* Chaque nouvelle pièce justificative sera importée dans la section "Robot Comptable" de votre compte Cegid Loop.
* Cegid Loop pré-remplira les journaux comptables de vos clients.

💡 Seuls les fichiers au format JPEG, PNG et PDF seront exportés vers Cegid Loop.

**Qui peut utiliser l'intégration?**
------------------------------------

Cette intégration est disponible pour les abonnements **Smart, Premium, Essential, Business et Enterprise.**

This integration is available for **Smart**, **Premium**, **Essential**, **Business** and **Enterprise** plans.

Tous les titulaires d’un compte et les administrateurs peuvent configurer cette intégration avec Cegid Loop. Cependant, seuls les experts-comptables auront les informations nécessaires (clé API Cegid Loop) pour compléter l'installation de l'intégration.

☝️*Cette fonctionnalité est disponible pour nos forfaits **Smart**, **Premium**, ainsi que pour nos forfaits **Essential, Business et Enterprise**. [Cliquez ici](https://support-fr.qonto.com/hc/fr/articles/23947726349073-Comment-changer-mon-forfait-ou-ma-fr%C3%A9quence-de-facturation) pour apprendre comment* votre client peut passer à un forfait supérieur.

**Comment mettre en place l'intégration ?**
-------------------------------------------

Pour configurer l'intégration de Cegid Loop, vous devez vous connecter au compte Qonto de votre client. Si vous n'y avez pas encore accès, c[liquez ici](https://support-fr.qonto.com/hc/fr/articles/23947722993553-Comment-inviter-et-g%C3%A9rer-les-utilisateurs-sur-mon-compte-Qonto) pour connaître la marche à suivre pour obtenir un accès.

Depuis l’application web Qonto, cliquez sur la section **Intégrations et Partenariats** en bas à gauche, puis **Intégrations**. Utilisez la barre de recherche pour trouver l’intégration, et cliquez sur Cegid Loop. Cliquez ensuite sur **Connecter** en haut à droite de votre écran, et suivez ces quelques étapes :

* **Etape 1: Récupérez votre clé API et votre clé secrète sur CegidLife** Si vous ne l’avez pas, veuillez suivre les étapes suivantes:

  + Connectez-vous à CegidLife en tant qu’Admin
  + Cliquez sur votre profil (icône en haut à droite)
  + Sur le menu de droite, sélectionnez `Clé API`
  + Cliquez sur `🔑 Générer une clé API`
  + Sélectionnez “Loop APIKey Standard” **comme service et nommer votre nouvelle clé “Qonto”** par exemple.
  + *🔐 La clé API et la clé secrète sont affichées. Attention à bien sauvegarder ces informations car il n'est pas possible de les visualiser une seconde fois.*
* **Etape 2: Installez l’application Qonto dans Loop Hub**

  + Depuis Loop Hub, cliquez sur l’icone ➕
  + Remplissez les champs comme indiqué ci-dessous:

    - Type: `Partenaire`
    - Application: `Qonto`
    - Clé API: `[La clé API récupérée précédemment]`
  + Sélectionnez tous les fichiers clients ou bien seulement ceux pour lesquels vous avez besoin de l’application Qonto (vos clients Qonto)
* **Etape 4: Créez une nouvelle authentification** en utilisant par exemple: “[Nom de votre client] x Qonto”. Ensuite, renseignez les informations que vous avez rassemblées précédemment: clé API (identifiant et le secret).
* **Etape 5: Sélectionnez le dossier client Cegid Loop que vous souhaitez synchroniser avec ce compte Qonto**

  + Si vous ne trouvez pas le client Qonto correspondant, c'est soit parce que vous n'avez pas ajouté l'application Qonto à ce fichier client, soit parce que vous n'avez pas saisi la bonne clé API à l'étape précédente.
* Enfin, cliquez sur **Create** (créer) et sur **Finish** (terminer) pour terminer l’installation.

Votre intégration est maintenant prête ! Un fichier sera automatiquement envoyé dans votre compte Cegid Loop, l’opération peut prendre quelques minutes.

**Que faire si je ne vois pas de fichier Qonto sur Cegid Loop ?**
-----------------------------------------------------------------

Si votre client a ajouté un fichier sur Qonto après 24 heures, vous devrez configurer à nouveau l'intégration. Depuis l’application web Qonto, cliquez sur la section **Intégrations et Partenariats** en bas à gauche puis **Intégrations**. Utilisez la barre de recherche pour trouver l’intégration, et cliquez sur Cegid Loop. Cliquez ensuite sur **Connecter** en haut à droite de votre écran. De là, cliquez sur **Déconnecter** en haut à droite de la page, et cliquez à nouveau sur **Connect**.

**Que se passe-t-il si je supprime un fichier dans Qonto ou dans Cegid Loop ?**
-------------------------------------------------------------------------------

Toutes les nouvelles pièces jointes sur Qonto seront synchronisées avec Cegid Loop à 21 heures (heure de Paris). Après cette synchronisation, la suppression de pièces jointes stockées sur Qonto n'aura pas d'impact sur celles déjà synchronisées avec Cegid Loop.
