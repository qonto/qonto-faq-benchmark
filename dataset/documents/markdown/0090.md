# Comment voir ou changer mon code PIN ?

**Comment voir mon code PIN ?**
-------------------------------

Votre code PIN est accessible à tout moment depuis la section Cartes de votre application web ou mobile Qonto. Pour le trouver, rendez-vous dans la section Cartes, sélectionnez votre carte et cliquez sur “**Voir PIN**”.

💡 Si vous avez configuré l'[Authentification forte](https://support-fr.qonto.com/hc/fr/articles/23947670125329-Qu-est-ce-que-l-authentification-forte-SCA) sur votre votre compte, vous recevrez une demande de confirmation sur votre téléphone associé.

☝️ Vous avez un doute sur votre code PIN ? Allez vérifier sur votre application avant de faire d’autres essais. En effet, si vous saisissez 3 fois un mauvais code votre carte sera bloquée et vous devrez le modifier.

**Comment modifier mon code PIN ?**
-----------------------------------

Si vous avez saisi un mauvais code PIN 3 fois, vous pouvez le réinitialiser à tout moment depuis votre application.

Pour **réinitialiser votre code PIN**, voici les étapes à suivre:

**💻 Ordinateur**
================

1. Connectez-vous à votre compte Qonto et allez dans l'onglet **Compte Pro** > puis **Cartes

   **
2. Sélectionnez la carte concernée, une fenêtre s'ouvre sur la droite
3. Depuis la fenêtre située à droite de votre écran, cliquez sur **Réinitialiser PIN**.

   
4. Il vous faudra par la suite confirmer 2 fois votre nouveau code PIN 

   
   
5. Afin de finaliser son activation, il faudra effectuer un **retrait** en distributeur automatique de billets en saisissant le nouveau code PIN.

   
6. Vous n’avez pas besoin de valider le retrait, vous pouvez annuler l’opération après avoir entré votre code PIN ou désactiver l’option de retrait sur votre carte.

   ☝️ **Attention** : si vous ne vous **souvenez plus du code PIN défini lors de la commande de votre carte,** il n'est pas possible, pour des raisons de sécurité, d'en demander la réinitialisation.

**📱 Mobile**
============

1. Ouvrez l'application mobile Qonto et connectez-vous.
2. Allez dans "**Cartes**" en bas à droite.

   
3. Sélectionnez la carte concernée et descendez en bas de l'écran puis cliquez sur **Changer PIN**.

   

   
4. Il vous faudra par la suite **confirmer 2 fois votre nouveau code PIN**

   
5. Afin de finaliser son activation, il faudra effectuer **un retrait en distributeur automatique de billets** en saisissant le nouveau code PIN.

   

Vous n’avez pas besoin de valider le retrait, vous pouvez annuler l’opération après avoir entré votre code PIN ou désactiver l’option de retrait sur votre carte.

**☝️ Attention : si vous ne vous souvenez plus du code PIN défini lors de la commande de votre carte, il n'est pas possible, pour des raisons de sécurité, d'en demander la réinitialisation.**

Dans ce cas, il faudra [annuler cette carte](https://support-fr.qonto.com/hc/fr/articles/23947680825233-Comment-supprimer-une-carte) et en [commander une nouvelle](https://support-fr.qonto.com/hc/fr/articles/23947709197329-Comment-commander-une-carte-Qonto).
