# Wie tätige ich eine internationale Überweisung in JPY

* Sie können eine Überweisung in japanischen Yen über unseren Partner Wise tätigen, der es Ihnen ermöglicht, die Überweisung über das lokale Netz abzuwickeln. Es ist jedoch wichtig, dass alle Angaben zum Begünstigten genau übereinstimmen; andernfalls wird die Überweisung abgelehnt. In diesem Artikel finden Sie eine ausführliche Anleitung, wie Sie jedes Feld für einen japanischen Begünstigten korrekt ausfüllen.

Wie führe ich eine Überweisung durch?
-------------------------------------

Klicken Sie im Bereich **Geschäftskonto** auf **Überweisungen** und wählen Sie **Überweisung durchführen**.

Klicken Sie dann auf **Internationale Überweisung**, geben Sie den Betrag in Euro ein und wählen Sie die Währung JPY.

Wenn Sie auf **Fortfahren** klicken, wählen Sie unter \*\*\*\* einen Begünstigten aus und/oder erstellen Sie einen neuen.

Welche Informationen benötige ich über meinen Empfänger?
--------------------------------------------------------

Alle Angaben zu Ihrem Begünstigten müssen zu 100 % übereinstimmen. **Eine Nichtübereinstimmung führt höchstwahrscheinlich zu einer Verzögerung oder Ablehnung Ihrer Überweisung.**

* Name des Begünstigten:

**Bitte geben Sie den Namen genau so an, wie er auf dem japanischen Bankkonto des Empfängers erscheint (er wird normalerweise in カタカナ Katakana geschrieben).** Er muss mit der Namensreihenfolge im Bankbuch Ihres Kunden übereinstimmen (auf der ersten Seite des Bankbuchs).

Der Name des Kontoinhabers, den die Bank für den Kunden hat, sollte auf dieser Seite gedruckt sein, daher ist es wichtig, dass Sie den genauen Namen eingeben, der auf dieser Seite steht.

💡 Wenn der Begünstigte kein Sparbuch hat, kann er den Katakana-Namen auf der Online-Bank-Website im Bereich Kontodaten/Registrierungsdaten finden.

**Bei muttersprachlichen japanischen Begünstigten** muss der Name in japanischer \*\*Katakana-Schrift angegeben werden, und zwar in der Reihenfolge Familienname + Vorname.

**Für nicht-japanische Begünstigte** verlangen die meisten Banken japanisches Katakana, aber einige können die Namen auch in lateinischen Buchstaben schreiben.

Die Namen von **Unternehmensempfängern** werden ebenfalls in Katakana geschrieben, einschließlich der gesetzlichen Abkürzung der Unternehmensart, meist eine Version von `カ）.

* Dann wählen Sie bitte aus der vorgeschlagenen Liste aus:
  + **Bankname:** bei der Auswahl aus der Dropdown-Liste wird entweder die **katakana- oder die lateinische** Version akzeptiert
  + **Filialname:** Nach der Eingabe des Banknamens wird ebenfalls eine Liste angezeigt
  + **Kontotyp**: `Sparen/Allgemeines` (普通 フツウ Futsuu), `Sparkonto` (貯蓄 チョチク Chochiku), `Girokonto/Girokonto` (当座 トウザ Touza)
  + **Kontonummer:** eine 7-stellige Kontonummer
* Geben Sie den Grund für die Überweisung an.



**Wie lange dauert es normalerweise, bis das Geld ankommt?**

Sobald wir Ihr Geld erhalten und umgewandelt haben, dauert es 1 Arbeitstag, bis es auf dem Bankkonto des Empfängers ankommt. Die Umrechnung kann bis zu 2 Arbeitstage dauern.

Wir geben Ihnen immer eine Schätzung, wie lange Ihre Überweisung dauern wird, wenn Sie sie in der Ansicht **Ein letzter Blick** einrichten.
