# Comment fonctionne l'essai gratuit des modules complémentaires ?

Les [modules complémentaires](https://support-fr.qonto.com/hc/fr/articles/28479048690705) offrent un ensemble de fonctionnalités avancées et peuvent être souscrits en complément d'un forfait. Ils enrichissent votre compte de fonctionnalités supplémentaires pour mieux répondre aux besoins de votre entreprise.

⚠️ Aucun module complémentaire n'est inclus par défaut dans aucun forfait.

Les modules actuellement disponibles sont :

* [**Gestion des Dépenses d'Équipes**](https://support-fr.qonto.com/hc/fr/articles/35198729512337) : Disponible uniquement pour les forfaits d'équipe (Essentiel, Business, Entreprise).
* [**Gestion des Factures Fournisseurs**](https://support-fr.qonto.com/hc/fr/articles/34954360188433) : Disponible uniquement pour les forfaits d'équipe (Essentiel, Business, Entreprise).
* [**Gestion des Factures Clients**](https://support-fr.qonto.com/hc/fr/articles/34770619599377) : Disponible pour tous les forfaits.
* **[Gestion de Trésorerie](https://support-fr.qonto.com/hc/fr/articles/33992897968401) :** Disponible pour tous les forfaits.

Les modules sont disponibles pour tous les pays et peuvent être activés par les rôles Titulaires ou les Admin, selon le forfait actuel que vous avez. Certains modules sont uniquement disponibles pour les forfaits d'équipe.

Comment fonctionne l'essai gratuit ?
------------------------------------

Nous offrons un **essai gratuit d'un mois** pour tous les modules complémentaires. Voici les règles principales :

1. **L'essai gratuit est initié par le client**

* Vous devez activer l'essai gratuit vous-même.

2. **Durée et activation**

* L'essai gratuit dure un mois.
* Vous pouvez **activer plusieurs essais gratuits de modules simultanément**.
* Vous pouvez commencer un essai gratuit pour un module **même si un autre essai gratuit de module est déjà actif.**

3. **Éligibilité**

* L'essai gratuit ne peut être activé qu'après avoir complété votre essai initial du forfait Qonto.
* Il est uniquement disponible si vous n'avez jamais souscrit à ce module spécifique auparavant.

4. **Cycles de facturation**

* L'essai gratuit s'applique aux facturations mensuelles et annuelles.
* Pendant l'essai, vous pouvez changer le cycle de facturation (mensuel ou annuel) pour le module.
* Si vous activez un essai gratuit depuis une autre fonctionnalité de votre app où ce la vous est suggéré, le cycle de facturation par défaut est mensuel. Pour les utilisateurs de forfait solo, il peut être nécessaire de mettre à niveau votre forfait pour accéder à certains modules.
* **☝️ Important : Si vous ne résiliez pas le module complémentaire avant la fin de l'essai, vous serez facturé pour le module complémentaire** en même temps que votre cycle de facturation actuel.

Puis-je annuler mon essai gratuit ?
-----------------------------------

Oui, vous pouvez le faire à tout moment.

Cependant, si vous activez un essai gratuit de module complémentaire et décidez que ce n'est pas le bon moment, vous ne pourrez pas activer à nouveau l'essai gratuit pour ce même module.

Comment l'essai gratuit du module complémentaire impacte-t-il mon essai gratuit du plan Qonto ?
-----------------------------------------------------------------------------------------------

Si vous commencez un essai gratuit de module complémentaire qui nécessite une mise à niveau de votre forfait, Qonto vous offrira automatiquement un essai gratuit pour le forfait requis.

Par exemple : Pour utiliser le module **Gestion des factures fournisseurs** ou le module **Gestion des dépenses d'équipes**, vous devrez passer au forfait Essentiel ou supérieur.
