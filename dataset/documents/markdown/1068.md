# Benötigen Sie Unterstützung, um Ihren Mitarbeitern die Funktionalität vorzustellen?

Teilen Sie die folgende Nachricht mit Ihr Teammitglied weiter. 👇

**Beschleunigen Sie die Erstattung Ihrer Ausgaben.** Wenn Sie Ihre Qonto Karte nicht benutzen können, verwenden Sie Ihr eigenes Geld, um eine berufliche Ausgabe zu tätigen. Um eine Erstattung zu erhalten, reichen Sie einen Erstattungsantrag ein und verfolgen Sie den Status in Echtzeit von überall aus mit der Qonto App.

Wie wird sie verwendet?

Lesen Sie diesen [FAQ-Artikel](https://support-de.qonto.com/hc/de/articles/23949201770897-Wie-kann-ich-als-Angestellter-eine-Erstattung-f%C3%BCr-Ausgaben-erhalten-die-ich-mit-meinem-eigenen-Geld-get%C3%A4tigt-habe), um zu erfahren, wie Sie einen Spesenbericht einreichen.
