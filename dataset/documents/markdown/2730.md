# Qonto App

The Qonto App is available in the [Play Store](https://play.google.com/store/apps/details?id=eu.qonto.qonto&hl=fr&pli=1) and [App Store](https://apps.apple.com/fr/app/qonto/id1214811644).

**APK**
-------

If you'd really like to use Qonto without a Google / Apple account, you can download our Android application by **[clicking on this link.](https://qonto-mobile-app.s3.eu-west-3.amazonaws.com/public/latest/qonto-release.apk)**

To complete the download, you'll need to **access your device's Settings**. In principle, you'll need to go to **Settings > Security > Allow unknown apps** (navigation may vary from one device to another).

By downloading this application, **you will be responsible for updates**, available from the same link, to ensure its operation.

⚠️ Please note that **we do not guarantee an optimal user experience** when using this application. Its operation is optimized via the [Play Store](https://play.google.com/store/apps/details?id=eu.qonto.qonto&hl=fr) and l’[App Store](https://itunes.apple.com/fr/app/qonto/id1214811644?mt=8). We therefore advise you to use this option only as a last resort.

**Account opening**
-------------------

If you wish to register, open the account by clicking [here](https://app.qonto.com/signin).

When using your computer, choose one of the available websites for the current markets: 🇩🇪 [DE](https://support-es.qonto.com/hc/en-us/articles/23950882471697), 🇫🇷 [FR](https://support-es.qonto.com/hc/en-us/articles/23950903121937), 🇪🇸 [ES](https://support-es.qonto.com/hc/en-us/articles/23950851565329), 🇮🇹 [IT](https://support-es.qonto.com/hc/en-us/articles/23950851565329).

*It is not yet possible to proceed at your capital deposit using the application.*

If you want to know more about [Who can open an account at Qonto?](https://qonto9015-es.zendesk.com/hc/en-us/articles/23951055693329) please read the mentioned article.
