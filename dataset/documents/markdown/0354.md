# Qu'est-ce qu'une carte de domiciliation?

### Qu’est-ce qu'une carte de domiciliation?

Une carte de domiciliation permet de lier le terminal de paiement au compte bancaire d'une entreprise, notamment d'un artisan ou d'un commerçant. Elle se compose généralement de 7 chiffres et est connue sous le nom de "carte de commerçant pour TPE". Elle est requise pour la configuration du terminal de paiement (TPE).

Avec une carte de domiciliation, vous pouvez :
​

* Encaisser le paiement par carte bancaire
* Effectuer le remboursement
* Annuler la transaction

☝️ A ce jour ,Qonto ne dispose pas encore de carte de domiciliation du fait de son statut d'établissement de paiement.

C'est pour cela que nous nous sommes associés à des partenaires tels que [Zettle](https://support-fr.qonto.com/hc/fr/articles/23947669174673-Puis-je-avoir-un-Terminal-de-Paiement-%C3%89lectronique-TPE-reli%C3%A9-%C3%A0-mon-compte-Qonto), le leader européen des TPE pour les PME.
