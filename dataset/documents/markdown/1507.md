# Come posso esportare le fatture dei clienti e dei fornitori dal mio conto?

Puoi esportare tutte le fatture pagate, non pagate e annullate in pochi clic nei formati XML o formato originale (PNG, JPG o PDF). Questo ti farà risparmiare tempo e renderà più facile la gestione e la condivisione dei documenti con il tuo team e con il tuo commercialista.

​

**Chi può esportare le fatture?**
---------------------------------

Tutti i ruoli Titolari, Manager, Admin e Commercialisti possono esportare le fatture.

​

**Come posso esportare le fatture dei fornitori dalla mia app?**
----------------------------------------------------------------

Puoi esportare le fatture dei clienti o dei fornitori solo dall'app web di Qonto sul tuo desktop seguendo i passaggi indicati qui sotto 👇

1. Accedi alla sezione **Fatture**
2. Clicca su **Fatture dei fornitori** a seconda delle tue esigenze
3. Clicca sull'icona **"Esporta fatture”** nell'angolo in alto a destra dello schermo
4. Seleziona il periodo di esportazione scegliendo tra:

   * **Questo mese**, per tutte le fatture dal primo giorno del mese corrente
   * **Quest'anno**, per tutte le fatture dal primo giorno dell'anno solare corrente
   * **Periodo personalizzato**, per selezionare le fatture di date specifiche
5. Scegli il formato desiderato: formato originale (PNG, PDF o JPG) o XML
6. (Opzionale) Scegli se esportare le fatture pagate, non pagate e annullate in cartelle separate.
7. Clicca su **Esporta**

Riceverai un link via email per scaricare l'export. Il link rimarrà attivo per 7 giorni.
​

☝ I commercialisti possono esportare le fatture dalla sezione Fatture dei fornitori o dall'Hub contabilità.

**Come posso esportare le fatture dei clienti dalla mia interfaccia?**
----------------------------------------------------------------------

Puoi esportare le tue fatture selezionando preventivamente quelle specifiche tramite i filtri dedicati oppure effettuando un’esportazione completa di tutte le tue fatture.

L’esportazione delle fatture clienti è possibile solo dalla web app Qonto su desktop, seguendo questi passaggi 👇

1. Vai nella sezione **Fatture**.
2. Clicca su **Fatture Clienti**.
3. Clicca sull’icona “**Esporta Fatture**” in alto a destra nella scheda delle fatture clienti.
4. Seleziona il periodo di esportazione scegliendo tra:

* **Questo mese**, per tutte le fatture dal primo giorno del mese corrente
* **Quest’anno**, per tutte le fatture dal primo giorno dell’anno corrente
* **Periodo personalizzato**, per selezionare fatture di date specifiche

5. (Opzionale) Spunta la casella per esportare le fatture clienti in cartelle separate
6. Clicca su **Esporta**. Tieni presente che i file esportati saranno nel loro formato originale (PNG, PDF o JPG).

Riceverai quindi un link via email per scaricare l’esportazione. Il link rimarrà attivo per 7 giorni.

💡 I commercialisti possono esportare le fatture sia dalla sezione **Fatture dei clienti** sia dall’hub contabile.

Perché ricevo un messaggio di errore quando esporto le mie fatture?
-------------------------------------------------------------------

Questo può accadere se si seleziona un periodo in cui non sono state emesse fatture o se il servizio di fatturazione elettronica non è stato attivato. Prova con un altro periodo per vedere se il problema si risolve e assicurati di aver attivato la fatturazione elettronica seguendo [questi passi](https://help.qonto.com/it/articles/6340699-come-attivo-il-servizio-di-fatturazione-elettronica-su-qonto). In caso il problema persista, contatta il nostro servizio clienti.

👉 Importante: Puoi esportare le fatture emesse e ricevute **nei giorni successivi al 04/07/2024**, data in cui è stata introdotta questa funzionalità.
