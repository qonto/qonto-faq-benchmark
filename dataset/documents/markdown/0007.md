# Qu’est-ce que le module avancé de Gestion des Factures Clients ?

Tandis que notre solution de facturation standard est incluse dans toutes les formules de compte pour couvrir les besoins standards d’une entreprise, le module complémentaire de Gestion des Factures Clients offre des fonctionnalités avancées pour accompagner la croissance de votre entreprise.

Disponible pour tous les forfaits Qonto, elle est conçue pour ceux qui ont besoin de plus de flexibilité dans la création, l'automatisation et la personnalisation des documents.

**Qu'est-ce qui est inclu dans l'outil standard vs. le module ?**
-----------------------------------------------------------------

|  |  |
| --- | --- |
| **Outil de facturation standard** | **Module avancé de Gestion des Factures Clients** |
| 🖥️📱 Factures et devis illimités (en 29 devises et 6 langues) | 🖥️📱 Signatures électroniques illimitées pour les devis et pièces-jointes associées |
| 🖥️📱 Avoirs et factures d'acompte | 🖥️ Factures récurrentes |
| 🖥️📱 Personnalisation simple des documents (logo et couleurs) | 🖥️ Personnalisation avancée de la mise en page et du contenu des documents |
| 🖥️📱 Catalogue de biens et services | 🖥️📱 Modèles préenregistrés de devis et factures |
| **🖥️📱** Liste de clients  *Incluant l’auto-complétion des informations des clients professionnels grâce aux bases de données publiques* | 🖥️📱 Formatage flexible de vos documents avec sous-sections et pièces jointes |
| 🖥️📱 Relances manuelles | 🖥️📱 Relances de paiement automatisées |
| 🖥️ Import et migration de factures, clients et articles depuis un autre outil | 🖥️ Synchronisation en temps réel avec des outils externes |
| 🖥️📱 Fonctionnalités de paiement intégrées | 🖥️📱Projets |
| 🖥️📱 Association automatique des transactions |  |

À noter : Les icônes 🖥️ et 📱 indiquent si les fonctionnalités sont disponibles sur les applications web et/ou mobiles.

Et ce n'est pas tout - nous ajoutons constamment de nouvelles fonctionnalités pour vous aider à gérer votre facturation toujours plus efficacement ! 🙌

**Comment gérer mes modules ?**
-------------------------------

Vous pouvez gérer vos options depuis l'application web et mobile.

* Sur le web, allez dans **Paramètres** > **Facturation et factures** (sous Organisation) et cliquez sur l'option souhaitée.
* Sur mobile, accédez à **Menu** > **Paramètres** > **Forfait** (sous Organisation) et sélectionnez votre option.

Pour plus d'informations sur les options disponibles, consultez notre article d'aide dédié : [Quels modules sont disponibles pour compléter mon forfait ?](https://support-fr.qonto.com/hc/fr/articles/28479048690705-Quels-modules-sont-disponibles-pour-compl%C3%A9ter-mon-forfait)

**Que se passe-t-il si je supprime le module ?**
------------------------------------------------

Pas d'inquiétude ! Vous conserverez l’accès à toutes les fonctionnalités standards de l’outil de facturation mentionnées ci-dessus.

En revanche, vous perdrez l’accès aux fonctionnalités avancées : par exemple, vos factures récurrentes seront mises en pause et vos brouillons ainsi que les futurs documents reviendront au format standard.

Bien que vous puissiez supprimer l'option à tout moment, que ce soit avec la facturation mensuelle ou annuelle, vous perdrez immédiatement accès aux fonctionnalités avancées du module et aucun remboursement ne sera possible pour la période restante.

Besoin d'aide pour démarrer ? Notre équipe d'assistance est disponible via le chat directement depuis votre application Qonto !
