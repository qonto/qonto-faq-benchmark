# Wie kann ich einen Nachweis für eine internationale Überweisung herunterladen?

Es ist möglich, einen Überweisungsnachweis direkt über Ihre Qonto-Oberfläche herunterzuladen, zum Beispiel wenn ein Dritter einen Nachweis anfordert.

☝️ Gut zu wissen: Das Herunterladen eines Überweisungsnachweises steht **Kontoinhabern, Administratoren und Managern** mit [den entsprechenden Berechtigungen](https://support-de.qonto.com/hc/de/articles/23949229714705-Wozu-sind-Personen-mit-Managerrolle-befugt) zur Verfügung.

Manager ohne Berechtigungen oder Mitarbeiter können keine Überweisungsnachweise herunterladen. Sie müssen sich an einen Administrator oder den Inhaber wenden.

Von Ihrer Web-App 💻 aus:

1. Gehen Sie zum Reiter Geschäftskonto
2. Dann zum Reiter Transaktionen
3. Wählen Sie die Überweisung aus
4. Klicken Sie auf Zahlungsnachweis herunterladen

Von Ihrer mobilen App 📱 aus:

1. Gehen Sie zum Bereich Transaktionen
2. Wählen Sie die Überweisung aus
3. Klicken Sie auf Zahlungsnachweis herunterladen

☝️ Gut zu wissen: Dieses Dokument kann nur heruntergeladen werden, **wenn die Überweisung ausgeführt wurde** (es kann nach Abschluss der Überweisung zu einer Verzögerung kommen, bis der Zahlungsnachweis aufgrund von Zwischenbanken und Zahlungspartnern zur Verfügung steht).
