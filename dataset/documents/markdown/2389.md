# ¿Qué aplicaciones puedo conectar a mi cuenta Qonto?

Gracias a [este enlace](https://qonto.com/es/connect), te mostramos una lista de aplicaciones que puedes conectar a Qonto, el modo de instalación de la integración, y más información sobre los datos que será posible sincronizar.

👉 Es bueno saberlo: El modo de instalación y los datos que puedes sincronizar dependen de cada integración.

¿Cómo conectar una aplicación con Qonto?
----------------------------------------

Consulta la [siguiente tabla](https://qonto.notion.site/06f32797e0b64860949cada860f9f67c?v=b28110a08bc64ef3bc452cd368bec076) para conocer el tipo de conexión para cada aplicación y obtener más información.

A continuación, sigue los siguientes pasos para conectar tu herramienta a Qonto.

**Conexión a tu aplicación desde Qonto:**

1. Desde la aplicación web Qonto, haz clic en el icono de ajustes.
2. Haz clic en **Integraciones y partners** y después en **Integraciones**.
3. Busca la integración que deseas instalar y selecciónala. A continuación, haz clic en **Conectar** en la parte superior derecha de la página.
4. Por último, sigue las instrucciones para terminar de instalar la integración.

**Conexión directamente en la aplicación con tus credenciales Qonto:**

* La integración se hará directamente desde la aplicación que deseas conectar a Qonto: necesitarás tus credenciales Qonto para instalar la integración.

**Conexión a Qonto con tu clave API Qonto:**

1. Desde la aplicación web Qonto, haz clic en el icono de ajustes.
2. Haz clic en **Integraciones y partners** y después en **Clave API**
3. Indica la clave API directamente desde la aplicación que deseas conectar a Qonto.

👉 Es bueno saberlo: Para más información sobre la clave API, consulta [el siguiente artículo](https://support-es.qonto.com/hc/es/articles/23951013753361--D%C3%B3nde-puedo-encontrar-mi-acceso-y-mi-clave-secreta-API).

¿Qué hacer si una integración no está disponible?
-------------------------------------------------

Puedes sugerirnos una nueva integración directamente desde la aplicación web Qonto:

1. Desde la aplicación web Qonto, haz clic en el icono de ajustes.
2. Haz clic en **Integraciones y partners** y después en **Integraciones**.
3. Haz clic en la parte inferior derecha de la página para sugerir otra integración.

   También puedes utilizar [Zapier](https://support-es.qonto.com/hc/es/articles/23951011058577--C%C3%B3mo-funciona-la-integraci%C3%B3n-de-Zapier-y-Qonto) y [Make](https://support-es.qonto.com/hc/es/articles/23951010971153-C%C3%B3mo-funciona-la-integraci%C3%B3n-de-Make-ex-Integromat-y-Qonto) (antiguamente Integromat) para automatizar algunas tareas manuales o conectar tu cuenta Qonto a otras herramientas.
