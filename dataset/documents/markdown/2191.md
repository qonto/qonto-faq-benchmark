# ¿Qué es Qonto Operator?

Una herramienta impulsada por IA que recopila automáticamente facturas de proveedores escaneando tus transacciones para identificar proveedores, luego recupera facturas de sus portales y las asocia a las transacciones en Qonto.

Esta funcionalidad se encuentra actualmente en fase Beta.

¿Qué planes y roles tienen acceso a esta funcionalidad?
-------------------------------------------------------

Disponible para todos los mercados y para todos los planes.

Solo los roles de Owner y Admin pueden usar la funcionalidad.

¿Cómo funciona el proceso de recopilación de facturas?
------------------------------------------------------

1. Inicia la integración y Qonto Operator escanea tus transacciones para identificar proveedores
2. Inicia sesión en tus portales de proveedores una sola vez
3. Nuestro agente de IA encuentra y descarga automáticamente las facturas
4. Las facturas se importan a Qonto y se asocian a las transacciones

¿Están seguros mis datos al usar esta funcionalidad?
----------------------------------------------------

Sí. Qonto comparte de forma segura solo los datos de transacciones recientes con nuestro partner Twin.so para identificar proveedores.

Los datos de las transacciones no se almacenan a largo plazo fuera de Qonto y solo se utilizan para la identificación de proveedores.

¿Cuáles son los principales beneficios?
---------------------------------------

* Ahorra tiempo importando facturas de proveedores con solo unos clics
* Asociación automática de facturas a transacciones
* Gestión centralizada de facturas
* Contabilidad e informes más rápidos

¿Qué es la fase Beta?
---------------------

La fase Beta es el período inicial de prueba donde el Agente de IA se está implementando a un número limitado de clientes para garantizar la calidad y recopilar comentarios antes de su lanzamiento completo.
Los clientes en el programa Beta obtienen acceso anticipado a esta nueva funcionalidad en Qonto con fines de prueba.
