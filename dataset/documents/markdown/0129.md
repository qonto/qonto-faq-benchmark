# Où puis-je trouver mes factures Qonto ?

La facturation de Qonto est basée sur une période calendaire mensuelle ou annuelle et les factures sont **générées le premier jour de chaque mois**. Les factures ne seront pas générées pour les mois où le montant total est égal à 0.

Les factures Qonto sont des factures mensuelles qui affichent les frais d'abonnement ainsi que tous les frais supplémentaires facturés entre le premier et le dernier jour de chaque mois.

**Les frais d’abonnement annuel** apparaitront sur la facture qui correspond au mois au cours duquel le frais a été facturé.

**Par exemple :** si je bascule mon abonnement sur une facturation annuelle le 15 juillet, le frais annuel sera facturé le jour même dès que je valide mon changement. Ce frais apparaîtra sur ma facture mensuelle de juillet, disponible le 1er août.

Pour une meilleure visibilité, vous pouvez récupérer vos factures Qonto à tout moment depuis notre interface web.

Pour ce faire, vous avez deux options :

**Depuis la section des factures**
==================================

1. Allez dans la section **Paramètres** de votre interface web de Qonto en bas à gauche de votre écran.
2. Ensuite, allez dans **Forfait et factures**.
3. Cliquez sur la section **Factures Qonto**.
4. Sélectionnez les factures que vous souhaitez télécharger. 🎉



☝️ Bon à savoir : Vous pouvez sélectionner et télécharger en masse autant de factures que nécessaire. Un fichier compressé (.zip) sera automatiquement envoyé à votre adresse e-mail, contenant toutes les factures sélectionnées en PDF. Cet email peut être transmis à votre comptable ou à toute personne de votre choix.

**Depuis la section Transactions**
==================================

1. Cliquez sur la transaction de votre choix dans la section **Compte Pro** > **Transactions**.
2. Cliquez ensuite sur **Facture**.
3. Vous trouverez votre facture en pièce jointe. 🎉

💡 Vous souhaitez retrouver la facture du paiement de votre Dépôt de capital ? Nous vous l’avons envoyé dans le mail intitulé *Votre facture Qonto*, le jour de votre paiement.
