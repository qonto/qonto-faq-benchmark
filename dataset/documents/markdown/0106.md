# Comment modifier mon numéro de téléphone ?

Vous pouvez modifier votre numéro de téléphone à tout moment en accédant à votre application Qonto **depuis votre ordinateur ou depuis votre application mobile**. Pour confirmer cette mise à jour, nous devons vérifier votre identité.

### **J'ai accès à mon compte et je souhaite changer mon numéro de téléphone, que dois-je faire ?**

**Depuis un ordinateur**

1. Connectez-vous à votre compte Qonto
2. Allez dans **Paramètres** en bas à gauche et cliquez sur **Paramètres personnels > Profil personnel.**
3. Cliquez sur le bouton **Modifier** - sous votre ancien numéro de téléphone
4. Saisissez votre nouveau numéro de téléphone
5. Saisissez le code de confirmation envoyé sur le nouveau numéro de téléphone
   * Si vous avez configuré l'[Authentification Forte du Client](https://support-fr.qonto.com/hc/en-us/articles/23947670125329), vous recevrez une demande de confirmation sur votre téléphone associé.
   * Si vous n'avez pas encore configuré l'Authentification Forte du Client, vous pouvez choisir de recevoir le code de confirmation sur votre ancien numéro ou par email. Saisissez le code de confirmation envoyé à votre ancien numéro de téléphone ou à votre email.
6. Votre numéro de téléphone est modifié !

**Depuis l'application mobile**

1. Connectez-vous à votre compte Qonto
2. Allez dans l'onglet **Menu** de votre application, cliquez sur ⚙️ puis cliquez sur votre photo de profil
3. Cliquez sur le crayon à droite du numéro de téléphone
4. Saisissez votre nouveau numéro de téléphone
5. Saisissez le code de confirmation envoyé sur le nouveau numéro de téléphone

   * Si vous avez configuré l'[Authentification Forte](https://support-fr.qonto.com/hc/fr/articles/23947670125329-Qu-est-ce-que-l-authentification-forte-SCA), vous recevrez une demande de confirmation sur votre téléphone associé
   * Si vous n'avez pas encore configuré l'Authentification Forte du Client, saisissez le code de confirmation envoyé à votre ancien numéro de téléphone
6. Votre numéro de téléphone est modifié !

### **Vous ne pouvez pas modifier votre numéro de téléphone ou un message d'erreur s'affiche ?**

Contactez-nous, nous serons ravis de vous aider ! 
Tout d'abord, nous devrons vérifier votre identité pour assurer la sécurité de votre compte. Pour cela, vous pouvez nous envoyer les éléments suivants par chat ou par email :

* Un **selfie**, avec votre pièce d'identité en main près de votre visage, et une feuille blanche avec la date du jour et le mot **QONTO** écrit à la main.

  
* Les informations suivantes :

  1. Nom de l'entreprise
  2. SIREN
  3. Nom de famille
  4. Prénom
  5. Nouveau numéro de téléphone

### **Pourquoi est-il important de maintenir votre numéro de téléphone à jour ?**

Il existe **trois cas** pour lesquels votre numéro de téléphone est nécessaire :

* Il nous permet de **vous contacter rapidement** si nous **suspectons une utilisation frauduleuse** de votre compte
* Il sera demandé pour **configurer la [vérification 2FA](https://support-fr.qonto.com/hc/fr/articles/23947714708881-Qu-est-ce-que-la-validation-en-deux-%C3%A9tapes-2FA)**.
* Il **rend possible le [protocole 3-D Secure](https://support-fr.qonto.com/hc/fr/articles/23947671680529-Qu-est-ce-que-le-3D-Secure)** (c'est-à-dire l'envoi d'un code de confirmation pour les achats en ligne).

Assurez-vous de maintenir vos coordonnées à jour dans votre profil utilisateur afin que nous puissions rester en contact. 🙌
