# Puis-je importer une liste de bénéficiaires pour effectuer un virement groupé ?

Qonto permet d'importer une liste de bénéficiaires (jusqu'à 400 à la fois) ce qui est particulièrement pratique si vous décidez de changer de banque et que vous n'avez pas envie de tout migrer à la main.

**Comment ça marche ?**
=======================

1. Téléchargez le fichier CSV suivant : [qonto\_import\_beneficiaries\_empty.csv](https://qonto-assets.s3.amazonaws.com/intercom_faq/import%20beneficiaries.csv)
2. Remplissez le fichier CSV en utilisant Excel ou un autre éditeur de CSV.
3. Ouvrez le fichier dans l'application Qonto
4. Rendez-vous sur l’onglet **Compte pro** de votre espace Qonto
5. Accédez à la section **Virements**
6. Cliquez sur l'icône noire **+ Effectuer un virement** dans le coin supérieur droit de votre écran
7. Accédez à **Virements SEPA groupés en euros**
8. Pour ajouter plusieurs bénéficiaires à la fois, importez un fichier .CSV
9. Vérifiez les données importées et validez

   ⚠️ Une erreur s'affiche au téléchargement de mon fichier.
   =========================================================

   Que faire ?
   ===========

   Le fichier doit obligatoirement contenir les 3 colonnes suivantes :

   (Veuillez noter que le fichier est en anglais, le nom des colonnes ne doit pas être modifié ou traduit)
   ​

   * NAME
   * IBAN
   * EMAIL

**Chaque ligne doit contenir une valeur pour NAME et IBAN. Il est cependant optionnel d'inclure une valeur pour la colonne EMAIL.**

La valeur IBAN doit correspondre à un certain format. En cas d'erreur, l'écran de confirmation mettra en évidence les bénéficiaires pour lesquels ces informations doivent être corrigées.

Une fois les informations corrigées, vous pourrez valider l'import de votre liste de bénéficiaires.

*NB : l'import de bénéficiaires dont le compte n'est pas un compte SEPA n'est pour le moment pas possible.*
