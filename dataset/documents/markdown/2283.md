# ¿Cómo funciona la oferta promocional Tarjeta-X?

Qonto proporciona tarjetas de débito Mastercard físicas y virtuales ([puedes tener hasta 5 de cada si lo deseas](https://support-es.qonto.com/hc/es/articles/23951037384593--Cu%C3%A1ntas-tarjetas-puedo-tener-con-mi-cuenta-Qonto)). Estas tarjetas deben estar vinculadas a un usuario real de Qonto y pueden configurarse para satisfacer tus necesidades específicas. Pagos online, pagos contactless o pagos con introducción de código PIN.

**El día 3 de julio de 2023, lanzamos una oferta promocional** sobre la tarjeta X: ofrecemos la **tarjeta X gratis durante 3 meses.**

**¿Cómo puedo disfrutar de la oferta especial y conseguir una tarjeta X metálica gratis durante 3 meses?**

La Tarjeta X metálica es gratuita durante 3 meses para cada nuevo cliente que abra una cuenta Qonto (sea cual sea el plan que elija).

Para aprovechar esta oferta, sigue estos pasos:

1. Copia el código de oferta: **XCARD3M**
2. [Inicia el proceso de apertura](https://welcome.qonto.com/signup/select-country) de cuenta en [Qonto.com](https://qonto.com/es?q_campaign=fr_search_brand_en&q_content=brand_exact_en&gclid=CjwKCAjw9qiTBhBbEiwAp-GE0cYqPII8lg80UPFoRy9McuuvSvXfhgxI1Zz1ySM1qYT5SFxEcZk8ixoCO9kQAvD_BwE)
3. Cuando se te pida que selecciones tu plan, haz clic en ¿Tienes un código promocional? en la esquina superior derecha.



**4. Introduce el código de descuento: XCARD3M y confirma.**

*💡 aparecerá que el código promocional se ha aplicado correctamente*

5. Continuar el proceso de registro

6. Una vez firmado el contrato, **solicita su tarjeta Metal X**



7**. ¡Listo! Ya puedes disfrutar de tu Tarjeta Metal X gratis durante los próximos 3 meses.**Al final de los 3 meses gratuitos, se te facturará automáticamente tu Tarjeta X con la tarifa estándar de 20 euros al mes, impuestos no incluidos.

*💡 El voucher se activa inmediatamente.*

👆 Esto significa que si la usas el 17/07/2023, no pagarás esta tarjeta X desde el 17/07/2023 hasta el 16/10/2023, luego pagarás lo prorrateado en octubre entre el 17/10/2023 y el 31/10/2023.
