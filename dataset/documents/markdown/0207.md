# Comment supprimer une carte ?

**Comment supprimer une carte physique?**
-----------------------------------------

Vous avez abîmé votre carte, vous souhaitez passer à [une autre gamme](https://qonto.com/fr/payment-methods/card) ou encore désactiver celle d'un collaborateur ?
​

Vous pouvez à tout moment supprimer une carte physique. Pour l’opposer, il faut modifier son statut en le passant comme “**perdue/volée**” depuis votre interface (même si vous avez toujours cette carte en votre possession).

* Pour être guidé sur votre application, rendez-vous par ici si **elle est perdue**: [https://app.qonto.com?tdm=report-lost-card](https://app.qonto.com/?tdm=report-lost-card)
* Pour être guidé sur votre application, rendez-vous par ici si **elle est volée**: [https://app.qonto.com?tdm=report-stolen-card](https://app.qonto.com/?tdm=report-stolen-card)

Pour ce faire :

1. Depuis la section **‘Compte Pro’**, cliquez sur **‘Cartes’**
2. Sélectionnez la carte concernée puis cliquez sur **Déclarer Perte/Vol** , en bas à droite.
3. Sélectionnez ensuite l’option **Déclarer perdue**.
4. Enfin, confirmez l'action via l'authentification forte sur votre téléphone ([plus d'informations ici](https://support-fr.qonto.com/hc/fr/articles/23947670125329-Qu-est-ce-que-l-authentification-forte-SCA)).

☝️ **Bon à savoir** : Cette action est irréversible et bloquera définitivement votre carte. Vérifiez donc bien vos dernières transactions afin de vous assurer qu’aucune opération frauduleuse n’a eu lieu. Cela stoppera également les frais liés à votre carte s'ils existent.
​

**Comment supprimer une carte virtuelle ?**
-------------------------------------------

Vous n'avez plus l'utilité de votre carte virtuelle ou de votre carte de publicité en ligne et vous souhaitez la supprimer ?

C'est très simple !

1. Depuis la section **‘Compte Pro’**, cliquez sur **‘Cartes’**
2. Sélectionnez la carte virtuelle que vous voulez supprimer.
3. Cliquez sur "**Supprimer la carte"**
4. Enfin, confirmez l'action via l'authentification forte sur votre téléphone ([plus d'informations ici](https://support-fr.qonto.com/hc/fr/articles/23947670125329-Qu-est-ce-que-l-authentification-forte-SCA)).

Si la carte est bloquée, il faut tout d'abord la débloquer pour ensuite pouvoir la supprimer.

Veuillez noter que cette action est irréversible et qu'il ne vous sera pas possible de réactiver cette carte par la suite. Cela stoppera également les frais liés à la carte s'ils existent.



La carte éphémère\* expire à la date choisie initialement.
