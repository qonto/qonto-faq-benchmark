# ¿Cómo obtener una prueba gratuita de un mes de los módulos de Qonto?

[Los módulos](https://support-es.qonto.com/hc/es/articles/28509717293713--Qu%C3%A9-m%C3%B3dulos-hay-disponibles-para-complementar-mi-plan) ofrecen un conjunto de funciones avanzadas y pueden suscribirse a un plan de precios. Mejoran tu cuenta con funcionalidades adicionales para adaptarse mejor a las necesidades de tu empresa.

⚠️ Ninguna subscripción incluye módulos por defecto.

Los módulos adicionales disponibles actualmente son:

* **[Módulo de gestión de facturas de proveedores](https://support-es.qonto.com/hc/es/articles/34997607275921-M%C3%B3dulo-de-gesti%C3%B3n-de-facturas-de-proveedores):** Disponible solo para planes de Equipo (Essential, Business, Enterprise).
* **[Módulo de gestión de gastos](https://support-es.qonto.com/hc/es/articles/34964810934545--Qu%C3%A9-es-el-M%C3%B3dulo-de-gesti%C3%B3n-de-gastos):** Disponible solo para planes de Equipo (Essential, Business, Enterprise).
* [**Módulo de gestión de facturas a clientes**:](https://support-es.qonto.com/hc/es/articles/34793938978321--Qu%C3%A9-es-el-M%C3%B3dulo-de-gesti%C3%B3n-de-facturas-a-clientes) Disponible para todos los planes.
* **[Módulo de flujo de caja](https://support-es.qonto.com/hc/es/articles/33980930450705--Qu%C3%A9-es-exactamente-la-gesti%C3%B3n-de-tesorer%C3%ADa-en-Qonto-y-c%C3%B3mo-puede-ayudar-a-mi-empresa):** Disponible para todos los planes

Los módulos adicionales están disponibles para todos los países y pueden ser activados por los titulares o administradores, dependiendo del plan de precios que tenga. [Algunos módulos están disponibles solo para subscripciones de Equipo.](https://qonto.com/es/pricing?periodicity=yearly&select-toggle=team&website_addon_period=yearly&_gl=1*c77ur5*_up*MQ..&gclid=Cj0KCQiArt6PBhCoARIsAMF5wag449wvTWudsTjGZWDIcmVGzR7GZwJ0WEPb5v2qQih78yKaplk8rF4aAgfDEALw_wcB)

¿Cómo funciona?
---------------

Ofrecemos un mes de prueba gratuita para todos los módulos adicionales. Estas son las reglas principales:

1. **La prueba gratuita la inicia el cliente**
   * Debes activar tú mismo la prueba gratuita.
2. **Duración y activación**
   * La prueba gratuita dura un mes.
   * Puedes activar varias pruebas gratuitas de complementos simultáneamente.
   * Puedes iniciar una prueba gratuita de un complemento aunque ya esté activa la prueba gratuita de otro complemento.
3. **Elegibilidad**
   * La prueba gratuita solo puede ser activada después de completar tu prueba inicial del plan Qonto.
   * Solo está disponible si nunca antes te has suscrito a ese módulo específico.
4. **Ciclos de facturación**
   * La prueba gratuita se aplica tanto a la facturación mensual como a la anual.
   * Durante la prueba, puede cambiar el ciclo de facturación (mensual o anual) del módulo.
   * Si activas una prueba gratuita a través de un punto de entrada de upsell, el ciclo de facturación por defecto es mensual. Para los usuarios de planes individuales, puede ser necesario actualizar el plan para acceder a determinados módulos.
   * Si no cancelas el módulo antes de que finalice la prueba, se le facturará el complemento junto con su ciclo de facturación actual.

¿Puedo cancelar la prueba gratuita?
-----------------------------------

Sí, puede hacerlo en cualquier momento. Sin embargo, si activas la prueba de un módulo y decides que no es el momento adecuado, no podrás volver a activar la prueba gratuita de ese módulo.

¿Cómo afecta la prueba gratuita del módulo adicional a mi prueba gratuita del plan Qonto?
-----------------------------------------------------------------------------------------

Si inicias una prueba gratuita de un módulo adicional que requiere una actualización del plan, Qonto te ofrecerá automáticamente una prueba gratuita del plan requerido.

Por ejemplo: para usar el **Módulo de gestión de gastos** o **Módulo de gestión de facturas de proveedores**, tendrás que pasar al plan Essential o superior.
