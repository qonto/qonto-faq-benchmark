# Wie kann ich eine Überweisung in Euro (SEPA) vornehmen?

Es gibt nichts Einfacheres als eine Überweisung zu tätigen!

Sie können eine Überweisung direkt über Ihre Web- oder Mobile-App durchführen.
Mit Qonto können Sie SEPA-Echtzeitüberweisungen initiieren! Wie? Folgen Sie einfach den untenstehenden Schritten👇

👆**Gut zu wissen:** Einmalige, geplante und wiederkehrende Überweisungen sind standardmäßig als Echtzeitüberweisungen konfiguriert, Sie können jedoch auch diese Einstellung deaktivieren und eine klassische Überweisung (erhältlich innerhalb von 48 Arbeitsstunden) im Schritt *Ein letzter Blick* des Ablaufs durchführen.

**💻 In Ihrer Web-App:**
-----------------------

* Gehen Sie zum Bereich **Geschäftskonto**
* Gehen Sie zum Bereich **Überweisungen**
* Klicken Sie auf das schwarze **+ Symbol** in der oberen rechten Ecke Ihres Bildschirms

  Sie haben 2 Möglichkeiten:
  --------------------------

  1 - Eine Rechnung hochladen
  ---------------------------

  Wenn Sie eine Rechnung haben, laden Sie sie jetzt hoch!

  + Das System sammelt Informationen auf der Rechnung, wann immer es möglich ist (Begünstigter / IBAN, Betrag, Verwendungszweck),
  + Sie können jedes Feld ändern, das Konto belasten, eine Wiederholung planen, Benachrichtigungen an den Begünstigten senden und Buchhaltungsdetails hinzufügen.

  2 - Ich habe keine Rechnung / Überweisungsdetails hinzufügen
  ------------------------------------------------------------

  Wenn Sie keine Rechnung haben, folgen Sie diesen Schritten:

  + Klicken Sie auf **Überweisungsdetails hinzufügen**
  + Klicken Sie auf **SEPA-Überweisung in Euro**
  + Wählen Sie das Konto, das belastet werden soll
  + Wählen Sie einen Empfänger ODER fügen Sie einen neuen Empfänger hinzu: den vollständigen Namen, wie er auf der Bankbestätigung steht (Nachname, Vorname, Firmenname)

    Der neue Empfänger wird automatisch gespeichert
  + Geben Sie den **Betrag** und den **Verwendungszweck** der Überweisung ein (Möglichkeit, bis zu 135 Zeichen im Verwendungszweck-Feld zu speichern).
  + **Programmierung und Wiederholung:** Möglichkeit, das Datum festzulegen, an dem die Überweisung ausgeführt wird, oder eine Wiederholung festzulegen, indem Sie **Überweisungswiederholung** auswählen
  + **Zusätzliche Informationen (alles optional):** Möglichkeit, einen Anhang zur Überweisung hinzuzufügen, die Mehrwertsteuer und das Analyseetikett auszuwählen. Sie können auch \*\*Benachrichtigen Sie den Empfänger (\*\*Möglichkeit, eine automatische E-Mail an den Empfänger mit den Details der getätigten Überweisung zu senden) auswählen
  + **Ein letzter Blick:** Sie können die Informationen der Überweisung vor der Bestätigung überprüfen

  Sie werden gebeten, die Operation mit Ihrem Mobiltelefon zu bestätigen.

**📲 In Ihrer mobilen App:**
---------------------------

* Gehen Sie zum **Menü >** **Überweisungen**
* Klicken Sie auf das schwarze **+ Symbol** in der oberen rechten Ecke Ihres Bildschirms

Sie haben 2 Möglichkeiten:
--------------------------

### 1 - Eine Rechnung hochladen (demnächst auch in unseren mobilen Apps verfügbar)

Wenn Sie eine Rechnung haben, laden Sie sie jetzt hoch!

* Das System sammelt Informationen auf der Rechnung, wann immer es möglich ist (Empfänger / IBAN, Betrag, Verwendungszweck),
* Sie können jedes Feld ändern, das Konto belasten, eine Wiederholung planen, Benachrichtigungen an den Empfänger senden und Buchhaltungsdetails hinzufügen.

So gehen Sie vor:

* + Klicken Sie auf **Rechnung hinzufügen**
  + Machen Sie ein Foto von der Rechnung oder laden Sie sie von Ihrem Smartphone hoch
  + Wählen Sie das **Konto, das belastet werden soll**, wählen Sie einen **Empfänger** ODER fügen Sie einen **neuen Empfänger** hinzu: den vollständigen Namen, wie er auf der Bankbestätigung steht (Nachname, Vorname, Firmenname). Der neue Empfänger wird automatisch gespeichert.

    - Fügen Sie einen **Verwendungszweck** hinzu (für den Empfänger sichtbar).
    - **Programmierung und Wiederholung:** Möglichkeit das Datum festzulegen, an dem die Überweisung ausgeführt wird, oder eine Wiederholung festzulegen, indem Sie **Überweisungswiederholung.** auswählen
  + Sie können weitere **Anhang** hinzufügen, die **Mehrwertsteuer** und das **Analyseetikett** auswählen, falls erforderlich (optional)

    - Sie können auch \*\*Benachrichtigen Sie den Begünstigten (\*\*Möglichkeit eine automatische E-Mail an den Begünstigten mit den Details der Überweisung zu senden) auswählen
    - **Ein letzter Blick:** Sie können die Informationen der Überweisung vor der Bestätigung doppelt prüfen

    Sie werden gebeten, die Operation mit Ihrem Mobiltelefon zu bestätigen.

### 2- Ich habe keine Rechnung / Überweisungsdetails hinzufügen

Wenn Sie keine Rechnung haben, folgen Sie diesen Schritten:

* Klicken Sie auf **Überweisungsdetails hinzufügen**
* Klicken Sie auf **SEPA-Überweisung in Euro**
* Wählen Sie das Konto, das belastet werden soll
* Wählen Sie einen Empfänger ODER fügen Sie einen neuen Empfänger hinzu: den vollständigen Namen, wie er auf der Bankbestätigung steht (Nachname, Vorname, Firmenname)

  Der neue Empfänger wird automatisch gespeichert
* Geben Sie den **Betrag** und den **Verwendungszweck** der Überweisung ein (Möglichkeit, bis zu 135 Zeichen im Verwendungszweck-Feld zu speichern).
* **Programmierung und Wiederholung:** Möglichkeit, das Datum festzulegen, an dem die Überweisung ausgeführt wird, oder eine Wiederholung festzulegen (wenn Sie zum Beispiel einen Dauerauftrag einrichten möchten), indem Sie **Überweisungswiederholung** auswählen
* **Zusätzliche Informationen (alles optional):** Möglichkeit einen Anhang zur Überweisung hinzuzufügen, die Mehrwertsteuer und das Analyseetikett auszuwählen. Sie können auch \*\*Benachrichtigen Sie den Empfänger (\*\*Möglichkeit eine automatische E-Mail an den Empfänger mit den Details der Überweisung zu senden) auswählen
* **Ein letzter Blick:** Sie können die Informationen der Überweisung vor der Bestätigung überprüfen

☝️ **Gut zu wissen** : Sie müssen keinen neuen Empfänger validieren, bevor Sie eine neue Überweisung initiieren.

Um Zeit zu sparen, können Sie Ihren Mehrwertsteuersatz und das zugehörige Analyseetikett für jeden einzelnen Empfänger festlegen, indem Sie auf **Buchhaltung,** dann **Lieferanten** klicken. Sobald dies erledigt ist, müssen Sie nicht mehr darüber nachdenken! Sie finden bereits ausgefüllte, dedizierte Felder mit den Informationen, wenn Sie eine neue Überweisung erstellen, während Sie sie durchführen.

Manager können Überweisungen gemäß ihren Berechtigungen durchführen, innerhalb der von dem Administrator oder dem Kontoinhaber festgelegten Grenzen.

**Überweisungen zwischen Qonto-Konten werden nicht von Ihrem Plan abgezogen und sofort gutgeschrieben!** Alles, was Sie tun müssen, ist, das gleiche Verfahren wie bei einer herkömmlichen Überweisung zu befolgen, indem Sie die Bankkontodaten (IBAN) Ihres Empfängers ausfüllen.
​
Derzeit können Sie **keine** sofortige SEPA-Überweisung für geplante, angeforderte, wiederkehrende und Sammelüberweisungen initiieren.

Wenn Ihre Überweisung größer als 100.000 € ist oder Ihr Empfänger nicht über SEPA Echtzeitüberweisungen erreicht werden kann, wird sie automatisch als Standardüberweisung durchgeführt.

Wenn Sie eine Überweisung auf ein geschlossenes Konto vornehmen, müssen Sie den Empfänger kontaktieren, damit seine Bank die Rückgabe der Gelder auf Ihr Qonto-Konto bestätigen kann (die Gelder sollten automatisch zurückgegeben werden).

☝️ **Tipps**:

Um Zeit bei Ihren SEPA-Überweisungen zu sparen, verwenden Sie den Link [qonto.new](https://qonto.new/) in der Suchleiste Ihres Webbrowsers. Sie werden direkt zur SEPA-Überweisungsseite weitergeleitet.

Sie können auch den Bereich Lieferantenrechnung für Ihre Überweisungen verwenden und vermeiden, alle Überweisungsdetails manuell auszufüllen.

🔁 Sie können jetzt einige Überweisungen, die Sie bereits getätigt haben, erneut initiieren, ohne sie erneut erstellen zu müssen! 🤩

Klicken Sie auf die Überweisung, die Sie im Tab "**Transaktion**" wiederholen möchten, und auf der rechten Seite sehen Sie die Schaltfläche **Überweisung wiederholen**.

Sie können einige Überweisungsdetails bearbeiten und dann validieren.

💡 Wenn Sie [Starke Kundenauthentifizierung](https://support-fr.qonto.com/hc/en-us/articles/23947670125329) auf Ihrem Konto eingerichtet haben, erhalten Sie eine Bestätigungsanfrage auf Ihrem zugehörigen Telefon.

**⏱ Mit dem neuen iOS-Widget :**
--------------------------------

Für diejenigen, die schneller und schneller werden möchten, entdecken Sie unser neues iOS Qonto Mobile-Widget.

💡 *Ein Widget ist ein kleines Modul, das Sie zur Startseite Ihres Telefons hinzufügen können, sodass Sie Ihre Anwendungen schneller steuern oder auf Informationen zugreifen können.*

Wie fügen Sie das Widget zu Ihrem Startbildschirm hinzu?

* Drücken Sie auf Ihrem iPhone-Startbildschirm lange auf eine beliebige Anwendung und klicken Sie dann auf Startbildschirm bearbeiten;
* Klicken Sie auf die + Schaltfläche in der oberen linken Ecke, und das Widget-Menü wird angezeigt.
