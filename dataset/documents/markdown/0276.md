# Pourquoi ma carte a-t-elle été bloquée?

**Vous avez bloqué la carte suite à 3 code PIN faux**
-----------------------------------------------------

Si vous avez saisi 3 mauvais PIN lors d’un retrait ou d’un paiement avec insertion de votre carte dans un terminal de paiement (TPE), le statut de votre carte devient “PIN bloqué”.

Vous devrez suivre la procédure de modification de votre code PIN [juste ici.](https://support-fr.qonto.com/hc/fr/articles/23947686148497-Comment-voir-ou-changer-mon-code-PIN)

☝️ **Attention** : si vous ne vous **souvenez plus du code PIN défini lors de la commande de votre carte,** il n'est pas possible de demander la réinitialisation, pour des raisons de sécurité.

Dans ce cas, il faudra [annuler cette carte](https://support-fr.qonto.com/hc/fr/articles/23947680825233-Comment-supprimer-une-carte) et en [commander une nouvelle](https://support-fr.qonto.com/hc/fr/articles/23947709197329-Comment-commander-une-carte-Qonto).

**Vous avez bloqué la carte temporairement**
--------------------------------------------

**Comment débloquer ma carte suite à un blocage temporaire ?** 🔓

* **Depuis la section ‘Compte Pro’**
* Sélectionnez la carte à débloquer ;
* Cliquez sur **Débloquer** pour activer la carte ;
* Confirmez l’action en saisissant votre mot de passe

Si vous êtes **employé**, vous aurez besoin de contacter un **admin du compte**.
