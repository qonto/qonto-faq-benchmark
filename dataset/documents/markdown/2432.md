# ¿Cómo importar una lista de beneficiarios?

Con Qonto puedes importar una lista de beneficiarios (hasta 400 a la vez). Necesitarás hacerlo si decides cambiar de banco o abrir una nueva cuenta bancaria.

**¿Cómo funciona?**
===================

1. Descarga el archivo CSV: [Borrador lista beneficiarios](https://qonto-assets.s3.amazonaws.com/intercom_faq/import%20beneficiaries.csv)
2. Rellena el archivo CSV con tus beneficiarios, utilizando Microsoft Excel o cualquier otro editor de hojas de cálculo (No modifiques la primera fila)
3. Abre el archivo en la aplicación Qonto
4. Ve a la pestaña **Cuenta de la empresa** de tu espacio Qonto
5. Accede a la sección **Transferencias**
6. Haz clic en el icono negro **+ Hacer una transferencia** en la esquina superior derecha de tu pantalla
7. Accede a la sección **Transferencias masivas SEPA en euros**
8. Para añadir varios beneficiarios a la vez, importa un archivo **.CSV**
9. Verifica los datos importados y valídalos

⚠️ **¿Qué hacer si se produce un error al descargar el archivo?**
=================================================================

Ten en cuenta que el archivo está en inglés, por lo que **no se puede modificar o traducir los encabezados de las columnas**. Además, debe contener las 3 columnas separadas por un punto y coma (;)

* **NAME**
* **IBAN**
* **EMAIL**

Cada línea debe contener un valor por Nombre e IBAN. También puedes incluir un valor para la columna EMAIL.

Los valores correspondientes a IBAN deben tener un formato especial. En caso de error, en la pantalla de confirmación aparecerá la lista de beneficiarios cuya información debe ser modificada.

Una vez se hayan hecho las modificaciones, puedes validar tu lista de beneficiarios para importarla.

NOTA: Los beneficiarios que no tengan una cuenta SEPA no se podrán añadir a la lista.
