# Will my device soon no longer be compatible with the Qonto app?

To ensure the highest level of security and performance for our users, Qonto is updating its security requirements. This update requires you to have the latest version of the Qonto app.

### What happens if my device's operating system (OS) is too old?

If your device has an OS that is too old, you will not be able to update the Qonto app and will no longer be able to use Qonto. There are two main scenarios:

* **Android 5 & iOS 12:** Qonto will no longer support these versions. We kindly invite you to switch to a newer device with at least Android 6 or iOS 14.
* **iOS 13:** You need to update your OS to continue using Qonto.

### What is the timeline for these changes?

* **June:** Gradual discontinuation of support for older Android versions will begin.
* **July:** Full discontinuation of support for older Android versions will be completed.
* **September:** Gradual discontinuation of support for older iOS versions.
* **October:** Full discontinuation of support for older iOS versions will be completed.

### What should I do if my device has Android 5?

You will need to get a new device that supports Android 6 or higher to install the latest version of the Qonto app.

### What should I do if my device has iOS 12?

You will need to get a new device that supports iOS 14 or higher to install the latest version of the Qonto app.

### What should I do if my device has iOS 13?

You will need to update your OS to download the latest version of the Qonto app.

### How can I avoid being blocked when those changes will be made?

To avoid being blocked, ensure that you have a device with a compatible OS and update to the latest version of the Qonto app before the specified deadlines. This will allow you to continue using Qonto without any interruptions.

### Who can I contact for more information?

If you have any questions or need further assistance, please contact our customer support team via the Qonto app or website.
