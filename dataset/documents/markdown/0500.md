# How do I make an international transfer?

Making an international transfer is fairly simple. You can make a transfer directly from your web or mobile app by following the steps below.

**💻 On your web app**
---------------------

1. Go to the **Business account** section and click on **Transfers**.
2. Click on **Make a transfer** in the upper right corner.
3. Select **International transfer**.
4. Select which account to debit, enter the transfer amount and select the currencies.
5. Optional step - Set up a scheduled payment by clicking on **Schedule**.
   * Select the starting date.
   * Select the frequency if you would like to set up a recurring transfer.
   * Click on **Set schedule** to save your settings for this scheduled transfer.
6. Once you are satisfied with the setup of your transfer, click on **Continue**.
7. Select a beneficiary or add a new one, add additional information and upload an attachment if applicable.
8. **One last look:** take a moment to double-check that everything is correct before clicking on **Confirm**.
9. Confirm your action with the two-factor authentication.

**📱On your mobile app**
-----------------------

1. Tap on **Menu** and then select **Transfers**.
2. Tap on the black **+ icon** in the upper right corner.
3. Select **International transfer**.
4. Enter the transfer amount and select the currencies.
5. Optional step - Set up a scheduled payment by tapping on **Schedule**.
   * Select an execution date.
   * If you would like to set up the **Transfer recurrence** tap on its toggle to enable it.
     + Select the appropriate interval.
     + Enter the end date if needed - the transfer will otherwise recur indefinitely until modified or canceled.
   * Tap on **Set schedule** to save your settings for this scheduled transfer.
6. Once you are satisfied with the setup of your transfer, tap on **Continue**.
7. Select the beneficiary or add a new one, add additional information and upload an attachment if applicable.
8. **One last look:** take a moment to double-check that everything is correct before tapping on **Confirm**.
9. Confirm your action with the two-factor authentication.

**💡 Please keep in mind** that a minimum amount will be necessary in order to execute SWIFT payments - usually around 10€ for all currencies (except for Kenyan Schillings for which the minimum amount is 36€).

**💡 Good to know:** If you want to find or check a BIC/SWIFT code, you can use [our BIC/SWIFT search engine](https://qonto.com/en/swift-codes).
