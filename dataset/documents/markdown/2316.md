# ¿Cómo configurar recordatorios de pago automáticos para las facturas no pagadas de los clientes?

Qonto permite configurar recordatorios de pago automáticos para notificar a tus clientes las facturas impagadas. Puedes configurar fácilmente recordatorios vinculados a un cliente concreto, lo que garantiza que las facturas futuras se gestionen sin problemas.

###

### ¿Quién puede establecerlos?

Esta función solo está disponible para titulares y administradores, tanto en la web como en las aplicaciones móviles. Los recordatorios de pago automáticos forman parte del [módulo de gestión de facturas a clientes](https://support-es.qonto.com/hc/es/articles/28509717293713--Qu%C3%A9-complementos-hay-disponibles-para-complementar-mi-plan#:~:text=2.%20Complemento%20de%20gesti%C3%B3n%20de%20facturas%20a%20clientes%3A)

###

### ¿Cómo puedo configurar un recordatorio de pago automático?

Hay dos formas de configurar un recordatorio de pago automático:

1. **Desde la Lista de Clientes:**
   * Ve a la lista de clientes
   * Haz clic en el cliente específico que deseas cobrar, o abre el menú de acciones rápidas.
   * Busca la opción **Recordatorio de pago automático.**
2. **Desde una factura impaga:**
   * Abre la factura que no está pagada
   * Clic en **Establecer recordatorios automáticos.**
   * El recordatorio se aplicará automáticamente a todas las futuras facturas pendientes de pago de ese cliente.

### ¿Qué datos se necesitan para configurar un recordatorio?

Para configurar un recordatorio automático, tendrás que:

* Introducir la dirección de correo electrónico del destinatario. Se pueden añadir varios correos separándolos con comas.
* Opcionalmente, configura una secuencia de recordatorios especificando cuántos recordatorios enviar y cuándo. Es posible programar hasta 5 recordatorios para un mismo cliente. Por ejemplo:
  + Primer recordatorio: 2 días antes de la fecha de expiración.
  + Segundo recordatorio: En la misma fecha de expiración.
  + Tercer recordatorio: 2 días después de la fecha de expiración.

### ¿Puedo editar o borrar un recordatorio?

Sí, es posible:

* Navega hasta los mismos puntos de acceso (lista de clientes o factura impaga).
* Selecciona la opción para editar o eliminar un recordatorio existente.

### ¿Qué pasa si cierran mi cuenta?

Si se desactiva tu organización Qonto, dejarán de enviarse todos los recordatorios de pago automáticos.
