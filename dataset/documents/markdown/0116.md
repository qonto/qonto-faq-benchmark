# Qu'est-ce qu'un litige commercial et combien de temps cela prend-il pour le contester?

Un litige commercial se produit lorsque le titulaire d'une carte rencontre des problèmes avec une transaction portant sur des biens ou des services. Cela peut se produire dans plusieurs circonstances, par exemple lorsqu’il a enregistré ses informations de carte sur le site web d'un commerçant ou a directement initié un paiement, et par la suite :

* Le commerçant ne remplit pas ses obligations, comme ne pas livrer les articles commandés.
* Le titulaire de la carte paie pour un bien ou un service que le commerçant ne fournit pas comme convenu.
* Le produit reçu par le titulaire de la carte diffère considérablement de la description ou des images fournies sur le site web du commerçant.

Un litige commercial est un désaccord entre le titulaire de la carte et le commerçant concernant l'exécution d'une transaction, la livraison de biens ou la prestation de services, amenant le titulaire de la carte à chercher une résolution, souvent sous la forme d'un remboursement ou d'un remplacement.

**Comment puis-je entamer le processus de litige pour une transaction?**
------------------------------------------------------------------------

1. Sélectionnez la transaction que vous souhaitez contester dans votre aperçu de compte et cliquez sur "**Besoin d'aide**".
2. Choisissez l'option "**J'ai eu un problème avec le paiement, le produit, ou le service**".
3. Avant de continuer, assurez-vous d'avoir **contacté le commerçant**. Si le commerçant ne résout pas le problème dans les 7 jours, veuillez continuer le litige.
4. Cliquez sur **"Contester cette transaction"** pour initier le processus de litige.

**Puis-je contester plusieurs transactions du même commerçant?**
----------------------------------------------------------------

Oui, si vous contestez plus d'une transaction du même commerçant, vous pouvez les sélectionner pendant le processus de litige pour inclure toutes les transactions pertinentes dans votre réclamation.

**Quelles preuves dois-je fournir pour mon litige?**
----------------------------------------------------

Vous devrez télécharger :

* Une preuve de conversation avec le commerçant, démontrant que vous avez tenté de résoudre le problème directement. S'ils ne répondent pas dans une semaine, montrez-nous une preuve de cela (capture d'écran, photo)
* Tous les documents supplémentaires qui appuient votre réclamation, tels que des factures, des confirmations de commande ou des descriptions des écarts entre le produit commandé et celui reçu.

**Comment décrire le problème dans mon litige?**
------------------------------------------------

Fournissez une description claire et détaillée de ce qui s'est passé. Incluez tous les détails pertinents sur la transaction, le problème avec le paiement, le produit ou le service, et toute communication que vous avez eue avec le commerçant concernant le litige.

**Que se passe-t-il après avoir soumis le litige?**
---------------------------------------------------

Une fois que vous avez soumis le litige, notre équipe examinera votre réclamation. Si le litige est approuvé, vous pouvez vous attendre à voir un remboursement **temporaire** sur votre compte prochainement.

**Et si le commerçant conteste mon remboursement?**
---------------------------------------------------

Après le remboursement temporaire, le commerçant **peut** **le contester** en initiant un chargeback. Si cela se produit, le remboursement initial sara débité de nouveau de votre compte. Nous vous en informerons et pourrions demander des informations supplémentaires pour soutenir votre réclamation pendant cette période.

**Comment saurai-je le résultat de mon litige?**
------------------------------------------------

Vous serez informé du résultat de votre litige par e-mail. Gardez un œil sur les messages de votre compte pour les mises à jour sur le statut de votre litige et toute action que vous pourriez devoir prendre.
