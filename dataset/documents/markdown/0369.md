# Comment puis-je utiliser l'intégration entre Qonto et Comptalib ?

[Comptalib](https://www.comptalib.com/partner/qonto/?promocode=QONTO1) est un outil de comptabilité pour les entreprises et leurs experts-comptables.

Vous pouvez profiter d'une intégration entre Qonto et Comptalib depuis la plateforme Connect, afin de synchroniser automatiquement et de manière sécurisée vos informations de transaction Qonto avec Comptalib.

De cette manière, vous gagnez du temps, puisque vous n'avez pas besoin de retransmettre vos informations à votre comptable depuis un export manuel.

**Comment fonctionne l'intégration ?**
--------------------------------------

Pour profiter de l'intégration, vous devez disposer d'un compte Comptalib. Si vous n'en avez pas encore, vous pouvez bénéficier d'un mois gratuit sur l'abonnement à Comptalib en cliquant 👉 [sur ce lien](https://www.comptalib.com/partner/qonto/?promocode=QONTO1).

1. Commencez par récupérer vos identifiants API Qonto : dans votre application mobile, cliquez sur **Intégrations et Partenariats**, puis sur **Clé API**. Copiez-collez vos identifiants.
2. Connectez vous à votre application Comptalib puis rendez-vous dans l’onglet **Paramètres**
3. Sélectionnez l'onglet **Banques** puis cliquez sur le logo Qonto
4. Collez vos identifiants API Qonto et validez le formulaire

Votre compte Qonto est synchronisé et vos informations de transaction Qonto remontent automatiquement vers Comptalib.
