# Wie kann ich Empfänger als vertrauenswürdig markieren?

Automatisierung von Transaktionen mit Zapier, Make oder anderen no-code Plattformen

Mit Qonto können Sie nicht nur **einfach über die App** oder Ihren Computer Geld **überweisen**, **sondern auch Ihre Zahlungen** durch die Nutzung von No-Code-Plattformen wie Zapier und Make oder direkt über unsere API **automatisieren.**

So **sparen Sie wertvolle Zeit** und können Zahlungsprozesse für Lieferanten und Mitarbeiter **effizient gestalten** oder Geldflüsse zwischen Ihren Konten nahtlos organisieren.

**Warum das Hinzufügen vertrauenswürdiger Empfänger wichtig ist**
-----------------------------------------------------------------

Um die Sicherheit Ihrer automatischen Überweisungen zu gewährleisten, haben wir ein starkes Authentifizierungssystem eingeführt, das eine Bestätigung jeder Überweisung per Push-Benachrichtigung auf Ihrem Smartphone erfordert. **Um diesen Schritt zu umgehen und Zeit zu sparen,** empfehlen wir, Ihre regelmäßigen Zahlungsempfänger als vertrauenswürdig zu markieren.

**So fügen Sie vertrauenswürdige Empfänger hinzu**
--------------------------------------------------

1. Öffnen Sie Qonto auf Ihrem Computer und **navigieren Sie zu Geschäftskonto → Überweisungen**
2. Beim Erstellen einer Überweisung finden Sie **im Menü die Option, Ihre Empfänger zu verwalten.**
3. Für bestehende Empfänger: Bewegen Sie den Mauszeiger über den Empfänger, klicken Sie auf die drei Punkte und **wählen Sie "Als vertrauenswürdig markieren"**. Bestätigen Sie diesen Schritt auf Ihrem Smartphone.
4. Für neue Empfänger: **Fügen Sie den Empfänger hinzu** und folgen Sie dem oben beschriebenen Prozess.



Sobald Sie Ihre **vertrauenswürdigen Empfänger eingerichtet haben**, können Sie **ohne Unterbrechung automatische Überweisungen** über Zapier, Make und unsere API planen und durchführen.
