# Qu'est-ce que le module Gestion des dépenses d'équipe ?

Concentrez-vous uniquement sur les dépenses qui comptent. Offrez-vous de la flexibilité, contrôlez seulement ce qui importe.

Simplifiez la gestion de vos dépenses grâce à des contrôles avancés. Optimisez le temps de votre équipe en vous concentrant uniquement sur les dépenses significatives tout en conservant flexibilité et contrôle là où c'est le plus important.

|  |  |
| --- | --- |
| **Forfaits standards** | **Module Gestion des dépenses** |
| Paramètres de base des cartes (limites journalières, limites de transaction) | Cartes virtuelles, publicitaires et instantanées illimitées |
| Rôle Collaborateur illimité | Permissions avancées pour les managers |
| Permissions de base du rôle Manager (invitations d'équipe, création de carte) à partir du forfait Business | Paramètres avancés des cartes (catégories de dépenses, jours d'utilisation) |
| Rapports de dépenses à partir du forfait Business | Circuits de validation personnalisés |
| 50 cartes virtuelles gratuites et 50 cartes publicitaires gratuites | Gestion de budget pour les équipes |
| Centralisation des reçus via connect (Google Drive), téléchargement groupé, transfert de reçus |  |
| Indemnités kilométriques |  |
| Numérisation des reçus | Intégration SIRH continue |
|  | Gestion des abonnements (suivi centralisé, notifications de paiement, historique des transactions) |
| Rappel de reçus manquants | Règles personnalisées pour bloquer une carte en cas de reçus manquants |
| Remboursement des dépenses personnelles |  |
| Intégration ponctuelle SIRH (Système d'Information de Ressources Humaines) |  |

**Combien coûte le module Gestion des dépenses ?**
--------------------------------------------------

Le module est disponible pour 89 €/mois avec facturation mensuelle ou 69 €/mois avec facturation annuelle (hors TVA).

Il est disponible pour les forfaits Team (Essential, Business et Enterprise).

**Quelle est la différence entre les rôles Manager basique et Manager avancé ?**
--------------------------------------------------------------------------------

| **Manager basique (inclus dans les forfaits Business et Entreprise) :** | **Manager avancé (nécessite le module Gestion des dépenses/Comptes fournisseurs), toutes les permissions du manager basique, plus :** |
| --- | --- |
| Sélectionner des sous-comptes pour les paiements de factures fournisseurs et l'accès aux transactions | Consulter les soldes des comptes, l'IBAN, les transactions et télécharger les relevés |
| Gérer les cartes (créer, supprimer, modifier et examiner les demandes de carte) | Gérer la comptabilité |
| Gérer les fournisseurs et les factures fournisseurs à l'échelle de l'entreprise : modifier les factures fournisseurs et les payer | Configurer et suspendre les mandats de prélèvement |
| Inviter des membres de l'équipe en tant que collaborateurs | Déposer des chèques |
|  | Effectuer des virements, des remboursements et des remboursements kilométriques |
|  | Agir en tant qu'approbateur dans les circuits de validation |
|  | Capacités améliorées de gestion des factures fournisseurs |

Remarque : Lors de la mise à niveau vers le module Gestion des dépenses/Comptes fournisseurs, les Managers basiques sont automatiquement éligibles aux permissions de Manager avancé mais nécessitent des mises à jour manuelles des permissions.

**Qu'est-ce qu'un circuit de validation ?**
-------------------------------------------

Un [circuit de validation](https://support-fr.qonto.com/hc/fr/articles/26570070089745) est un processus qui gère les demandes de dépenses depuis leur initiation jusqu'à la décision finale.

Cette fonctionnalité est disponible via ce module (Gestion des dépenses d'équipes) et également via le module [Gestion des Factures fournisseurs.](https://support-fr.qonto.com/hc/fr/articles/34954360188433)

**Comment fonctionne la gestion des budgets ?**
-----------------------------------------------

* Définir des [budgets](https://support-fr.qonto.com/hc/fr/articles/23947583343121) pour chaque équipe
* Créer des comptes dédiés avec des IBAN spécifiques
* Suivre les dépenses par équipe, projet ou catégorie de dépenses
* Surveiller l'utilisation du budget en temps réel.

**Comment puis-je gérer mes modules ?**
---------------------------------------

Vous pouvez gérer vos modules depuis l'application web et mobile. Sur le web, allez dans **Paramètres** > **Forfaits et factures** > **Détails du forfait** et cliquez sur "**Gérez les modules complémentaires**".

Sur mobile, accédez à **Menu** > **Paramètres** (en haut à droite) > **Forfait** et sélectionnez votre module.

Pour plus d'informations sur les modules disponibles, consultez notre article d'aide dédié : [Quels modules sont disponibles pour compléter mon forfait ?](https://support-fr.qonto.com/hc/fr/articles/28479048690705)

**Que se passe-t-il si je supprime le module ?**
------------------------------------------------

Pas d'inquiétude ! Vous conserverez l'accès à toutes les fonctionnalités standard. Vos factures récurrentes seront mises en pause, et les personnalisations reviendront au format standard. Bien que vous puissiez supprimer le module à tout moment avec une facturation mensuelle, les fonctionnalités de facturation annuelle restent actives jusqu'à la fin de votre période de facturation, sans remboursement en cours de période.

Besoin d'aide pour commencer ? Notre équipe de support est disponible via le chat directement depuis votre application Qonto !
