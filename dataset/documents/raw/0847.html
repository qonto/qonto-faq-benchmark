Add-ons bieten eine Reihe fortgeschrittener Funktionen und können zusätzlich zu einem Preisplan abonniert werden. Sie erweitern Ihr Konto um zusätzliche Funktionen, um besser auf die Bedürfnisse Ihres Unternehmens einzugehen.

⚠️ Keine Add-ons sind standardmäßig in einem Preisplan enthalten.

Die derzeit verfügbaren Add-ons sind:

  • Team- & Kostenmanagement: Nur verfügbar für Team-Pläne (Essential, Business, Enterprise).
  • Lieferantenrechnungen: Nur verfügbar für Team-Pläne (Essential, Business, Enterprise).
  • Kundenrechnungen: Für alle Pläne verfügbar.
  • Cash Flow Management: Für alle Pläne verfügbar.

Add-ons sind in allen Ländern verfügbar und können von Eigentümern oder Administratoren aktiviert werden, abhängig vom aktuellen Preisplan, den Sie haben. Bestimmte Add-ons sind nur für Team-Pläne verfügbar.

Wie funktioniert es?

Wir bieten eine einmonatige kostenlose Testversion für alle Add-ons an. Hier sind die wichtigsten Regeln:

  1. Die kostenlose Testversion ist vom Kunden initiiert
    • Sie müssen die kostenlose Testversion selbst aktivieren.
  2. Dauer und Aktivierung
    • Die kostenlose Testversion dauert einen Monat.
    • Sie können mehrere Add-on-Testversionen gleichzeitig aktivieren.
    • Sie können eine kostenlose Testversion für ein Add-on starten, auch wenn bereits eine andere Add-on-Testversion aktiv ist.
  3. Berechtigung
    • Die kostenlose Testversion kann nur aktiviert werden, nachdem Sie die anfängliche Qonto-Plan-Testversion abgeschlossen haben.
    • Sie ist nur verfügbar, wenn Sie dieses spezifische Add-on noch nie abonniert haben.
  4. Abrechnungszyklen
    • Die kostenlose Testversion gilt sowohl für monatliche als auch für jährliche Abrechnung.
    • Während der Testversion können Sie den Abrechnungszyklus (monatlich oder jährlich) für das Add-on ändern.
    • Wenn Sie eine kostenlose Testversion über einen Upsell-Einstiegspunkt aktivieren, wird der Abrechnungszyklus standardmäßig auf monatlich gesetzt. Für Solo-Plan-Nutzer kann ein Upgrade des Plans erforderlich sein, um auf bestimmte Add-ons zugreifen zu können.
    • Wenn Sie das Add-on nicht vor dem Ende der Testversion kündigen, werden Ihnen die Kosten für das Add-on zusammen mit Ihrem aktuellen Abrechnungszyklus in Rechnung gestellt.

Kann ich die kostenlose Testversion kündigen?

Ja, Sie können jederzeit kündigen. Wenn Sie jedoch eine Add-on-Testversion aktivieren und feststellen, dass es nicht der richtige Zeitpunkt ist, können Sie die kostenlose Testversion dieses Add-ons nicht erneut aktivieren.

Wie wirkt sich die kostenlose Testversion des Add-ons auf die kostenlose Testversion meines Qonto-Plans aus?

Wenn Sie eine kostenlose Testversion eines Add-ons starten, die ein Plan-Upgrade erfordert, bietet Qonto Ihnen automatisch eine kostenlose Testversion für den erforderlichen Plan an.

Zum Beispiel: Um Lieferantenrechnungen oder Team- & Kostenmanagement zu nutzen, müssen Sie auf den Essential-Plan oder einen höheren Plan upgraden.
