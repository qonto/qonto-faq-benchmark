Una domiciliación de tarjeta (o tarjeta de domiciliación) conecta el terminal de pago a la cuenta bancaria de una empresa y es especialmente útil para artesanos o comerciantes. Suele tener 7 dígitos y se conoce como "tarjeta de comercio para TPV". Es necesaria para la configuración del terminal de pago (TPV).

Con una domiciliación de tarjeta se puede:

  • Cobrar el pago con tarjeta de crédito

  • Reembolsar la transacción

  • Cancelar la operación

☝️ Al ser una entidad de pago y no una institución bancaria, Qonto aún no ofrece una tarjeta de domiciliación.
