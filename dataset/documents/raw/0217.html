La fonctionnalité Actions Rapides améliore votre productivité grâce à des raccourcis pratiques qui vous permettent d'effectuer des tâches en 1 à 2 clics. Que vous envoyiez des virements SEPA, téléchargiez des factures et reçus ou recherchiez vos dernières transactions, vous gagnerez du temps en réduisant les étapes de navigation dans l'application Qonto.

Cela vous permet de :

  • Initier un virement SEPA instantané avec une simple demande écrite et un clic pour confirmer.
  • Télécharger un reçu ou une facture en utilisant la fonction glisser-déposer.
  • Rechercher vos 50 dernières transactions.
  • Utilisez des raccourcis intelligents pour effectuer vos tâches habituelles, mais plus rapidement.

Située sur le panneau gauche de l'application web, sous votre logo, cette fonction ressemble à une barre de recherche. Vous pouvez également utiliser Command K (Mac) ou Ctrl K (Windows) pour activer les actions rapides.

Qui peut utiliser les actions rapides ?

Pour l'instant, cette fonctionnalité n'est accessible qu'aux Titulaires et aux Admin. Elle est disponible pour tous les forfaits, seulement pour l'application web.

Quelles sont les actions disponibles ?

Vous pouvez effectuer les actions intelligentes suivantes :

  • Effectuer un virement SEPA instantané
  • Importer des reçus et des factures fournisseurs

Vous pouvez naviguer rapidement via les raccourcis suivants :

  • Effectuer un virement
  • Créer une carte
  • Télécharger les relevés de compte
  • Ajouter un prélèvement automatique sortant
  • Ajouter un compte
  • Configurer une intégration
  • Inviter un collaborateur
  • Envoyer une note de frais
  • Accéder aux IBAN

 

Comment cela fonctionne-t-il ?

Pour commencer, cliquez sur l’icône Actions rapides ⚡️.

Sélectionnez l'action que vous recherchez dans la liste.

Cliquez dessus et le processus correspondant démarrera automatiquement.

 

Vous trouverez deux types d'actions dans la liste :

  • Les raccourcis vous redirigent instantanément vers la page correspondante de l'application.
  • Les actions intelligentes offrent un processus simplifié pour accomplir les tâches plus efficacement.

 

Effectuer un virement SEPA instantané:

  • Saisir le prompt : Envoyer [montant] euros à [@nom du bénéficiaire existant] pour [raison].
  • Sélectionnez le bénéficiaire existant en tapant @ et appuyez sur Entrée.

Une fois que vous avez appuyé sur Entrée, vous pouvez vérifier l'exactitude de votre demande :

  • Si elle est correcte, appuyez sur Envoyer le transfert et validez l'action sur votre téléphone avec le SCA.
  • Si l'information est incorrecte, appuyez sur Modifier les détails pour la corriger.

⚠️ Le bénéficiaire doit exister avant la saisie du prompt.


Téléchargez des reçus et factures fournisseurs :

Glissez-déposez votre fichier au format PDF, JPG ou PNG, jusqu'à 30 MB.
Une fois téléchargé, vous le retrouverez dans votre section Factures fournisseurs et nous l'associerons à la bonne transaction.
💡 Note : Vous pouvez glisser-déposer plusieurs fichiers en même temps.


Recherchez des transactions :

Accédez facilement à vos 50 dernières transactions. Vous pouvez utiliser la barre de recherche pour taper le nom ou le montant.
