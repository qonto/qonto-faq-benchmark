Mit Qonto können Sie automatische Zahlungserinnerungen einrichten, um Ihre Kunden über unbezahlte Rechnungen zu informieren. Sie können ganz einfach Erinnerungen für einen bestimmten Kunden einrichten, um sicherzustellen, dass zukünftige Rechnungen problemlos bearbeitet werden.

 

Wer kann sie einrichten?

Diese Funktion steht nur Inhabern und Admins zur Verfügung, sowohl in der Web- als auch in der mobilen Version. Automatisierte Zahlungserinnerungen sind Teil des Add-ons Kundenrechnungen.

 

Wie kann ich eine automatische Zahlungserinnerung einrichten?

Es gibt zwei Möglichkeiten, eine automatische Zahlungserinnerung einzurichten:

1. Von der Kundenliste aus:
 -Gehen Sie zur Kundenliste.
 -Klicken Sie auf den Kunden, dem Sie eine Rechnung stellen möchten, oder öffnen Sie das Schnellaktionsmenü.
-Suchen Sie nach der Option Automatisierte Zahlungserinnerung.

2. Von einer unbezahlten Rechnung aus:
-Öffnen Sie eine unbezahlte Rechnung.
-Klicken Sie auf Automatische Erinnerung einrichten.
-Die Mahnung wird automatisch auf alle zukünftigen unbezahlten Rechnungen für diesen Kunden angewendet.

 

Welche Angaben sind erforderlich, um eine Mahnung einzurichten?

Um eine automatische Erinnerung einzurichten, benötigen Sie folgende Angaben:

  • Geben Sie die E-Mail-Adresse des Empfängers ein. Sie können mehrere E-Mails hinzufügen, indem Sie sie durch Kommas trennen.
  • Optional können Sie eine Erinnerungssequenz einrichten, indem Sie angeben, wie viele Erinnerungen Sie wann senden möchten. Sie können bis zu 5 Erinnerungen für einen einzelnen Kunden planen. Zum Beispiel:

1. Erinnerung: 2 Tage vor dem Fälligkeitsdatum.
2. Erinnerung: Am Fälligkeitstag.
3. Erinnerung: 2 Tage nach dem Fälligkeitsdatum.

 

Kann ich eine Erinnerung bearbeiten oder löschen?

Ja, das können Sie:

  • Gehen Sie zu denselben Einträgen (Kundenliste oder unbezahlte Rechnung).
  • Wählen Sie die Option zum Bearbeiten oder Löschen einer bestehenden Erinnerung.

Was passiert, wenn mein Konto geschlossen wird?

Wenn Ihre Qonto-Konto deaktiviert wird, werden alle automatischen Zahlungserinnerungen eingestellt.
