Vous avez la possibilité de modifier à tout moment votre adresse e-mail en accédant à votre application Qonto depuis un ordinateur ou votre téléphone.
​

 

Vous avez accès à votre application Qonto ?

 

💻 Depuis un ordinateur

  1. Rendez-vous dans Paramètres en bas à gauche, puis cliquez sur Paramètres personnels > Profil personnel.

  2. Cliquez sur le bouton Modifier situé en dessous de votre adresse mail actuelle

  3. Vous pouvez ensuite saisir votre nouvelle adresse e-mail

  4. Confirmez-la en saisissant le code de vérification à 6 chiffres que vous avez reçu par e-mail.

  5. Si vous avez configuré l'authentification forte, vous recevrez une demande de confirmation sur votre téléphone associé

  6. Si vous n'avez pas encore configuré l'authentification forte, saisissez le code de confirmation reçu par SMS

  7. Le tour est joué, votre adresse mail est modifiée !

 

📱 Depuis l’application mobile

  1. Rendez-vous dans la section Menu puis cliquez sur ⚙️ en haut à droite de votre interface

  2. Cliquez sur votre profil

  3. Au niveau de votre adresse mail actuelle, cliquez sur l'émoticône en forme de crayon situé à droite

  4. Ensuite, saisissez votre nouvelle adresse mail

  5. Confirmez-la en saisissant le code de vérification à 6 chiffres que vous avez reçu par e-mail.

  6. Si vous avez configuré l'authentification forte, vous recevrez une demande de confirmation sur votre téléphone associé

  7. Si vous n'avez pas encore configuré l'authentification forte, saisissez le code de confirmation reçu par SMS

  8. Le tour est joué, votre adresse mail est modifiée !

 

Avez-vous déjà configuré un mot de passe ?

Si vous n'avez pas encore configuré de mot de passe (vous vous êtes inscrit avec Google / Apple), vous devrez en configurer un lorsque vous modifierez votre adresse e-mail.

En plus des étapes ci-dessus 👆:

  1. Après avoir entré votre code de vérification à 6 chiffres, vous serez déconnecté de votre compte.

  2. Vous recevrez un autre e-mail avec des instructions pour configurer votre mot de passe

  3. Cliquez sur le lien de cet e-mail pour configurer votre mot de passe.

 

Vous n'avez plus accès à votre espace Qonto ou un message d'erreur s'affiche ?

Pour procéder à ce changement, nous avons besoin de vérifier votre identité afin de nous assurer que personne n'essaie de se faire passer pour vous (on est jamais trop prudent).🕵️‍♂️

Munissez-vous des éléments suivants et envoyez-le nous par chat :

  • Un selfie, tenant en main votre pièce d’identité proche de votre visage et une feuille blanche avec la date du jour et le mot QONTO écrit à la main.

  • Indiquez-nous les informations suivantes :

1. Nom de votre société

2. SIREN

3. Nom

4. Prénom

5. Nouvelle adresse e-mail

 

 

À noter : Vous pouvez gérer plusieurs comptes Qonto avec une seule adresse email. Il vous suffit de cliquer sur le logo de votre entreprise en haut à gauche de l'application et de sélectionner "+Ajouter une autre entreprise". Vous pouvez ensuite facilement basculer entre différentes sociétés dans l'application Qonto.
