La création d'un code PIN vous permet de confirmer la commande de vos cartes Qonto. Sans validation de votre part, la carte ne sera jamais envoyée.

 

Pour garantir la sécurité, le système n'accepte pas les combinaisons suivantes : 0000 (4 fois zéro) ou 0243 (commence par zéro) ou 1234 (chiffres consécutifs).

 

Êtes-vous le Gestionnaire, Admin ou Manager ?

Si vous commencez la commande d'une carte et que vous ne voyez pas le titre, choisissez le code PIN de la carte si vous le faites au moment de la commande.

 

Êtes-vous un Collaborateur ?

Vous pouvez choisir votre code PIN dans les instructions de l'email "Choisissez un code PIN pour votre carte 🔑 " ou dans toutes les cartes > Sélectionnez la carte > Cliquez sur le code PIN.

Si vous n'avez pas encore ajouté votre pièce d'identité avant de définir votre code PIN, nous vous demanderons une pièce d'identité qui devra être approuvée.

 

Pour des raisons de sécurité, la commande sera confirmée après la connaissance du code PIN et la validation de votre pièce d'identité.

 

Encore une fois, vous ne pourrez plus activer vos cartes .

 

☝️ Bon à savoir : votre code PIN sera visible à tout moment depuis votre application web ou mobile Qonto, après l'activation de la carte. Cliquez ici pour tous les détails .
