Comment puis-je profiter de l'offre spéciale et obtenir une carte X Métal gratuitement durant 3 mois ?

La carte X Métal est gratuite durant 3 mois pour chaque nouveau client qui ouvre un compte Qonto (quelle que soit la formule choisie).

Pour profiter de cette offre, suivez les étapes suivantes :

  1. Notez le code promotionnel de l'offre : XCARD3M

  2. Commencez le processus d'ouverture de compte sur Qonto.com

  3. Lorsque vous êtes invité à sélectionner votre forfait, cliquez sur Avez-vous un code promo ? dans le coin supérieur droit.

4. Saisissez le code de réduction : XCARD3M et confirmez.

NB : il sera écrit que le code promo a été appliqué

5. Poursuivre le processus d'inscription

6. Après la signature du contrat, commandez votre carte X Métal

C'est fait ! Vous pouvez maintenant profiter de votre carte X Métal gratuitement pendant les 3 prochains mois.

À l'issue de ces 3 mois gratuits, votre carte X vous sera automatiquement facturée au tarif standard de 20 € HT par mois.

NB : le code promotionnel est actif immédiatement.

👆 Cela signifie que si vous la commandez le 17/07/2023, vous ne paierez pas cette carte X du 17/07/2023 au 16/10/2023, vous paierez ensuite au prorata en octobre entre le 17/10/2023 et le 31/10/2023.
