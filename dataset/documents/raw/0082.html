Quels changements dois-je prévoir concernant mes cartes Qonto ?

Nous effectuons une migration technique pour améliorer votre expérience bancaire. Pendant cette période, certaines fonctionnalités de gestion des cartes seront temporairement indisponibles.

Ne vous inquiétez pas - vos cartes continueront à fonctionner normalement pour les paiements, mais vous ne pourrez pas modifier les paramètres de carte ou consulter les informations sensibles comme les codes PIN pendant une courte période.

 

Quelles opérations de carte seront indisponibles pendant la migration ?

Pendant cette période, vous ne pourrez pas :

  • La carte visuelle dans le portefeuille pourrait ne pas être la bonne ; ce n'est pas le cas pour toutes les cartes
  • Les paiements sans contact ne fonctionnent pas ; mais un correctif est actuellement déployé
  • Les paiements par code PIN ne fonctionnent pas ; mais un correctif est actuellement déployé 

Mes cartes existantes fonctionneront-elles toujours ?

Oui ! Vous pourrez toujours payer avec vos cartes comme d'habitude.

Seules les opérations de gestion des cartes sont affectées pendant la migration.

 

Combien de temps durera cette interruption de service ?

La durée exacte sera visible dans l'application avant le début de la migration. Nous travaillons pour que cette période soit aussi courte que possible afin de minimiser tout désagrément.

 

Mes cartes fonctionneront-elles normalement après la migration ?

Oui ! Lorsque la migration sera terminée, la bannière ne sera plus visible, tous les services de carte reprendront automatiquement. Vous n'aurez aucune action à entreprendre, et vos cartes continueront à fonctionner comme avant.

 

Que dois-je faire si j'ai besoin d'un accès urgent aux détails de ma carte ou à mon code PIN ?

Nous vous recommandons de noter les détails de votre carte et votre code PIN avant la migration si vous pensez en avoir besoin pendant cette période.

Si vous avez besoin de plus d'informations ou pour toute autre demande, veuillez contacter notre équipe d'assistance client : support@qonto.com.
