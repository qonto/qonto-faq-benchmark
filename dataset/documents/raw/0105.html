Vous rencontrez des difficultés pour vérifier votre identité ? Pas d’inquiétude !

Cet article vous propose des solutions simples pour les résoudre.


Vous recevez un message d’erreur (Session expirée)

❗️ Pourquoi cela se produit-il ?

  • Vous avez cliqué sur le lien de vérification mais n’avez pas complété la session dans les deux heures.
  • Vous avez quitté la session et ouvert une nouvelle session.
  • Vous avez ouvert le lien sur un autre appareil.

Comment remédier à ce blocage ?

  1. Fermez toutes les fenêtres de Qonto actuellement ouvertes sur votre navigateur smartphone.
  2. Retournez à la page de vérification d'identité sur votre ordinateur.
  3. Sur cette page, vous verrez un QR code et une phrase indiquant : "Générez un nouveau code QR et un nouveau lien."
  4. Cliquez sur ce lien pour générer un nouveau QR code, puis scannez-le avec votre smartphone pour recommencer le processus de vérification d'identité.



Votre lien de vérification ne fonctionne pas

Comment remédier à ce blocage ?

  1. Téléchargez notre application mobile disponible pour Android et iOS.
  2. Connectez-vous à votre compte depuis l'application.
  3. Cliquez sur “Vérifier mon identité”.


Vous rencontrez des difficultés pour prendre votre selfie

Avant de passer en revue les points techniques, assurez-vous de :

  • Être dans une pièce bien éclairée.
  • Garder la tête dans le cadre.

Pour les utilisateurs d’iPhone 🍏

  1. Ouvrez l’application Paramètres.
  2. Accédez à Confidentialité et Sécurité.
  3. Sélectionnez la fonction matérielle que vous souhaitez activer, comme l’Appareil photo, le Bluetooth, le “Réseau local” ou le Micro.
  4. Pour activer les services de la caméra pour les sites Web de Safari/Google, sélectionnez “Pendant l’utilisation de l’application” dans Réglages, allez dans Safari, puis tout en bas, sélectionnez Appareil photo et autorisez.
  5. Revenez à l’application du navigateur et cliquez sur Réessayer.

Pour les utilisateurs d’Android 🤖

  1. Ouvrez l’application Paramètres.
  2. Cliquez sur Applications.
  3. Appuyez sur l’application que vous souhaitez modifier (par exemple, Google Chrome). Si elle n’apparaît pas, appuyez sur "Afficher toutes les applications", puis choisissez votre application. 💡 Si vous avez un téléphone Redmi/Xiaomi sans Chrome, essayez le navigateur Opera ou Mi Browse.
  4. Appuyez sur Autorisations. Si des autorisations ont été accordées ou refusées, elles apparaîtront dans cette section.
  5. Pour modifier un paramètre d’autorisation, touchez-le et sélectionnez Autoriser.

Utilisez un autre navigateur : Opera, Google Chrome, et Safari en priorité.
👉 Si vous avez un téléphone de la marque Redmi, nous vous conseillons d'utiliser Opera ou le navigateur Mi.



Vous rencontrez des difficultés dues à la qualité de votre document d’identité

Si vous rencontrez des difficultés liées à la qualité de votre document, suivez ces conseils :

  • Assurez-vous d’être dans une pièce bien éclairée.
  • Photographiez l’intégralité du document (recto/verso).
  • Posez votre document sur une surface plane pour assurer la prise.

⚠️ La photo doit être de bonne qualité et les informations visibles en zoomant.

⚠️ Pour des raisons de sécurité, nous n’acceptons pas les photocopies de document.
