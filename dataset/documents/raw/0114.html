Dans certaines situations, il est possible de modifier ou d’annuler un virement validé directement depuis l’application mobile ou web.

Où puis-je consulter mes virements internationaux programmés ?

Un aperçu de vos virements est disponible dans la section Virements du menu Compte pro. Vos virements programmés qui n'ont pas encore été traités apparaîtront dans l'onglet En cours tandis que les virements déjà exécutés et rejetés apparaîtront dans l'onglet Passés.

💡 Bon à savoir : seuls les virements exécutés apparaissent dans la vue Transactions. Si un virement programmé est créé via la section Factures fournisseurs, la facture liée à ce virement apparaîtra également dans l'onglet Paiements programmés de cette section.

Comment les modifier ou les annuler ?

💻 Sur votre application web

  1. Cliquez sur Compte pro et accédez à l'aperçu de vos virements en cliquant sur Virements.
  2. Allez dans l'onglet En cours et sélectionnez le virement que vous souhaitez modifier ou annuler.
  • Pour modifier le virement, cliquez sur Modifier.
    • Effectuez les ajustements nécessaires puis cliquez sur Confirmer.
    • Complétez l'authentification forte pour valider la modification.
  • Pour annuler le virement, cliquez sur Annuler.
    • Confirmez votre action en cliquant sur Confirmer dans la fenêtre de confirmation.

 

📱Sur votre application mobile

  1. Accédez à l'aperçu de vos virements en appuyant sur Virements.
  2. Appuyez sur le virement que vous souhaitez modifier ou annuler.
  • Pour modifier le virement, appuyez sur Modifier le virement.
    • Effectuez les ajustements nécessaires puis appuyez sur Confirmer.
    • Complétez l'authentification forte pour valider la modification.
  • Pour annuler un virement, appuyez sur Annuler le virement.
    • Confirmez votre action en appuyant sur Confirmer dans la fenêtre de confirmation.

 

Y a-t-il des limitations de modification ?

Il existe quelques limitations concernant les détails du virement qui peuvent être modifiés une fois qu'un virement programmé ou récurrent a été configuré.

  • Le montant, le compte à débiter et le bénéficiaire ne peuvent plus être modifiés. Si vous souhaitez modifier ces détails, vous devez annuler le virement et en configurer un nouveau.
  • La fréquence et la date de fin d'un virement récurrent sont modifiables à la fois dans l'application mobile et l'application web. La date de début d'exécution ne peut être modifiée que dans l'application mobile.
