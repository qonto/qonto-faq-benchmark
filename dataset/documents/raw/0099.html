Il est possible de télécharger une preuve d'exécution de virement directement depuis votre interface Qonto, en cas de demande de justificatif par un tiers par exemple.

 

💡Bon à savoir : Le téléchargement d'une preuve de virement pour les virements sortants est disponible pour les Titulaires du compte, les Admins et les Managers ayant les permissions adéquates.
​

Les Managers sans les permissions ou les Collaborateurs ne pourront pas télécharger les preuves de virement, ils doivent se rapprocher d'un Admin ou du Titulaire. Les managers ayant les permissions pour effectuer un virement directement, et non juste une demande de virement, pourront télécharger les preuves de virements de ceux qu'ils ont réalisé eux-mêmes.


​Si vous avez besoin d’une preuve des virements entrants, il vous suffit de contacter notre service client par chat ou par e-mail.

Depuis votre application web :

  • Rendez-vous dans la section Compte pro, puis dans l'onglet Transactions
  • Recherchez le virement pour lequel vous souhaitez une preuve de virement et cliquez dessus
  • Dans le panneau latéral droit, cliquez sur « Télécharger la preuve de paiement » pour télécharger le document

Depuis votre application mobile :

  • Rendez-vous dans la section Virements du Menu
  • Recherchez le virement pour lequel vous souhaitez une preuve de virement et cliquez dessus
  • Cliquez sur « Télécharger la preuve de paiement » pour télécharger le document

💡 Bon à savoir : Vous pouvez également retrouver votre virement sortant dans l’onglet ‘Virements’. Cliquez sur ‘Voir les détails du virement’ pour accéder directement à ses informations dans l’onglet ‘Transactions’.

 

NB : Ce document ne peut être téléchargé que si le virement a été exécuté.
