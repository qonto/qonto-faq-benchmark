Ein Aktionscode bei Qonto ist ein alphanumerischer Code, den Sie in die App eingeben, um einen Rabatt auf das monatliche oder jährliche Abonnement zu erhalten. Der Rabatt wird direkt auf die Abonnementgebühren für einen bestimmten Zeitraum angewendet, wobei jeweils nur ein Code aktiv sein kann.

 

Wie wird mein Aktionscode auf meine Abonnementgebühren angewendet?

Ich habe ein monatliches Abonnement:

Ein Rabatt wird jeden Monat für die gesamte Gültigkeitsdauer des Aktionscodes auf Ihre Abonnementgebühren angewendet. Zum Beispiel, wenn Sie einen Aktionscode von 11 € (ohne MwSt.) für 6 Monate haben, werden maximal 11 € (ohne MwSt.) jeden Monat für 6 Monate von Ihren monatlichen Gebühren abgezogen.

Ich habe ein jährliches Abonnement:

Wenn Sie ein jährliches Abonnement haben, wird der Rabatt direkt auf die jährliche Abonnementgebühr angewendet. Zum Beispiel, wenn Sie einen Aktionscode von 11 € (ohne MwSt.) für 3 Monate haben, wird der Gesamtbetrag (11 €*3) direkt von der jährlichen Gebühr bei der nächsten Verlängerung abgezogen.

☝️ Wichtig: In diesem Fall ist es notwendig, ihren Aktionscode vor dem Verlängerungsdatum einzugeben. Sie müssen den Code entweder im Monat vor der Verlängerung oder spätestens im Verlängerungsmonat vor dem tatsächlichen Datum eingeben.

Hinweis: Wenn Sie mehrere Aktionscodes haben, können Sie alle in Ihrer Weboberfläche eingeben. Es kann jeweils nur ein Code aktiv sein. Sie haben daher die Sichtbarkeit darauf, welcher aktiv ist und welche ausstehen. Die Aktionscodes werden automatisch in der Reihenfolge angewendet, in der sie eingegeben wurden.

 

Wie gebe ich meinen Aktionscode ein?

Ich habe bereits ein Qonto-Konto:

Um einen Aktionscode auf Ihr Qonto-Konto anzuwenden, müssen Sie sich von einem Computer aus einloggen und die folgenden Schritte ausführen:

  1. Gehen Sie zum Einstellungen-Bereich Ihrer Qonto-Webanwendung unten links.
  2. Klicken Sie auf den Bereich Plan und Rechnungen.
  3. Geben Sie Ihren Aktionscode unter Promo Code ein und klicken Sie auf Hinzufügen.
  4. Das war's, Ihr Aktionscode wird automatisch berücksichtigt. 🎉

Ich habe noch kein Qonto-Konto:

Wenn Sie Ihr Qonto-Konto noch nicht erstellt haben oder dabei sind, können Sie während des Registrierungsprozesses einen Aktionscode anwenden. So geht's:

Wenn Sie den Schritt zur Auswahl des Plans erreichen, erscheint auf dieser Seite ein dediziertes Feld für den Aktionscode. Geben Sie Ihren Code in das Feld "Promo Code" ein.
