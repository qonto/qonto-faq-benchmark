Vous pouvez maintenant exporter l’ensemble de vos factures (payées, non payées et annulées) en quelques clics. Cela vous permet de gagner du temps et facilite la gestion et le partage de vos documents financiers avec votre comptable.

 

Qui peut exporter des factures ?

Tous les rôles tels que Titulaire, Admin, Manager et Comptable peuvent exporter les factures.

 

Comment le faire depuis mon interface web ?

Vous pouvez exporter vos factures clients ou fournisseurs depuis l'application web qonto, accessible depuis un ordinateur.

Veuillez suivre les étapes ci-dessous pour les exporter 👇

  1. Allez dans la section Factures.
  2. Cliquez sur Factures Clients ou Factures Fournisseurs selon votre besoin.
  3. Cliquez sur l’icône “Exporter les factures” en haut à droite de votre écran.
  4. Sélectionnez la période en choisissant entre :
    • Ce Mois, pour toutes les factures depuis le 1ᵉʳ de l’année calendaire en cours
    • Cette Année, pour toutes les factures depuis le 1ᵉʳ du mois calendaire en cours
    • Période Personnalisée, pour sélectionner des dates précises
  5. (Optionnel) Cochez la case si vous souhaitez exporter les factures payées, non payées et annulées dans des dossiers séparés.
  6. Cliquez sur Exporter L'export se fera dans le format original de la facture (PNG, PDF ou JPG).

Vous recevrez ensuite un lien par email pour télécharger l'export. Le lien restera actif pendant 7 jours.

 

💡 Les comptables peuvent exporter soit depuis la section Factures Fournisseurs soit depuis le Portail comptabilité.

 

Pourquoi est-ce que je reçois un message d'erreur lors de l'exportation de mes factures ?

Cela peut arriver si vous sélectionnez une période où il n'y a pas de factures. Veuillez essayer une autre période pour voir si cela résout le problème. Sinon, veuillez contacter le support.
