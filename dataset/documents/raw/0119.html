Nous avons introduit le Module de gestion des factures clients pour des fonctionnalités de facturation avancées, tout en maintenant notre solution de facturation standard gratuite.

Si vous avez le module de gestion des factures clients activé sur votre compte, cet article explique :

  • Les raisons pour lesquelles il est activé.
  • Ce qui change après le 1er avril.
  • Comment gérer votre abonnement si vous préférez uniquement la facturation standard.
  • Quelles sont les fonctionnalités incluses dans l'outil de facturation standard et dans le module de gestion des factures clients.

 

Pourquoi ai-je le module de Gestion des Factures Clients activé sur mon compte ?

À partir du 1er octobre 2024, le module de gestion des factures clients a été proposé en essai gratuit.

  1. Vous avez souscrit à l'essai gratuit par vous-même.
  2. Vous utilisiez des factures récurrentes ou des rappels de paiement automatisés avant la mise en place du module de gestion des factures clients. Nous l'avons donc automatiquement activé sur votre compte pour assurer la continuité de votre flux de travail.

 

Quels sont les changements tarifaires à partir du 1er avril ?

À partir du 1er avril 2025, le Module de gestion des factures clients devient un service payant.

Prix public :

  • Facturation mensuelle : 45 €/mois HT
  • Facturation annuelle : 35 €/mois HT (420 € facturés en une fois)

Offres promotionnelles exclusives du 1er avril au 30 juin :

  1. Offre de facturation mensuelle :
    • 35 €/mois HT en avril, mai et juin.
    • Appliqué automatiquement à partir du 1er avril pour les clients utilisant déjà le module.
  2. Offre de facturation annuelle :
    • 29 €/mois HT pour un an (348 € facturés en une fois).
    • À activer via les paramètres de votre compte avant le 30 juin

Puis-je me désabonner de ce module ?

Oui, vous pouvez vous désabonner du module gratuitement avant le 1er avril. Après le 1er avril :

  • Si le module est facturé mensuellement, vous pouvez l'annuler à tout moment.
  • Si le module est facturé annuellement, c'est un engagement d'un an — vous pouvez vous désabonner, mais aucun remboursement ne sera accordé.

Vous pouvez gérer votre abonnement dans les paramètres de votre compte. Pour des instructions détaillées, consultez notre article "Comment changer mon forfait ou ma fréquence de facturation ?”

 

Bon à savoir : Vous conserverez l'accès à toutes les fonctionnalités de facturation standard après avoir supprimé le module de gestion des factures clients.
