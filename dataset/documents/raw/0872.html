Die Slack Requests Integration ermöglicht es Ihnen, tägliche Benachrichtigungen in Ihrem Slack-Workspace (während der Installation ausgewählt) über alle ausstehenden Qonto-Anfragen zu erhalten, einschließlich Überweisungen, Multi-Überweisungen, virtuelle Karten und Flash-Karten. Diese Funktion ist für alle Preispläne verfügbar!

Wer kann die Integration einrichten?

Admin- und Owner-Rollen können diese Integration installieren, solange die Starke Kundenauthentifizierung (SCA) für Ihr Qonto-Konto aktiviert ist.

Wie kann ich die Slack Requests Integration installieren?

Sie müssen die Slack Requests Integration über den Slack Marketplace einrichten.

Sobald dies erledigt ist, müssen Sie sie in Ihrer Qonto-App aktivieren (im Bereich 'Integrationen und Partnerschaften').

Welche Arten von Anfragen werden an Slack gesendet?

Die Integration sendet folgende Arten von Anfragen an Slack:

  • Flash-Karte
  • Virtuelle Karte
  • Überweisung
  • Multi-Überweisung

Sie können diese Anfragen direkt in Slack genehmigen oder ablehnen, und die Entscheidung wird in der Qonto-App angezeigt.

Wie viele Benutzer pro Organisation können die Integration nutzen?

Die Slack Requests Integration unterstützt mehrere Benutzer pro Organisation.

Der Benutzer, der die Integration installiert, kann weitere Slack-Benutzer einladen, sich mit Qonto zu verbinden, sodass diese Überweisungsanfragen über Slack genehmigen oder ablehnen können.

Wie oft erhalte ich Slack-Nachrichten?

Sie erhalten eine Zusammenfassung Ihrer ausstehenden Qonto-Anfragen einmal täglich um 8:00 Uhr.

Bei Fragen wenden Sie sich bitte an support@qonto.com.
