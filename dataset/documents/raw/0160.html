Depuis votre application mobile Qonto 📲

Prélèvements SEPA B2B

  • Remplir et signer le mandat B2B fourni par le créancier

  • Connectez-vous à votre application mobile Qonto et cliquez sur Prélèvements sortants dans la rubrique Plus

  • Cliquez sur le bouton + pour télécharger le mandat

  • Prenez une photo du mandat ou sélectionnez-la dans votre bibliothèque photo ou un autre dossier

  • Saisir les détails du mandat : la Référence Unique de Mandat (RUM), Votre Identifiant SEPA Créancier (ICS) et la fréquence de paiement (ponctuelle ou récurrente)

  • Valider le mandat

Un prélèvement B2B est un prélèvement interentreprises. Celui-ci est réservé uniquement aux paiements entre entreprises et il est majoritairement utilisé par les institutions publiques (DGFIP, URSSAF, SIE…).

L'autre particularité de ce mandat est que le débiteur ne peut pas prétendre à un remboursement.

En cas de contestation, le client devra se rapprocher du créancier, aucune action n’est possible de notre côté.

 

Reconnaitre un mandat B2B

👉 Il y a la mention “Mandat de prélèvement SEPA inter-entreprise” sur l’en-tête de page

👉 Il comporte souvent la mention “Vous n’êtes pas en droit de demander à votre banque le remboursement d’un prélèvement SEPA inter-entreprise”.

​Attention, un prélèvement SEPA inter-entreprise ne peut pas être contesté après son exécution.

 

💡Si vous avez configuré l'authentification forte sur votre compte, vous recevrez une demande de confirmation sur votre téléphone associé.

 

 

Depuis votre application web 💻

Prélèvements SEPA B2B

  • Signer le mandat de prélèvement B2B fourni par le créancier

  • Connectez vous à votre application web Qonto et rendez-vous dans la section “Compte pro”, puis dans la section “Prélèvements sortants” et cliquez sur le bouton “Ajouter un prélèvement” en haut à droite.

  • Renseigner les informations du mandat : la Référence Unique de Mandat (RUM), l’identifiant Créancier SEPA (ICS) et le type de paiement (unique ou récurrent)
    ​

💡Si vous avez configuré l'Authentification forte sur votre compte, vous recevrez une demande de confirmation sur votre téléphone associé.

 

Cliquez sur ce lien pour visualiser une démo depuis votre propre interface : https://app.qonto.com?tdm=create-sdd-mandate

 

Prélèvements SEPA Core

Vous n'avez rien à faire sur votre Compte Qonto !

Il vous suffit de fournir vos coordonnées bancaires Qonto à votre créancier. Vous pouvez les télécharger à tout moment depuis votre compte. Le créancier sera autorisé à débiter votre compte.

Vous pouvez contester un prélèvement SEPA Core si le montant qui figurait dans l'historique de votre compte semble être incorrect.

 

Reconnaitre un mandat CORE

👉 Il y a la mention “Vous êtes en droit de demander le remboursement dans un délai de 8 semaines".
