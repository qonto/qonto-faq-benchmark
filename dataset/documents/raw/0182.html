Disponible pour tous les forfaits

 

Vous pouvez désormais facilement suivre vos comptes professionnels externes directement dans votre interface avec la fonction d'agrégation de comptes.

Cela vous permet de garder un oeil sur les soldes de vos comptes externes ainsi que vos transactions depuis l'application Qonto pour simplifier la comptabilité de votre entreprise :

  • centralisation de vos données financières
  • un meilleur contrôle et une meilleure visibilité sur vos informations financières

👉 Cliquez sur le lien suivant pour découvrir une démo directement sur votre compte Qonto : https://app.qonto.com/?tdm=add-account 

Quels rôles peuvent connecter un compte externe à Qonto ?

Les rôles Titulaires et Admin ont la possibilité de gérer les connexions avec les institutions externes, aussi bien sur l'application Qonto web que mobile.

Seuls les rôles Titulaires, Admin et Comptable peuvent visualiser les données des comptes externes.

 

⚠️ Dans l'article, le mot institutions fait référence aux banques externes ou PSP.

Un PSP (Prestataire de Services de Paiement) est une société tierce qui permet aux entreprises d'accepter les paiements électroniques, tels que les cartes de crédit et les cartes de débit.

Par exemple, Stripe et Paypal sont des Prestataires de Services de Paiement.


Comment le configurer sur mon compte ?

Pour connecter (ou reconnecter) votre compte professionnel externe, veuillez suivre les étapes ci-dessous.

 

👆 Bon à savoir : Nous vous recommandons de connecter des comptes externes en euros exclusivement.

 

🖥️ Depuis l'application web :

  1. Rendez-vous dans la section Compte pro > Comptes et cliquez sur Créer un compte.
  2. Cliquez sur Compte externe > Choisir.
  3. Sélectionnez le compte bancaire que vous souhaitez importer sur votre tableau de bord Qonto
    - Parmi les banques et PSPs les plus populaires déjà suggérées.
    - Via la barre de recherche s'il n'apparaît pas dans les suggestions. Si vous ne trouvez pas la banque ou le PSP que vous cherchez, c'est que la connexion n'est pas encore disponible. Sachez toutefois que nos équipes travaillent activement pour vous proposer un large choix d'établissements adaptés à vos besoins.
  4. Approuvez la connexion à votre compte externe en donnant votre consentement en :
    - Cliquant sur Autoriser et continuer. Vous pouvez scanner le code QR avec votre téléphone et vous connecter directement sur l'application téléphonique de votre banque externe. Cette option n'est disponible que pour certaines institutions
    - Ou en cliquant sur Continuer depuis l'ordinateur de bureau. Vous serez redirigé vers votre compte externe pour vous connecter avec vos identifiants habituels.
  5. Sélectionnez les comptes bancaires que vous souhaitez connecter à Qonto. Vous pouvez sélectionner plusieurs comptes à la fois. Ils sont identifiables grâce au nom et au solde affichés.

C'est fait ! Vous serez ensuite redirigé vers Qonto et votre compte externe apparaîtra dans votre section Comptes. Vous recevrez un email de confirmation une fois que les données seront entièrement synchronisées.

À noter : Vous pouvez également visualiser votre compte externe depuis la section Intégrations et Partenariats de votre interface. 

 

📱 Depuis l'application mobile :

  1. Depuis l'écran d’accueil > cliquez sur la section Solde > et appuyez sur le symbole ➕
  2. Sélectionnez Compte externe
  3. Approuvez la connexion à votre compte externe en donnant votre consentement et cliquez sur Autoriser et continuer
  4. Sélectionnez votre compte et connectez-vous avec vos identifiants habituels
  5. Autorisez la connexion à Qonto.

Vous êtes prêt !

 

👆 Bon à savoir : Si l’institution que vous souhaitez connecter n’apparait pas dans la liste, nous vous invitons à remplir ce formulaire qui sera ensuite transmis à notre partenaire.

 

Comment cela apparaîtra-t-il sur mon interface ?

Vous trouverez tous vos comptes dans la section Comptes de votre interface. Vos comptes Qonto et externes seront répartis en 4 catégories, classées du plus utilisé au moins utilisé :

1ère catégorie : Comptes courants (flux de trésorerie)

2ème catégorie : Comptes d'épargne

3ème catégorie : Comptes de patrimoine (investissements financiers à long terme)

4ème catégorie : Autres comptes, généralement utilisés lorsque le type de compte ne correspond à aucune des catégories ci-dessus.

Les logos de votre banque externe/PSP apparaîtront dans votre liste de comptes pour faciliter votre navigation sur votre interface. Ils apparaîtront également dans la liste des transactions afin que vous puissiez identifier rapidement quelle transaction a été effectuée avec quel compte.

Vous pouvez filtrer et personnaliser votre vue en sélectionnant vos comptes depuis la section Aperçu, cliquez sur Tous les comptes, sélectionnez ceux que vous souhaitez et appuyez sur Appliquer.


Vous aurez accès à l’historique de vos transactions externes des 3 derniers mois ou plus en fonction de votre banque.

 

Dois-je renouveler la synchronisation à un moment donné ?

Oui, pour des raisons de sécurité, vous devrez renouveler votre connexion tous les 6 mois. Vous recevrez une notification directement sur l'application Qonto avec un lien sur lequel cliquer, ce qui lancera un processus pour renouveler votre consentement.

Si la connexion est interrompue, les données externes restent visibles pendant quelques mois, mais le délai exact dépend de la banque externe/PSP, et non de Qonto.

Cependant, si vous déconnectez manuellement votre compte externe de Qonto, les justificatifs liés aux transactions externes seront perdus. Il ne sera pas possible de les récupérer.


Comment déconnecter un compte externe de Qonto ?

🖥️ Vous pouvez le faire depuis l'application web :

  • Allez dans la section Compte pro > cliquez sur Comptes > sélectionnez le compte bancaire
  • Cliquez sur les 3 points en haut à droite > puis sur Gérer la connexion
  • Déconnectez votre compte


Qonto peut-il accéder à ces comptes ?

Non, Qonto récupère uniquement les données de vos comptes externes pour les afficher et les enrichir. Qonto n'a pas accès à vos identifiants bancaires et ne peut pas initier de transactions sur vos comptes.

Puis-je exporter les transactions effectuées sur des comptes externes depuis Qonto ?

Oui, vous pouvez inclure les transactions externes et leurs pièces jointes effectuées via Qonto dans votre export. Veuillez cliquer ici pour savoir comment exporter vos transactions.

 

Puis-je joindre une facture ou un reçu à une transaction effectuée avec un compte externe ?

Vous pouvez associer des reçus à vos transactions de comptes externes depuis la section Transactions de votre compte ou via votre adresse e-mail de transfert.
