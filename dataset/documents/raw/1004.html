Karte wurde wegen falscher PIN-Eingabe gesperrt

Wenn Sie beim Abheben oder bei einer physischen Zahlung 3 mal den PIN-Code eingegeben, wird der Status Ihrer Karte auf "PIN gesperrt" gesetzt.

Sie müssen den Prozess zur Änderung Ihrer PIN durchführen.

Eine Anleitung dazu finden Sie unter diesem Link 👉 Wie kann ich meinen PIN-Code einsehen oder zurücksetzen? 

☝️ Wenn Sie sich bei Erhalt Ihrer Karte nicht mehr an den PIN-Code erinnern, den Sie bei der Bestellung festgelegt haben, ist es aus Sicherheitsgründen nicht möglich, diesen zurückzusetzen.

In diesem Fall müssen Sie die Karte deaktivieren und eine neue Karte bestellen.

👉Wie kann ich eine Karte deaktivieren?
👉Wie kann ich eine Qonto Karte bestellen?

 

Ihre Karte kann vorübergehend gesperrt/entsperrt werden

Es ist möglich, Ihre Karte vorübergehend zu sperren und direkt aus Ihrem Kundenbereich zu sperren/entsperren.

Eine Anleitung dazu finden Sie unter diesem Link 👉 Wie kann ich eine Karte sperren/entsperren?

Wie kann ich eine Karte nach einer vorübergehenden Sperrung entsperren?

  • Gehen Sie im Bereich “Geschäftskonto” auf “Karten”
  • Wählen Sie die Karte aus, die Sie reaktivieren möchten Klicken Sie auf “Karte entsperren”
  • Geben Sie Ihr Passwort ein und wählen Sie “Diese Karte entsperren”
  • Bestätigen Sie Ihre Wahl

☝️Wenn Sie eine Mitarbeiter-Rolle haben, ist eine Genehmigung zur Kartenentsperrung durch einen Admin oder den Manager erforderlich. 

Eine Anleitung dazu finden Sie unter diesem Link 👉 Wie kann ich eine Karte sperren/entsperren?

 

☝️ Ihre Karte wird vorübergehend gesperrt, wenn Sie einen Rückbuchungsantrag aufgrund unautorisierter Aktivitäten gestellt haben

Wenn Sie einen Rückbuchungsantrag stellen, weil Sie unautorisierte oder betrügerische Aktivitäten mit Ihrer Karte feststellen und als Folge eine oder mehrere Kartentransaktionen ausgeführt und Ihr Konto belastet wurde:

  • ⚠️ wird Ihre Karte aus Sicherheitsgründen vorübergehend gesperrt, um weitere mögliche betrügerische Abbuchungen zu verhindern.

  • 👉 Sollten die Ermittlungen Ihrem Rückbuchungsantrag wegen Betrug stattgeben, wird die Karte endgültig wegen Kompromittierung der Kartendaten deaktiviert werden müssen. Dazu erhalten Sie zusätzlich eine Rückmeldung von unserem Team.

  • ☝️ Sollten die Ermittlungen ergeben, dass es sich um keine betrügerische Aktivität, sondern um einen möglichen Handelsstreit mit einem Händler handelt, wird die Karte von unserem Team entsperrt und wieder aktiviert und Sie werden entsprechend über die weiteren erforderlichen Maßnahmen informiert.

    Mehr Details zur vorübergehenden Sperrung der Karte finden Sie in diesem Artikel 👉 Ich erkenne eine Kartenzahlung nicht, was soll ich tun?

    🚨 Es wird dringend empfohlen, die Karte erst dann zu entsperren, wenn unser Team die Bearbeitung Ihrer Rückbuchungsanfrage abgeschlossen hat, um weitere mögliche unberechtigte Abbuchungen zu verhindern.
