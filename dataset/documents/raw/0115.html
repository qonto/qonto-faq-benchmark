Effectuer un virement international est assez simple. Vous pouvez faire un virement directement depuis votre application web ou mobile en suivant les étapes ci-dessous.

💻 Sur votre application web

  1. Allez dans la section Compte pro et cliquez sur Virements.
  2. Cliquez sur Effectuer un virement dans le coin supérieur droit.
  3. Sélectionnez Virement international.
  4. Sélectionnez le compte à débiter, saisissez le montant du virement et sélectionnez les devises.
  5. Étape facultative - Programmez un paiement en cliquant sur Programmer.
    • Sélectionnez la date de début.
    • Sélectionnez la fréquence si vous souhaitez mettre en place un virement récurrent.
    • Cliquez sur Configurer la programmation pour enregistrer vos paramètres pour ce virement programmé.
  6. Une fois que vous êtes satisfait de la configuration de votre virement, cliquez sur Continuer.
  7. Sélectionnez un bénéficiaire ou ajoutez-en un nouveau, ajoutez des informations supplémentaires et téléchargez une pièce jointe si nécessaire.
  8. Un dernier coup d'œil : prenez un moment pour vérifier que tout est correct avant de cliquer sur Confirmer.
  9. Confirmez votre action avec l'authentification à deux facteurs.

📱Sur votre application mobile

  1. Appuyez sur Menu puis sélectionnez Virements.
  2. Appuyez sur l'icône + noire dans le coin supérieur droit.
  3. Sélectionnez Virement international.
  4. Saisissez le montant du virement et sélectionnez les devises.
  5. Étape facultative - Programmez un paiement en appuyant sur Programmer.
    • Sélectionnez une date d'exécution.
    • Si vous souhaitez configurer la Récurrence du virement appuyez sur son bouton pour l'activer.
      • Sélectionnez l'intervalle approprié.
      • Saisissez la date de fin si nécessaire - le virement se répétera sinon indéfiniment jusqu'à ce qu'il soit modifié ou annulé.
    • Appuyez sur Configurer la programmation pour enregistrer vos paramètres pour ce virement programmé.
  6. Une fois que vous êtes satisfait de la configuration de votre virement, appuyez sur Continuer.
  7. Sélectionnez le bénéficiaire ou ajoutez-en un nouveau, ajoutez des informations supplémentaires et téléchargez une pièce jointe si nécessaire.
  8. Un dernier coup d'œil : prenez un moment pour vérifier que tout est correct avant d'appuyer sur Confirmer.
  9. Confirmez votre action avec l'authentification à deux facteurs.

💡 Veuillez garder à l'esprit qu'un montant minimum sera nécessaire pour exécuter les paiements SWIFT - généralement autour de 10€ pour toutes les devises (sauf pour les Schillings kényans pour lesquels le montant minimum est de 36€).

💡 Bon à savoir : Si vous souhaitez trouver ou vérifier un code BIC/SWIFT, vous pouvez utiliser notre moteur de recherche BIC/SWIFT.
