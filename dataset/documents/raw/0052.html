Google Ads est une plateforme publicitaire numérique qui aide les entreprises à atteindre des clients potentiels via Google Search, YouTube et les sites web partenaires.

Grâce à l'intégration Google Ads de Qonto, vos factures sont automatiquement récupérées et importées dans votre compte Qonto. Le système fonctionne selon un calendrier programmé pour collecter les factures des configurations de facturation éligibles, simplifiant ainsi votre flux de travail comptable.

Rôles utilisateur : Titulaire et Admin

Forfaits : Actuellement disponible sur tous les forfaits

Appareil : Application web uniquement pour le moment

 

Comment fonctionne l'intégration Google Ads

  • Un seul compte Google Ads peut être connecté par organisation Qonto
  • L'intégration synchronise automatiquement toutes les factures mensuelles de vos sous-comptes et configurations de facturation

 

Comment ça marche ?

  • Connectez un compte Google Ads à votre organisation Qonto
  • Nous synchroniserons automatiquement les factures de tous vos sous-comptes et configurations de facturation
  • Vos factures sont récupérées quotidiennement à une heure programmée

 

De quoi avez-vous besoin pour commencer ?

  1. Facturation mensuelle : Configurez votre compte Google Ads pour une facturation mensuelle
  2. Compte MCC : Disposez d'un compte gestionnaire qui supervise plusieurs comptes clients
  3. Niveau d'accès approprié : Accès Administrateur ou Standard à votre compte Google Ads

 

Avez-vous besoin de votre identifiant de compte ?

Un coup d'œil rapide ! Il se trouve en haut de votre tableau de bord Google Ads – ce numéro unique identifie votre compte

 

Souhaitez-vous vérifier vos détails de facturation ?

  1. Cliquez sur "Facturation" dans le menu de gauche
  2. Sélectionnez "Configuration de facturation"
  3. Vous verrez toutes vos configurations de facturation listées avec leurs noms et identifiants

👉 Astuce : Gardez ces informations à portée de main – elles sont utiles si vous avez besoin d'assistance !

 

Comment trouver les détails de votre facture ?

Cliquez sur n'importe quelle configuration de facturation pour voir : • Numéro de facture • Date d'émission • Montant total • Identifiant de compte associé

💡 Retrouvez toutes vos factures dans l'onglet Factures sous chaque configuration de facturation

 

Comment vos factures sont-elles nommées dans Qonto ?

Nous gardons cela simple : googleads_AAAA-MM_montant Exemple : googleads_2025-05_34567

👉 Astuce rapide : AAAA-MM indique la période de facturation (comme 2025-05 pour mai 2025)
