Sie können ganz einfach Vorlagen für Ihre Kundenrechnungen direkt in Ihrem Qonto-Konto erstellen und anwenden. Vorlagen helfen Ihnen, Zeit zu sparen und Konsistenz in Ihrem Rechnungsprozess zu gewährleisten, indem wiederkehrende Informationen vorausgefüllt werden.

Diese Funktion steht Kontoinhabern und Admins mit Zugang zum Kundenrechnungen -Add-on zur Verfügung.

 

Wie erstelle ich eine Rechnungsvorlage?

Sie können eine neue Vorlage im Bereich Rechnungen erstellen:

  • Gehen Sie zu Rechnungen > Vorlagen und klicken Sie auf das Symbol oben rechts Vorlage.
  • Klicken Sie auf Vorlage erstellen.
  • Füllen Sie die Details aus, die Sie wiederverwenden möchten:
    • Rechnungsdetails (Titel, Referenz, Daten)
    • Produkte und Dienstleistungen (Beschreibung, Mengen, Preis)
    • Benutzerdefinierte Nachrichten (optional)
  • Sehen Sie sich die Vorschau Ihrer Vorlage an, um sicherzustellen, dass alle Informationen korrekt sind.
  • Klicken Sie auf Speichern (Ihre Vorlage steht nun für zukünftige Rechnungen zur Verfügung).

Sie können auch direkt aus einer bestehenden Rechnung oder einem Angebot eine Vorlage erstellen, indem Sie die Option Vorlage aus Rechnung/Angebot erstellen auswählen.

Dabei werden alle relevanten Felder kopiert, die Sie vor dem Speichern anpassen können.

 

Wie wende ich eine Vorlage auf eine neue Rechnung an?

Wenn Sie eine neue Rechnung erstellen möchten:

  • Gehen Sie zu Rechnungen > Kundenrechnungen > Rechnung erstellen.
  • Klicken Sie auf das Symbol oben rechts "Vorlage"
  • Wählen Sie die Vorlage aus, die Sie verwenden möchten.
  • Das System füllt automatisch alle voreingestellten Details aus der Vorlage aus.
  • Überprüfen und bearbeiten Sie bei Bedarf alle Felder.
  • Schließen Sie Ihre Rechnung wie gewohnt ab und senden Sie sie.

Eine Benachrichtigung bestätigt, dass die Vorlage erfolgreich angewendet wurde.

 

Was sollte ich bei der Verwaltung meiner Vorlagen beachten

Beachten Sie, dass Sie den Erstellungsprozess der Vorlage jederzeit ohne Speichern abbrechen können.

Denken Sie bei der Verwendung von Vorlagen daran, dass alle aus einer Vorlage erstellten Rechnungen zusammen mit Ihren regulären Rechnungen aufgelistet werden. Beachten Sie, dass Sie die Rechnungsdetails vor dem Versand immer überprüfen und anpassen können, auch wenn Sie eine Vorlage verwenden.
