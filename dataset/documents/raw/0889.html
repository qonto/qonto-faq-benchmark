Eine internationale Überweisung zu tätigen ist recht einfach. Sie können eine Überweisung direkt über Ihre Web- oder mobile App durchführen, indem Sie die folgenden Schritte befolgen.

💻 In Ihrer Web-App

  1. Gehen Sie zum Bereich Geschäftskonto und klicken Sie auf Überweisungen.
  2. Klicken Sie auf Überweisung tätigen in der oberen rechten Ecke.
  3. Wählen Sie Internationale Überweisung.
  4. Wählen Sie das zu belastende Konto aus, geben Sie den Überweisungsbetrag ein und wählen Sie die Währungen.
  5. Optionaler Schritt - Richten Sie eine terminierte Zahlung ein, indem Sie auf Terminieren klicken.
    • Wählen Sie das Startdatum aus.
    • Wählen Sie die Häufigkeit aus, wenn Sie eine wiederkehrende Überweisung einrichten möchten.
    • Klicken Sie auf Terminierung festlegen um Ihre Einstellungen für diese terminierte Überweisung zu speichern.
  6. Sobald Sie mit der Einrichtung Ihrer Überweisung zufrieden sind, klicken Sie auf Weiter.
  7. Wählen Sie einen Empfänger aus oder fügen Sie einen neuen hinzu, fügen Sie zusätzliche Informationen hinzu und laden Sie gegebenenfalls einen Anhang hoch.
  8. Ein letzter Blick: Nehmen Sie sich einen Moment Zeit, um zu überprüfen, dass alles korrekt ist, bevor Sie auf Bestätigen klicken.
  9. Bestätigen Sie Ihre Aktion mit der Zwei-Faktor-Authentifizierung.

📱In Ihrer mobilen App

  1. Tippen Sie auf Menü und wählen Sie dann Überweisungen.
  2. Tippen Sie auf das schwarze + Symbol in der oberen rechten Ecke.
  3. Wählen Sie Internationale Überweisung.
  4. Geben Sie den Überweisungsbetrag ein und wählen Sie die Währungen.
  5. Optionaler Schritt - Richten Sie eine terminierte Zahlung ein, indem Sie auf Terminieren tippen.
    • Wählen Sie ein Ausführungsdatum.
    • Wenn Sie die Wiederholung der Überweisung einrichten möchten, tippen Sie auf den entsprechenden Schalter, um ihn zu aktivieren.
      • Wählen Sie das passende Intervall.
      • Geben Sie bei Bedarf das Enddatum ein - die Überweisung wird sonst auf unbestimmte Zeit wiederholt, bis sie geändert oder storniert wird.
    • Tippen Sie auf Terminierung festlegen um Ihre Einstellungen für diese terminierte Überweisung zu speichern.
  6. Sobald Sie mit der Einrichtung Ihrer Überweisung zufrieden sind, tippen Sie auf Weiter.
  7. Wählen Sie den Empfänger aus oder fügen Sie einen neuen hinzu, fügen Sie zusätzliche Informationen hinzu und laden Sie gegebenenfalls einen Anhang hoch.
  8. Ein letzter Blick: Nehmen Sie sich einen Moment Zeit, um zu überprüfen, dass alles korrekt ist, bevor Sie auf Bestätigen tippen.
  9. Bestätigen Sie Ihre Aktion mit der Zwei-Faktor-Authentifizierung.

💡 Bitte beachten Sie, dass ein Mindestbetrag erforderlich ist, um SWIFT-Überweisungen auszuführen - in der Regel etwa 10 € für alle Währungen (mit Ausnahme des Kenianischen Schillings, für den der Mindestbetrag 36 € beträgt).
