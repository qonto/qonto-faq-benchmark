Rechercher sur Qonto est un moyen simple de localiser les documents financiers pertinents dans Qonto, comme les factures ou les reçus, et de les associer à vos transactions. Cette fonction simplifie le rapprochement en vous permettant de rechercher et filtrer rapidement les documents, et suggère même des correspondances potentielles grâce à l'IA.

L'objectif est de vous faire gagner un temps précieux dans votre processus comptable.

Cette fonctionnalité est disponible pour :

  • Tous les clients Qonto (à l'exception de ceux ayant un accès Employé).
  • Tous les forfaits et marchés, sur Desktop, iOS, et Android.

Comment puis-je trouver mes documents sur Qonto ?

Pour trouver des documents tels que les factures fournisseurs, les factures clients et les reçus, suivez les étapes ci-dessous :

  1. Ouvrez la vue détaillée de n'importe quelle transaction.
  2. Cliquez sur Rechercher sur Qonto pour chercher des documents correspondants dans votre compte.
  3. Consultez les suggestions basées sur l'IA pour associer rapidement le bon document à votre transaction.

Comment puis-je filtrer les documents dans Rechercher sur Qonto ?

Vous pouvez filtrer votre recherche de documents par :

  • Date de téléchargement, en utilisant des périodes prédéfinies (par exemple, ce mois-ci, le mois dernier).
  • Paramètres de date personnalisés pour des périodes spécifiques.
