You can initiate up to 400 transfers at once by uploading an .XML file that respects the ISO 20022 standard in your Qonto app. Guidelines for XML files are available in the web app during the setup of a bulk transfer.

 

💡Good to know: It is possible to send bulk transfers as instant, but please note, we can’t guarantee that all bulk transfers will be processed as instant.

 

💡 This feature is available from the Basic Plan.

 

Most of the payment and accounting services (such as PayFit) can automatically provide .XML files.

 

To initiate a group transfer using an .XML file, simply follow these steps:

  1. Click on Business account in the menu on the left of your web app.
  2. Click on Transfers and then on Make a transfer.
  3. Select SEPA bulk transfer in euros → Upload a file.
  4. Consult our guidelines for XML files which are linked there to help you with uploading the correct XML format.
  5. Once you have exported your XML file, drag and drop or click on the drag and drop zone to select it from your computer and upload it.

    💡 An error message will appear if there are any issues with the file format or the contents of the file and specify which issue was encountered.

  6. Click on Continue once your file has successfully been uploaded.
  7. The web app will prompt you to Review transfer details.
    Here you can review transfer details and make any changes if necessary for each beneficiary from your uploaded file before clicking on Continue.

    💡 Any missing or invalid data will be highlighted in red with a brief description of the issue.

  8. Select which account to debit and optionally schedule the transfer before clicking on Continue.
  9. Take a One last look at the summary and review if everything is correct before clicking on Confirm.

💡 If you have set up Strong Customer Authentication on your account, you will receive a confirmation request on your associated phone.
