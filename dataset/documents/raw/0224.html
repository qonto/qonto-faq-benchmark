Vous souhaitez contester un débit par carte ?

Avec Qonto, vous pouvez facilement contester une transaction que vous ne reconnaissez pas

Il existe plusieurs types de contestation 👇

1. Le litige commercial

Vous avez enregistré votre carte sur le site du commerçant :

  • Le commerçant n’a pas respecté ses engagements (le colis n’a pas été livré).
  • Vous avez payé un service mais celui-ci n’a pas été honoré
  • L’article commandé n’est pas conforme à celui affiché sur le site

Pour ces cas, nous vous invitons à contacter le commerçant afin de demander un remboursement. Si vous n’obtenez pas satisfaction, il faudra réunir tous les échanges écrits avec le commerçant.

Le litige commercial doit être déclaré dans un délai de 90 jours après la transaction.

👉 Une fois votre dossier complet (avec les échanges écrits), nous vous invitons à contester la transaction directement depuis votre application Qonto.

Pour être guidé sur votre application, rendez-vous par ici : https://app.qonto.com?tdm=request-chargeback

Il vous suffit de sélectionner la transaction que vous souhaitez contester et de cliquer sur Besoin d'aide, puis J'ai un problème avec le paiement, le produit ou le service.

Ajoutez toutes les informations que vous pouvez fournir (facture, preuve de biens/services défectueux, échanges de mails avec le commerçant). Notre équipe reviendra vers vous dans les 24 heures ouvrables suivantes.

💡 Plus vous fournissez d'informations, plus votre contestation sera traitée rapidement.

Vous pouvez trouver les étapes ici

Vous constatez un prélèvement récurrent d'un commerçant que vous connaissez :

Il est possible que vous ayez souscrit malgré vous à un programme d’abonnement suite à un paiement sur le site du commerçant. Cela arrive typiquement lorsqu’une case est cochée par défaut et vous donne accès à un essai gratuit, qui sera automatiquement renouvelé et facturé par la suite.

Malheureusement, Qonto ne peut pas intervenir dans ce cas. Il vous faudra demander la résiliation et le remboursement de l’abonnement depuis le service client du site commerçant.

2. Un paiement frauduleux par carte

Vous constatez un paiement par carte dont vous n'êtes pas à l'origine :

  • Tout d’abord, nous vous conseillons de déclarer votre carte comme “perdue” ou “volée” pour éviter de nouvelles transactions frauduleuses.
    • Pour être guidé sur votre application, rendez-vous par ici si elle est perdue: https://app.qonto.com?tdm=report-lost-card
    • Pour être guidé sur votre application, rendez-vous par ici si elle est volée: https://app.qonto.com?tdm=report-stolen-card

La fraude doit être déclarée dans un délai de 8 semaines après la transaction.

👉 Ensuite, nous vous invitons à contester la transaction directement depuis votre application Qonto. Sélectionnez la transaction que vous souhaitez contester et cliquez sur Besoin d'aide, puis sélectionnez Je soupçonne une activité frauduleuse.

Pour une résolution rapide et efficace, veuillez ajouter tous les documents pertinents. Vous pouvez inclure des photos, des captures d'écran, des e-mails et des discussions. Dans la section de description, fournissez des détails supplémentaires afin d'augmenter les chances de résoudre votre litige.

Vous pouvez trouver les étapes ici

3. Un retrait DAB (distributeur automatique de billets)

Vous avez fait un retrait mais les billets ne sont pas sortis :

👉 Nous vous invitons à contester la transaction directement depuis votre application Qonto. Il vous suffit de sélectionner la transaction concernée et de cliquer sur Besoin d'aide, puis J'ai reçu un montant différent ou aucun argent.

Pour être guidé sur votre application, rendez-vous par ici : https://app.qonto.com?tdm=request-chargeback

Vous avez un maximum de 90 jours pour contester un retrait au distributeur automatique.
