Un code promotionnel chez Qonto est un code alphanumérique à entrer dans son application qui permet d'obtenir une réduction sur l'abonnement mensuel ou annuel. La réduction s'applique directement sur les frais d'abonnement pendant une période définie, avec un seul code actif à la fois.

 

Comment s’applique mon code promotionnel sur mes frais d’abonnement ?

Je dispose d’un abonnement mensuel :

Une réduction est appliquée sur vos frais d'abonnement chaque mois durant toute la validité du code promotionnel. Par exemple, si vous avez un code promotionnel de 11€HT durant 6 mois, 11€HT maximum seront déduits de vos frais mensuels, chaque mois, durant 6 mois.

Je dispose d’un abonnement annuel :

Si vous avez un abonnement annuel, la réduction s’applique directement sur le frais d’abonnement annuel. Par exemple, si vous avez un code promotionnel de 11€HT pour 3 mois, le total (11*3) sera directement déduit du montant du frais annuel, lors de son prochain renouvellement.

☝️ Important : Dans ce cas-là, il est nécessaire de saisir votre code promotionnel avant la date de renouvellement. Vous devez entrer le code soit durant le mois précédant le renouvellement, soit au plus tard le mois du renouvellement, avant la date effective de celui-ci.

À noter : Si vous disposez de plusieurs codes promotionnels, vous pourrez tous les saisir sur votre interface web. Un seul code ne peut être actif à la fois. Vous aurez donc de la visibilité sur celui qui est actif et ceux qui sont en attente. Les codes promotionnels s’appliqueront automatiquement dans l’ordre auquel ils ont été saisis.

 

Comment saisir mon code promotionnel ?

Je dispose déjà d’un compte Qonto :

Pour appliquer un code promotionnel sur votre compte Qonto, vous devez vous connecter depuis un ordinateur et réaliser les actions suivantes :

  1. Allez dans la section Paramètres de votre application web Qonto en bas à gauche.
  2. Cliquez sur la section Forfait et factures.
  3. Entrez votre code promotionnel sous Code promo et cliquez sur Ajouter.
  4. Le tour est joué, votre code promotionnel sera bien pris en compte automatiquement. 🎉

Je n’ai pas encore de compte Qonto :

Si vous n’avez pas encore créé votre compte Qonto ou que vous êtes en train de le faire, vous pouvez appliquer un code promotionnel pendant le processus d'inscription. Voici comment faire :

Lorsque vous arrivez à l'étape de sélection du forfait, un encart dédié à la saisie du code promotionnel apparaîtra sur cette page. Entrez votre code dans le champ “Code promo”.
